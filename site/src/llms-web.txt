# 安装 Orca PPT（命令行 + 浏览器工作台）

1. **检查依赖，缺什么装什么**：Node.js 22.18 以上（`node -v`）；Chrome 或 Edge（`orca-ppt` 用它渲染稿子，
   不会自己下载浏览器）。
2. **装 `orca-ppt`**（升级也是重跑这一行）：

   ```
   npm install -g https://github.com/orca-studio/orca-ppt/releases/latest/download/orca-ppt.tgz
   ```

   直连 GitHub 太慢（几十 KB/s）时，包可以改从镜像下：在原地址前加 `https://gh-proxy.com/`（不通就换 `https://v4.gh-proxy.org/`），下到本地，
   拿 github.com 上的 `SHA256SUMS.txt` 核对 `orca-ppt.tgz` 那一行，对上了再 `npm install -g ./orca-ppt.tgz`。
   镜像是第三方的：校验文件不走镜像，对不上就停下，删掉包，告诉用户。

3. **装 skill**：`orca-ppt skill` 打印随包附带的 skill 目录，把它链进你读 skill 的目录，名字用 `orca-ppt`：
   WorkBuddy 是 `~/.workbuddy/skills/orca-ppt`，Claude Code 是 `~/.claude/skills/orca-ppt`，Codex 等是
   `~/.agents/skills/orca-ppt`。macOS、Linux 用 `ln -s`；Windows 用目录联接
   `cmd /c mklink /J <链接> <skill 目录>`（不用管理员）。那里已经有一个 `orca-ppt` 时先问用户再换。
   升级不用重链：包装在原处，链接一直指着最新的。
4. **确认连得上**：`orca-ppt serve --detach --no-open` 打印出工作台的网址，`orca-ppt call deck_status`
   返回 `NO_DECK_OPEN` 或页数，就都好了。
5. **告诉用户装好了**，请他新开一个对话 / 任务（skill 一般在新对话里才加载）。之后说要做稿子，你照 skill 来。
