# Roadmap

## M0 — 骨架(本轮)

仓库、文档、monorepo、契约包、能起来的空 server 和渲染层。跑得起来,没有功能。

## M1 — 放映画布 ✅

- server 在 127.0.0.1 上服务一个已有的 deck 目录,服务根按稿子实际逃逸层数倒推
- Electron `<webview>` guest 里放映,方向键翻页(走 `Reveal.next()`,不灌键盘事件)
- 认 `deck.html` 和 `index.html`;没有 `outline.json` 时页数从 HTML 本身数出来
- 左栏页胶片、状态栏页码与画布同步

**验收(已过):** `examples/forest-timeline`(4 页)和 `examples/emerald-editorial`(5 页)
在产品里原样放映 —— 缩放比、主题字体、GSAP 转场与浏览器里一致,页面自报问题为 0。

画布尺寸变化不用额外处理:guest 收得到 resize,reveal 自己重算缩放比 —— 加过一个
ResizeObserver 主动调 `Reveal.layout()`,量下来是多余的,已经去掉。

## M2 — 检视锚 ✅

- 画布注入检视脚本,hover 高亮、点击取锚、Esc 取消
- 锚 → 带上下文的裁切图 → 挂在输入框上 → 随提交进对话
- Claude Code 适配器接上 Agent SDK,SDK 消息翻译成 Thread → Turn → Item
- 稿子在磁盘上变了画布就重载,**并回到原来那一页** —— agent 改的和用户自己在编辑器里
  改的一视同仁

**验收(已过):** 在画布上点中第 2 页标题、写一句「把这个标题改成 X」,Claude Code 定位到
那个元素、改了 `index.html`、画布自己刷新并停在第 2 页。全程没有描述过那个元素在哪。

**这一版的权限:** 改文件自动放行(作用域是用户打开的那份 deck 目录),其余工具走默认。
SDK 不挂 `canUseTool` 时需要授权的调用是**直接拒绝**而不是等人点头,所以不放行改文件的话
产品不成立。交互式授权在 M3。

## M3 — 阶段编排与授权 ✅

- **交互式授权**:`canUseTool` 接到 UI,允许 / 总是允许 / 拒绝。M2 那个 `acceptEdits`
  兜底已撤掉;没挂授权回调的调用方一律**拒绝** —— 背着用户放行比少能干一点危险得多
- Brief / Theme / Outline / Plan / Build 五阶段,产物落 `.deck/`,跑完做确定性校验
- 阶段状态**从磁盘上的产物推出来**:关掉重开、换台机器、用别的工具改过,状态都对
- 重跑一个阶段,下游全部作废 —— 不作废的话界面会显示一份基于旧上游的产物是「好的」
- 「看产物」用系统默认应用打开那个文件:deck 是磁盘上的目录,改产物就用用户自己的编辑器,
  不在应用里造一个更差的 JSON 编辑器
- 主题目录从 skill 的 `runtime/themes` 读,喂给选主题阶段

**验收(已过):** 一个空目录 + 一句「讲讲我们这个季度做了什么,给团队看,四页」,
五个阶段依次跑完出成品,全程不开终端。

**仍然欠的:** 主题选择器现在只把目录喂给提示词,界面上还不能点着选。

## MCP 转向(已完成)

适配器层整个删掉:`adapter-api`、`adapter-claude-code`、`adapter-codex`、会话管理、授权 UI、
对话栏。换成一个 MCP server —— 协议的第二个薄客户端。

- **不变量**:界面能做的每一件事都是一个协议方法;MCP 和界面等价
- 待办队列:人取的锚、点的「跑」挂进去,agent 调 `take_requests` 取走
- 阶段闸门保留,方向从「我们推」变成「agent 拉」
- 授权交还给 agent 宿主,不造第二套

**验收(已过):** MCP 挂在 `http://127.0.0.1:6722/mcp`,11 个工具,一行命令装好;
没显式 `open_deck` 时回退到界面正开着的那份;`phase_prompt` 在上游不合规时如实拒绝;
`show_slide` 驱动画布;`capture_slide` 截回一张真实渲染的整页图。

## M4 — 把转场弄好

**不做录制导出。** 演示稿的交付物是稿子本身,不是视频 —— 要看效果就放一遍。
原来这里写着「录制 job、只重录选中段、导出 mp4」,以及为此要给 skill 的 `capture.mjs`
加范围参数,全部否掉。(09-24 给 `capture.mjs` 加的 `--interrupt` 是另一回事:它模拟
「转场放到一半按下一页」,给自检验跳帧用,不是录制导出。)

预览靠两条,都已经在:方向键翻页会真的播转场(实测过,连拍 8 帧有 6 对在变);
自动播放按每页声明的 `data-hold` 依次往后翻。

**已完成**。剩下的原本是:

- `plan.json` 可视化:一行一次翻页,显示两页的**关系**和选用的**手法**
- 点一行跳到那次翻页并重放
- 点「这儿不对」产生**转场锚**进待办 —— 契约里 `TransitionAnchor` 早就有,但界面上
  没有任何入口能产生它;也就是说「第 3 页到第 4 页这个硬切没对上」今天只能打字描述,
  而我们整个产品的立论就是不用打字描述位置
- 现成的稿子没有 `plan.json`(skill 把转场计划写在 HTML 注释里),要能从注释解析

**验收(已过):** 转场画在导航器里两张缩略图之间(它本来就住在两页之间),显示稿子里
记的**手法**,悬停出两个动作 —— 重放、挂进待办。挂出来的是**转场锚**,agent 那头
`take_requests` 收到「第 3 页 → 第 4 页的转场 · 这个形态变换没对上」,和人点元素
同一个去处、同一个格式,没加新工具。

_为什么不是「看效果」:_ 看效果按方向键就有。时间轴给的是**意图** —— 计划里写的是
「这两页本来是什么关系」,画面只告诉你发生了什么。两者不一致的时候,那才是 bug。
另外 20 页 = 19 次转场,挨个播要几分钟,列表一眼能看出「连着四次都是 morph」。

## M5 — 自检回路(暂不做)

**现在是:agent 触发,人给反馈。** 改完自己调 `capture_slide` 看一眼、或者按 ▶ 放一遍;
哪儿不对由人指出来 —— 在画布上点一处、或者点那一道转场,指给它看。

render → critique → revise 的自动闭环等以后真有需要再说。当时写下来的三项确定性检查
(页面自报问题、帧差量、匹配剪辑轮廓比对)全都要逐帧渲染的结果,而录制已经否掉;
真要做时先重新回答一个问题:**这三项拦住的东西,人自己放一遍是不是已经能看出来。**
