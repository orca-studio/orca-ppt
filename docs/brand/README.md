# Orca PPT 品牌与宣传素材

定位：和 AI 一起，把想法做成演示稿。连接用户自己的 AI agent，支持构思、制作、放映和带位置的修改意见。

## 主标志

叠放的幻灯片表示演示稿，页内短线表示内容排版，绿色四角星表示 AI 辅助创作。黑白保持工具感，绿色沿用应用强调色。虎鲸仅作可选吉祥物，不作主 logo。

| 文件                                   | 用途                                                                                                         |
| -------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| `orca-mark.svg`                        | 矢量标志；应用使用 `apps/web/public/brand/orca-mark.svg`，修改时同步                                         |
| `orca-app-icon.png`                    | 1024 × 1024 圆角底板图标;桌面壳用它派生 `apps/desktop/assets/icon.png`(macOS 留白,824 居中加投影),修改时同步 |
| `orca-avatar-square.png` / `.svg`      | 1024 × 1024 完整白底正方形头像，无透明角                                                                     |
| `orca-wordmark.png` / `.svg`           | 横向标志与字标                                                                                               |
| `launch-banner-1920x1080.png` / `.svg` | 16:9 产品宣传横幅                                                                                            |
| `social-square-1080.png` / `.svg`      | 1:1 社交海报，标注流程明确为示意                                                                             |
| `social-card-1200x630.png` / `.svg`    | 社交分享卡片                                                                                                 |
| `orca-mascot-avatar.png`               | 可选 3D 虎鲸吉祥物，不用于产品主标志                                                                         |

SVG 是可编辑源文件；PNG 可直接上传。文字采用系统字体栈，跨系统编辑时需确认字体与换行。

品牌色：墨黑 `#151918`、绿色 `#16a34a`、浅绿 `#ccebd6`、白色 `#ffffff`。应用采用白色底板适配深浅主题。头像交给平台裁切，不预先切圆角。

## 文案与使用

- 主标题：和 AI 一起，把想法做成演示稿。
- 社交标题：AI 帮你做稿，你来决定精彩。
- 说明：连接你的 AI agent，从想法走到成稿。
- 产品生成 HTML 演示稿；不要宣传成已支持导出 PowerPoint `.pptx`、录制视频或内置独立模型。

主 logo、字标与宣传排版直接用 SVG 制作。3D 吉祥物使用内置 image_gen 生成，提示词见 `mascot-prompt.md`。
