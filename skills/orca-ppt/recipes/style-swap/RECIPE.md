# 网页改版提案

手法：同一个网页换风格

## 参考拆解

参考是一组「前端网页设计风格」图鉴（小红书长图，来源不明）：一种风格一张横幅，左边写风格名和关键词，右边是这个风格的网页示意图。
每张示意图是**不同的网站**，所以并排看能比风格，翻页时却接不起来：前后两页没有同一个东西，只能溶解。

本同款把它改成**同一个网站**：一套固定内容（品牌、导航、主标题、副标题、两个按钮、三个数字、主视觉、几块色块），
每种风格只改样子。四样东西叠出来：

1. **框不动**：一个只有三个圆点的浏览器框（`art/chrome.png`），每页同一个位置、同一个尺寸。风格名写在框外左上角。
2. **元素一一配对**：框里每个元素整份稿子一个 `data-id`。翻页时 reveal 按配对把位置、字号、颜色、圆角、描边、内边距连续过渡过去，
   字体族和阴影没法插值，在转场开始那一刻直接换。每样东西始终只有一份，观众看到的是「这个标题变粗、变大、移到了这里」，不是两页叠在一起。
3. **主视觉换质感**：每种风格一张配图。上一张、下一张透明地叠在同一个框里，翻页时跟着框移动、交叉淡化。
4. **动效风格真的动**：最后一种风格分两页，第二页所有元素原地不动，翻过去后背景视频推近，数据卡弹出，鼠标移到按钮上（页内动画）。

## 适用 / 不适用

| 适用 | 不适用 |
| --- | --- |
| 比稿、设计评审：同一个页面摆几种视觉方向，让人翻页比 | 要比的是不同页面、不同信息结构（首页 vs 详情页）：内容不一样就配不上，用普通内容页 |
| 改版前后、品牌换皮提案：旧版 → 新版 | 要演真实的交互流程（点击、表单、滚动）：这里只有第一屏 |
| 讲网页 / 界面风格的分享、课程、短视频 | 用户要交付真实网页：这是示意，不是可用的前端代码 |

## 内容槽位

| 槽位 | 从哪取 | 缺了怎么办 |
| --- | --- | --- |
| **网页内容**：品牌名、导航 3–4 项、主标题（一句，可以两行）、副标题、主按钮、次按钮、三个数字 | 用户的产品 / 页面 | 文案按用户的产品自己写；**数字不编**，没有就删掉三个数字（`stat1–3` 整份删掉），或者放明显的占位。品牌名不许用真实存在的品牌、域名 |
| **风格清单**（按出场顺序，4–10 种） | 用户给的，或按用途挑 | 没给就从样稿的 8 种里挑。顺序本身是叙事：先稳后大胆（极简 → 瑞士 → … → 极繁），对比的两种放相邻 |
| **每种风格的配图** | 用户给的设计稿、截图，或生成 | 没有就不放图，那一页用色块和大字撑（样稿的瑞士页就没有图）。配图里不许出现网址、二维码、真实品牌 |
| **动效页的背景视频** | 可选 | 没有就只留页内动画（数据卡、鼠标），背景不动也成立 |

## 页面结构

样稿 9 页，一个虚构的 AI 创作工具「栖云」：

| 页 | 风格 | 看点 |
| --- | --- | --- |
| 1 | 极简主义 | 整页配图，细衬线标题 |
| 2 | 瑞士国际主义 | 配图淡出，分割线和红色竖块进来，标题变成粗黑体，三个数字排成一列 |
| 3 | 玻璃拟态 | 红块变成磨砂卡片，数字落进卡片 |
| 4 | 粗野主义 | 卡片收成底部黑条，配图缩到右半边、去色 |
| 5 | 赛博朋克 | 黑条变成霓虹框，标题变洋红发光 |
| 6 | 黑色科技 | 同一版式，只换成克制的白字和一道弧光（和第 5 页成对比） |
| 7 | 极繁主义 | 标题描边、倾斜，FLOW 大字和圆形贴纸进来 |
| 8 | 动效主导（静） | FLOW 变成斜体大字，标题缩小 |
| 9 | 动效主导（动） | 元素不动；背景视频推近，数据卡弹出浮动，鼠标移到按钮上 |

**风格数和样稿不同时**，删页或复制一页改 section 类（`mk-风格`）和坐标；新风格的样子写进 `mockup.css`。
每加、删、换一页，都要把下面「动效原则」里的三件事重新对一遍：前后两页的配图层、隐藏元素的位置、错开时间。

坐标看样稿 `index.html`：所有元素都在网页区域 `left 292 ~ 1628、top 248 ~ 1000` 里（框内 1336×752），框外只有浏览器框图和风格名。

## 动效原则

- **一套内容，整份稿子不变。**每个元素一个 `data-id`，文字一个字都不改 —— reveal 按 `data-id` 配对，字变了就成了两个东西。
  某种风格不需要某个元素（瑞士没有配图，极繁不放数字），就把它留在页面里、写 `opacity:0`，不要删。删了它就没法从上一页走过来，下一页也没法走回去。
- **透明待命的元素停在哪**：上一页还看得见的，留在上一页的位置原地淡出；否则提前停在**下一次出现的位置**，到时原地淡入。
  停错了（停在很早以前的位置），它会边飞边淡入，从别的元素中间穿过去。
- **主视觉三层**：每页放这一页的配图（`opacity:1`），再放上一页、下一页的配图（`opacity:0`，框和这一页的配图一样）。
  翻页时这一页的图和下一页的图都从这一页的框走到下一页的框，一张淡出一张淡入 —— 框是连续的，只有质感在溶解。
  配图层的 `data-id` 按图起名（`mk-art-min`），同一张图隔几页再出现可以复用。
- **错开时间**（都写 `data-auto-animate-delay` / `data-auto-animate-duration`）：
  - 这一页新出现的元素等 0.35 秒，让上一页要消失的先走；要消失的元素用 0.5 秒淡完。
  - 三个数字换队形（一行 ↔ 一列 ↔ 卡片里）时依次出发，沿整体移动方向走在最前面的先走，相隔 0.08 秒。否则后面的会从前面的身上穿过去。
  - 两个元素的路线交叉时（样稿第 8 页 FLOW 从右上飞到左上，标题从中间往下走），晚走的那个等 0.25 秒。
  - 风格名不配对：旧名上移淡出，新名延迟 0.45 秒上浮进来，同一时刻只读得到一个名字。
- **共享动画 1.2 秒**（位移常常超过半屏，见 `transitions.md`「共享元素」第 9 条）；动效页的「静 → 动」那次 0.4 秒，什么都不动，只是开始放页内动画。
- **两种风格版式相同时**（赛博朋克 → 黑色科技），就让它几乎不动，只换颜色和字体：观众盯着同一个标题看它变色，这一对就是在演「一个热闹，一个克制」。
- 每一次翻页都是共享元素，不受「不要连续三次同一种手法」的限制：同一个网页一路换风格，重复的动作正是看点（和元素交接走列表同理）。

## 硬规则

- 根节点写 `data-demo="style-swap"`；框内样式只在 `mockup.css` 里，每条选择器带 `.mk`；框外照常只用主题和配色。
  规则全文见 `references/style-swap.md`，`check-deck` 会核。
- 框内元素都带 `mk` 类，每页一个 `.mk-screen`（`data-id="mk-screen"`）。终态和转场中途都不许出这个区域，字不许叠字、不许压在色块 / 图片边上。
- 色块和配图不写 `rotate`。写了旋转的元素引擎会改成绕中心变形，又平移又缩放时中途会冲出原来的范围；要倾斜只给文字写（样稿极繁页的标题和 FLOW）。
- 画面里不许出现网址、域名、地址栏（浏览器框只有三个圆点），品牌名、文案都要是虚构的或用户自己的。
- 动效页的背景视频首尾一致（最后回到第 0 帧的样子）：翻走时它的淡出副本停在当时那一帧，首尾不一致的话循环放映会跳。

## 自检

除了 `transitions.md` 末尾的通用自检，再看：

1. 中间帧（30% / 50% / 70%）里每样东西只有一份：没有两套标题、两个按钮叠在一起。`check-deck` 量的是这三个点，正常速度再看一遍。
2. 配图的框是连续移动的，不是一个框消失、另一个框出现。
3. 深浅底互换的翻页（玻璃 → 粗野、黑色科技 → 极简），中段文字颜色会过渡到和底色接近，有零点几秒发灰，这是颜色插值的样子；
   字要是完全看不见了，把那一页的字色或底色往反方向拉开一点。
4. 动效页翻过去之后才开始动，翻过去那一下画面一点不跳。

## 样稿

`index.html`：9 页，主题 Soft Editorial，配色 washi（只管框外：底色和风格名）。框内样式 `mockup.css`。
`art/` 里：7 张配图（AI 生成，网站「栖云」是虚构的）、黑色科技的弧光（CSS 画好截的图）、浏览器框 `chrome.png`、
动效页背景视频 `mot-bg.mp4`（主视觉推近再回到原位，速度线扫过，6 秒）、鼠标 `cursor.svg`。
首页样片只录 1–4 页（极简 → 瑞士 → 玻璃 → 粗野），封面取瑞士页落定之后。

```bash
node scripts/check-deck.mjs recipes/style-swap/index.html
node scripts/capture.mjs recipes/style-swap/index.html -o recipes/style-swap/index.mp4
```
