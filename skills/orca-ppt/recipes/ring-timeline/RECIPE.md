# 环形时间轴

## 参考拆解

参考的是 PowerPoint 里流行的「旋转时间轴」：画面左边半个大圆环，环上排着几个年份，
一块浅色扇形压在当前年份上；每翻一页，扇形绕圆心转到下一个年份，右边换上这一年的说明。
它在 PowerPoint 里的做法是「空心圆 + 空心弧，每页把弧旋转一格，切换选平滑」。叠出来的是三样东西：

1. **半个大圆环**：圆心贴着画布左边，只露出右半边，所以环很大、年份排得开，又不占右边的版面。
2. **一块高亮扇形**：和圆环同心，比环略宽一圈，压在当前年份上。当前年份放大、变实，其余年份压暗。
3. **右边一栏说明**：这一年的标题、一句话、一个数。翻页时旧的往上退、新的从下面升上来。

看点只有一个，重复走完全程：

> **扇形绕圆心转一格，年份跟着一个变大、一个变暗，右边的文字往上换一段。**
> 封面上扇形藏在画面外，第二页才转进来；最后一页它继续转出画面，五年走完。

观众盯着同一块扇形走，「讲到第几年了」不用解释。

## 适用 / 不适用

| 适用 | 不适用 |
| --- | --- |
| 发展历程、产品版本演进、项目阶段：4 到 6 个按顺序排的节点 | 节点超过 6 个：一格不到 25°，年份挤在一起，换横向时间线（`forest-timeline`） |
| 每个节点说的话差不多长：一个标题、一句话、一个数 | 节点之间要比大小（营收逐年涨了多少）—— 环上读不出量级，用柱状图（`data-report`、`cobalt-grid`） |
| 想要「一路往前走」的节奏感，同一个动作重复 | 节点之间是并列关系、没有先后 —— 转盘暗示了顺序，用 `drink-showcase` 或 Bento |

## 内容槽位

| 槽位 | 从哪取 | 缺了怎么办 |
| --- | --- | --- |
| **节点**（年份、版本号、阶段名） | 用户给的时间线，4–6 个 | 环上写的字不超过 4 个字符宽（「2021」「V3」「一期」）；名字长就在环上写序号，名字放右栏标签 |
| **每个节点一段** | 标题（≤ 10 字）+ 一句话 + 一个数和它的单位 | 没有数就不放数字行，标题和一句话照常；**不编数** |
| **封面** | 一个总括的大字（「五年」「十个版本」）+ 一句副标题 | 用节点数自己写 |
| **结尾** | 往后看的一句话 | 没有就写「下一个 X」，按节点的单位 |
| **圆环中心** | 主语 + 「发展历程」这类四个字 | 默认「发展历程」 |

## 页面结构

```
1 封面      圆环 + 全部年份（都压暗），扇形转到画面外；右栏总括大字 .t-display + 副标题
2–6 节点    每页一个节点：扇形转到它，它变 .t-h1 .t-on-accent；右栏 标签 / 标题 / 一句话 / 大数字 + 单位
7 结尾      扇形继续转出画面，年份全部压暗；右栏一句往后看的话
```

做转场锚的元素照样稿抄坐标（圆心 `(120, 540)`）：

| 元素 | 坐标 | 写法 |
| --- | --- | --- |
| 圆环 `ring` | `left:-420 top:0 1080×1080`，内半径 300 | `.s-surface`，洞用径向渐变画在背景上 |
| 扇形 `wedge` | `left:-460 top:-40 1160×1160`，张角 30° 朝正右方 | `.s-accent`，`clip-path` 三角形 + 径向渐变，每页只改 `rotate` |
| 年份 `y2021`… | 半径 420 的圆上，-60° / -30° / 0° / 30° / 60° | 宽 200、居中；当前 `.t-h1` 行高 80 → `top = y − 40`，其余 `.t-h2` 行高 58 → `top = y − 29` |

节点数不是 5 时：可见的弧取 120°（-60° 到 60°），一格 = 120° ÷ (节点数 − 1)，扇形张角取一格的角度。
右栏从 `left:800` 起，标签 `top:280`、标题 `340`、一句话 `460`（宽 1000）、大数字 `640`、单位 `820`。

主题和配色：样稿用 `clearing` 主题（Inter）+ `amber` 配色（炭灰底、琥珀环、奶油色扇形）。
换配色时，扇形用 `.s-accent`、环用 `.s-surface`，两者要明显分得开。

## 动效原则

```
1→2  关系：高亮扇形从画面外绕圆心转进来，停在第一个节点   手法：绕圆心转  共享：wedge
2→3  关系：扇形转到下一个节点，前一个压暗、这一个放大       手法：绕圆心转  共享：wedge
…    （每个节点一样）
6→7  关系：扇形继续顺时针转出画面                           手法：绕圆心转  共享：wedge
```

- **同一个动作连续用**：时间轴就是「顺序往前走」，和元素交接走列表一样，是组合规则允许的例外
  （`transitions.md`「组合规则」）。不在中间插遮挡剪辑 —— 一插，观众就跟丢了扇形。
- **一直顺时针**：角度从小到大写，翻一页加一格。往回翻是直接切，不会反着转。
- **进出画面转得远**：封面 -150°、结尾 150°，离第一格、最后一格各 90°，写 `data-auto-animate-duration="1.2"`；
  中间每格 30°，用默认 0.9 秒。
- **年份跟着扇形的位置变**：扇形离开的年份前半程变回普通（`data-auto-animate-duration` 等于半程），
  到达的年份后半程才放大点亮（`data-auto-animate-delay` 和 `data-auto-animate-duration` 都等于半程）：
  0.9 秒的页写 `0.45`，1.2 秒的页写 `0.6`（`transitions.md`「焦点移交」第 4 条）。
- **右栏的字不做共享元素**：每页内容都不同，让它们按默认规则走 —— 旧的上移淡出，新的上浮淡入
  （0.9 秒那几页从 0.6 起，1.2 秒那页从 0.8 起，依次加 0.08；大数字和单位同一行，共用一个延迟）。

## 硬规则

- 扇形和圆环的盒子每页位置、大小一样，只改 `rotate`；每页都写 `rotate`。
- 一次转动不超过 180°（`check-deck` 会提醒）。
- 扇形和圆环不用 `mask`：洞用径向渐变，张角用 `clip-path`（`transitions.md`「绕圆心转」第 5 条）。
- 每个年份写 `data-id`，文字两页一样；当前年份 `.t-on-accent`，其余 `.t-on-surface`。
- 不编数：节点的数从用户给的材料来，没有就不放数字行。

## 自检

除了 `references/transitions.md` 末尾的通用自检，再看：

1. 扇形是**绕圆心**转的：中途每一帧它都贴着圆环，没有甩出环外，也没有先消失再出现。
2. 年份是**原地**变大变暗的：文字中心不动，没有淡出再浮进来；扇形转到两格中间时，没有两个年份同时是半大不小的。
3. 1→2 扇形从画面外转进来；6→7 继续顺时针转出去，不倒转。
4. 右栏旧文字往上退、新文字从下面升上来，中途不叠在一起。
5. 环上的年份都在安全区里，当前年份的字没有超出扇形。
