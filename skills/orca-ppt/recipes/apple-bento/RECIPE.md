# 苹果卡片

样稿场景：两款手机的功能亮点。手法：版式（bento 卡片墙：圆角统一、间距统一、底和卡只差一点灰）+ 卡片墙在页与页之间整组重排、遮挡、钻入

## 参考拆解

参考是抖音 · PT老农《为什么苹果的卡片很高级？来看这套公式》，拆的是 apple.com 产品页的 bento 卡片。笔记给的公式是「圆角 ≈ 短边 × 18%、横距 16 / 竖距 16 或 24」；在 apple.com 上量 computed style 得到的是更简单的一套，样稿按实测：

1. **圆角统一**：所有卡片 28px，不随卡片大小变；
2. **间距统一**：卡片之间 20px，横竖一样；
3. **底和卡只差一点灰**：#F5F5F7 底配白卡，或者整页近黑配纯黑卡；
4. **一格一件事**：一张产品图 + 一行小字 + 一个大数字（「120Hz」「2.2 倍」「增加 20 小时」），关键字用蓝色或渐变；
5. **拼贴封面**：一个渐变大标题压在几块卡片墙中间（原笔记的「Apple Card」那张）。

参考是静态的。这里把卡片墙当成会动的东西：拼贴里的缩略图是后面整页的缩小版，翻页时原地放大归位。

| 参考 | 这里 |
| --- | --- |
| 圆角、间距、底色 | 主题 `bento`（`--radius-m: 28px`）+ 配色 `porcelain`；坐标按 20px 间距排 |
| 白卡 / 近黑底 / 纯黑卡 | `.s-surface-2` / `.s-surface` / 主题的 `.s-ink`（从 `--surface` 推出的纯黑） |
| 卡里的说明小字 | `.t-label`；要自动换行的说明段落用主题的 `.t-copy` |
| 渐变大标题 | `.t-display` 里一个 `.t-gradient`，三个 `--grad-*` 指配色变量 |
| 带字的卡片 | 全部是 HTML：卡片底 + 不带字的产品图 + 文字。图里不许带字 |

## 适用 / 不适用

| 适用 | 不适用 |
| --- | --- |
| 产品发布、功能亮点、宣传短片：有一两款产品、一堆规格数字 | 没有产品图的内容：bento 的格子靠产品图撑，全是字的格子很空 |
| 纯画面展示（给视频旁白配画面） | 一页要讲清一段道理的汇报：一格只放一句话、一个数 |
| 两款产品对照（一黑一白） | 三款以上平级产品：换 `drink-showcase` |

## 内容槽位

| 槽位 | 从哪取 | 缺了怎么办 |
| --- | --- | --- |
| **封面大标题** | brief | 10 个字符以内（`.t-display` 一行，左右各留一列卡片） |
| **产品 A 的 10 个亮点**（第 2 页 bento） | 产品官网、规格表 | 每格一行小字 + 一个大数字或一张图；数字一律不编 |
| **产品 B 的 6 个亮点**（第 3 页黑卡） | 同上 | 同上 |
| **产品照** | 用户给的或官网原图 | 抠图或纯色底、不带字；每款至少 1 张主图 + 3 张局部 |
| **三条功能说明**（封面左列） | 官网原文 | 每条一句，句首一段用彩色 |

## 页面结构

样稿 7 页，iPhone Air 和 iPhone 18 Pro（apple.com.cn 的官方图和原文）：

| 页 | 主角 | 坐标 |
| --- | --- | --- |
| 1 拼贴封面 | 左列三张说明卡、上面第 2 页的缩小版、下面第 3 页的缩小版、右列两张产品照，正中渐变大字 | 左列 `120, 110 + i × 290, 380 × 270`；右列 `1440, 100 / 545, 360 × 425` |
| 2 产品 A 总结 bento | 6 列 × 3 行 11 格 | `cell(c, r, w, h) = [170 + c × 266, 110 + r × 292, w × 266 − 20, h × 292 − 20]` |
| 3 产品 B 六格黑卡 | 整页近黑 + 3 × 2 张纯黑卡 | 卡片 `505 × 448`，x `183 / 708 / 1233`，y `81 / 549` |
| 4 非黑即白 | 整页黑收成左半屏，左两张黑卡、右两张白卡 | 卡片 `640 × 300`，x `160 / 1120`，y `230 / 550` |
| 5 产品 B 主图 bento | 从左上那张主摄卡里长出来：主图 + 主摄 + 两张黑卡 | 主图 `180, 80, 770 × 920` |
| 6 倾斜拼贴 | 六张产品照整组倾斜 −12° | 300 × 300，中心距 320 |
| 7 结尾 | 渐变大字 | 和封面同一行 |

封面的两块缩略图是第 2、3 页**原样复制、等比缩小**：格子底和图按缩小后的坐标写（`mAir` 把整页坐标映射到 `(654, 80)` 宽 612），
字照抄后用 `scale` + `transform-origin: 0 0` 缩小。缩略图里的字开头加一个零宽空格（`&#8203;`），不然 reveal 会按相同文字把它和第 2 页的字配对，缩放会跳。
产品 A 的格子数变了，就重排 `cell` 网格，封面的缩略图跟着同一份坐标算，不要两边各写一份。

## 动效原则

样稿开头的注释里有转场计划。要点：

- **缩略图就是下一页。** 1→2 是整组重排：格子底按 `data-id`（a1–a11）、图按 `src` 配对，从缩略图原地放大到整页；缩小的字淡出，正常大小的字晚 0.9–1.0 秒浮出。
  不要把缩略图做成一张截图：截图放大是糊的，也配不上对。
- **黑卡片墙从下面上来。** 2→3 用遮挡剪辑，色块用 `surface`、方向 `up`，和下一页的底同色；第 3 页的卡片不写入场动画，由离开的色块从下往上擦出来。
- **整页黑是一块形状。** 第 3 页的近黑底是 `data-id="dark"` 的 `.s-surface`，3→4 它收成左半屏，成了黑白分屏的黑那一半。
- **钻进一张卡。** 4→5 从主摄卡（`data-zoom="cam"`）放大进去，主图 bento 从里面长出来；6→7 推近拼贴里那张浅色卡（`data-zoom="tile"`），再拉开露出大字。
  推近的目标选浅色卡：选黑卡的话，满屏的那一帧整页是黑的。
- 同一手法不连用三次；遮挡、整页推近每份各最多两次。
- 停留：每页 3–3.5 秒。

## 硬规则

- 圆角只用主题的 `var(--radius-m)`（28px）；只圆一侧的图写 `0 var(--radius-m) var(--radius-m) 0`，不要自己写一个数。
- 相邻卡片间距 20px，横竖一样。
- 图里不带字。官网截图里带字的卡片，拆成「卡片底 + 不带字的产品图 + HTML 文字」重做。
- 渐变只给三种字：封面和结尾的大标题、产品名（第 2 页的「iPhone Air」）、说明卡句首那一段；格子里的数字强调用 `.t-accent`。
- 同一张图在相邻两页出现、但不该配对时（封面右列的产品照和第 2 页格子里的同一张），复制一份换文件名（`hk-air2.webp`）。
- 样稿用的是 Apple 官网的产品图和原文，做同款时换成用户自己的产品，一样也不留。

## 自检

除了 `transitions.md` 末尾的通用自检，再看：

1. 1→2：每个格子都是从封面缩略图的位置放大过去的，没有一格是淡入的；缩小的字没有和大字配对。
2. 2→3：色块从下往上一口气扫过去，中间不停顿，满屏那一帧和第 3 页的底同色。
3. 量一下：任意两张相邻卡片的间距都是 20，图片铺满所在的格子，圆角和格子的圆角对得上。
4. 每一格的字不贴边：格里的小字左右各留 16 以上。
