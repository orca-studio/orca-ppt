# 卡片墙钻入

样稿场景：价值观宣讲。手法：原则墙钻进一张卡

## 参考拆解

参考是我们自己的样稿 `examples/editorial-tri-tone/`：一份刊物式的「八条原则」简报，主题 `editorial-tri-tone`，配色 `blush`。
看点叠在四样东西上：

1. **三色闭环**：腮红粉画布、酒红深面板、奶油黄卡片和胶囊。没有第四种颜色，酒红和奶油黄在墙上交替，详情页整页酒红。
2. **刊名一路跟着走**：封面正中的巨大刊名（`t-display`）翻页时缩到左上角变成页眉（`t-label`），之后每一页都在同一个位置，观众始终知道自己在哪本刊物里。
3. **墙上的一张卡就是下一页**：原则墙的第 01 张酒红卡被镜头推近、长大、铺满画面，里面显出整页酒红的详情页。观众看到的是「点进了这一张」，不是「换了一页」。
4. **章节号是衬线斜体大字**：详情页的 `01` → `02` 用文字级匹配原地滚动，标题和正文原地换掉，版式一像素不动；再往后整页内容像翻刊物一样一起滑过去。

成立的原因：墙是总览，详情页是其中一格，两者的关系本来就是「整体 ↔ 细节」，所以放大进元素内部读得懂；
而详情页之间版式完全相同、只是顺序往后走，所以用原地替换和元素交接，只让变了的东西动。
最后整页酒红收成结尾页中间的一张酒红卡，和「墙上的一张卡变成一页」首尾相反。

## 适用 / 不适用

| 适用 | 不适用 |
| --- | --- |
| 一组**平级的条目**：原则、价值观、方法论、提案要点、品牌信条，4 到 8 条 | 条目之间有先后或大小（流程步骤、排名、增长数据）—— 墙上平铺会被读成对等 |
| 每条有一个短标题（2–4 个词，或 8 个汉字以内）+ 一两句说明 | 每条要讲一大段、带图表或图片。详情页只有一个标题、两句正文和一行胶囊，装不下 |
| 只展开其中 2 到 4 条做详情页，其余留在墙上 | 每一条都要展开。详情页连着超过 4 页，同一个版式翻到后面观众会开始数页 |
| 品牌介绍、创意提案、团队宣言这类要刊物感、有态度的场合 | 严肃的财务、技术汇报。腮红粉加酒红的气质压不住 |
| 墙上条目正好 8 个最满；6 个可以排成 2×3 | 少于 4 个撑不起「墙」，超过 8 个卡片会小到标题放不下；换版式或拆成两面墙 |

## 内容槽位

| 槽位 | 从哪取 | 缺了怎么办 |
| --- | --- | --- |
| **刊名** | 用户的品牌名、项目名 | 用主题的名词短语（"Studio & Salon"）。一行放得下，`t-display` 不换行 |
| **刊号 / 日期** | 用户给的期数、季度 | 默认 `VOL. 01 — EDITORIAL BRIEF` 和当季（`FW · 2026`）。不编不存在的期号含义 |
| **封面关键词**（5–8 个） | 用户内容里反复出现的词 | 从条目标题里提炼单个词；缺了宁可少放几个胶囊，不凑词 |
| **条目**（4–8 个，每个一个短标题） | 用户的原则、要点 | **不编条目**。不够 8 个就按实际数排墙，最后一格可以是明确的占位（样稿的 "To be added"），并在转场计划注释里写明 |
| **展开的条目**（2–4 个，每个一两句说明 + 3 个胶囊标签） | 用户指定，默认取前几条 | 说明没给就只写标题能支撑的一句，不编案例、不编数据；胶囊没给就从说明里取词，取不出就不放这一行 |
| **结尾数字和一句话** | 条目总数 + 墙的标题 | 默认「条目数 + 墙标题的后半句」（`08` / `principles, loosely held`） |

图片、插画这类素材这个同款用不上；用户硬要加图，就不是这个同款。

## 页面结构

```
1 封面      右上刊号；上方两行奶油黄胶囊（关键词）；正中巨大刊名（data-id: mark）；左下日期
2 原则墙    刊名缩成左上页眉（mark）；右上章节标记；标题一行；2×4 卡片，酒红 / 奶油黄交替
            第一张酒红卡写 data-zoom="p1"
3 第一条    整页酒红（data-id: page）；页眉 mark；章节标记 data-swap="sec"；
            衬线斜体章节号 data-text="num"；标题 data-swap="title"；正文 data-swap="body"
4 第二条    同一版式：sec / title / body 原地替换，num 01 → 02 滚动；底部新增一行三个胶囊
            （每个元素同时写 data-carry，供下一次翻页用）
5 第三条    同一版式，data-carry：sec / num / title / body / tags 整组滑过去
6 结尾      整页酒红收成画面中间的一张酒红卡（page）；卡上大数字和一句话；页眉 mark 留在左上
```

坐标看样稿 `examples/editorial-tri-tone/index.html`（做同款时 create_deck 会复制它）。

- 结尾卡和详情页整页形状同一个 `data-id`（`page`）、同一个颜色类 `s-surface`。
- 胶囊就是 `.s-accent`：本主题 `--radius-s` 是 999px，强调块天然是胶囊形。

`data-zoom` 的那张卡必须是酒红的 `.s-surface` —— 它要长成整页酒红的详情页，换成奶油黄卡中途会混出浑浊的橄榄色（`blush` 配色里酒红和奶油黄不能互变）。

引用顺序：`tokens.css → themes/editorial-tri-tone.css → palettes/blush.css`（`blush` 是这个主题的默认配色）。

## 动效原则

样稿的转场计划：

```
1→2  关系：封面巨大的刊名缩到左上角，变成页眉                        手法：共享元素            共享：mark
2→3  关系：原则墙里的第 01 张卡是下一页的细节                          手法：放大进元素内部      from：p1
3→4  关系：同一版式的下一条原则，章节号 01 → 02，标题和正文原地换掉      手法：共享元素 + 文字级匹配 + 原地替换
4→5  关系：再下一条原则，版式完全相同，整页内容整体流过去                手法：元素交接（胶囊一起滑走）
5→6  关系：整页酒红收成结尾页中间的一张酒红卡                          手法：形态变换（整页 → 卡片）共享：page
```

- **五次翻页五种手法，没有一种连用三次**。展开第四条、第五条时继续用元素交接（走列表时允许连用），不要回头再做文字级匹配：`data-text` / `data-swap` 只在不写 `data-st` 的共享元素页上生效，元素交接页不认。
- **一个元素可以同时带进、出两个键**：第 4 页的元素写 `data-swap`（承接 3→4 的原地替换）又写 `data-carry`（交给 4→5 的元素交接）。第 3 页只要 `data-swap`，第 5 页只要 `data-carry`。
- **每次翻页的共享元素只有一两个**：1→2 只配 `mark`，5→6 只配 `page`（`mark` 位置不变、只换颜色）。墙上的八张卡全是新元素，不做共享 —— 封面胶囊和墙卡片之间没有一一对应关系，硬配会读成「胶囊变卡片」的假关系。
- **刊名缩成页眉要 1.2 秒**：从 `t-display` 到 `t-label` 尺寸变化远超 3 倍，`data-auto-animate-duration="1.2"`。墙的标题和章节标记从 `0.8` 出；卡片 `data-enter="pop"`，**两张一组**从 `0.9` 起每组加 `0.08`（0.9 / 0.98 / 1.06 / 1.14），卡片上的编号和标题跟卡片用同一个延迟。
- **放大进元素内部用默认 1.8 秒，不改短**：卡片要一边长大一边移到正中，太快就只剩「闪了一下」。
- **详情页之间版式一像素不动**：3→4 默认 0.9 秒，变的只有字；第 4 页新出现的胶囊从 `0.7` 起每个加 `0.08`，等标题和正文换完再出。4→5 交接按 `data-carry` 第一次出现的顺序错开 0.06 秒，所以按阅读顺序写：sec → num → title → body → tags；方向用默认的 `left`，整份只用这一个方向。
- **整页收成卡片 1.2 秒**：卡上内容从 `0.8` / `0.9` / `1.0` 依次出，形状扫过大半个画面，不要提前。
- **停留**：墙和详情页信息多，`data-hold="3"`；封面和结尾 `2.5`。

## 硬规则

- 只用 `blush` 的三种颜色，不在页里写颜色；酒红和奶油黄之间不做跨色变形。
- `data-zoom` 的卡是酒红 `.s-surface`，详情页整页形状也是 `.s-surface`，并且是 section 的第一个子元素。
- 胶囊（`.s-accent`）上的字加 `.t-on-accent`；酒红面上的字（包括结尾卡上的大数字）加 `.t-on-surface`。
- 详情页之间元素位置和尺寸完全相同，`data-swap` 的两端中心差不超过 40px，`data-text` 的两端左上角对齐。
- `.t-serif` 只用在章节号、年份、结尾那句短语，不用在正文。
- 不编条目、不编说明里的事实和数据。

## 自检

除了 `references/transitions.md` 末尾的通用自检，再看：

1. 封面到原则墙：刊名是连续缩到左上角的，没有在页眉位置淡入；墙上的卡片在刊名基本落位后才两两弹出。
2. 原则墙到第一条：被推近的是第 01 张酒红卡，它一路长大到铺满，周围的卡片虚化退场；铺满那一帧和详情页 1:1 对上，没有跳。
3. 第一条到第二条：章节号是滚过去的（`01` → `02`），标题、正文、章节标记在原位换掉，没有位移；刊名页眉纹丝不动。
4. 第二条到第三条：五组内容整体向左滑走、新内容从右边进来，胶囊跟着一起走；整页酒红底不闪。
5. 结尾：酒红底是从整页收成卡片的，不是卡片淡入；卡上的大数字在酒红上看得清。
6. 刊名页眉从第 2 页起每页同一位置。
