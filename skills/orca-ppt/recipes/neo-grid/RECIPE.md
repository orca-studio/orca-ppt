# 路演关键数据

手法：网格面板重排

## 参考拆解

配色和版面借自 [beautiful-html-templates](https://github.com/zarazhangrui/beautiful-html-templates)
的 Neo-Grid Bold 模板（MIT）。它是海报式的年报风格：

1. **整页是一格格面板拼起来的**，面板之间留一道缝，没有圆角、阴影、描边。
2. **三种颜色轮流当主角**：墨黑（反白面板）、纸白（普通面板）、荧光柠檬黄（信号面板）。
3. **粗体全大写的标题**（Space Grotesk）加等宽小标签（JetBrains Mono），棋盘格小方块当装饰。

原模板是逐页的静态海报。我们按转场原则加的看点是：

> **封面的面板就是数据页的格子。** 翻页时同一组面板各自移位、改尺寸，排成数字格，每格换上一个数；
> 柠檬黄那格装着最大的数，下一页撑满整页成为结论；同一块整页柠檬黄上，数字往后流到年底目标；
> 再缩回「下一步」的标题格；最后同一组面板重新拼成一张海报收尾，和封面首尾呼应。

## 适用 / 不适用

| 适用 | 不适用 |
| --- | --- |
| 融资路演、增长亮点、产品发布的数据段：几个并列的关键数字，其中一个最重要 | 数字之间要比大小、看趋势（用图表，或者「季度数据报告」同款） |
| 想要响亮、有冲击力的版面 | 严肃克制的场合（年度财报、学术汇报）—— 荧光黄太吵 |
| 4 到 6 个关键数字 | 只有 1 到 2 个数，格子凑不满；超过 6 个，格子太碎 |

## 内容槽位

| 槽位 | 从哪取 | 缺了怎么办 |
| --- | --- | --- |
| **4–6 个关键数字，各带一个短标签** | 用户给的数据；给的是表格文件就按 `references/data.md` 读，一次读整块，出处写进转场计划 | **不编数据**。没有就停下来要，或者用明显的占位并在转场计划注释里写明 |
| **最重要的那个数** | 用户指定 | 默认取最大、最能说明问题的那个；它放进柠檬黄格 |
| **标题**（封面一句、数据页一句） | 用户的主题 | 写短、写成大写，一行不超过 14 个字符 |
| **那个数的下一个值**（目标、预测、下一阶段） | 用户的计划 | 没给就不做第 4 页（目标页），结论页直接接下一步 |
| **下一步的 3 件事** | 用户的计划 | 没给就不做第 5 页，目标页（或结论页）直接接结尾 |
| **结尾的联系方式 / 行动号召** | 用户给的 | 没给就只留一句大标题（「LET'S TALK」这类），底下两格放标签不放具体信息 |

## 页面结构

```
1 封面      四块面板拼成海报：墨黑竖条、柠檬黄标题格、纸白副题格、墨黑底栏
2 数据页    同样四块面板重排成数字格（data-id 不变），另外弹出 1–2 个纸白新格
3 结论页    柠檬黄那格撑满整页（写成第一个元素），最大的数从格子里放大成 .t-metric
4 目标页    同一块整页柠檬黄、同样的版式：标签 / 大数字 / 一句话换成下一个值，棋盘格原地不动
5 下一步    柠檬黄缩回顶部标题格，下面三栏是三件事
6 结尾      下一步的四块面板重新拼成海报：柠檬黄大标题格、墨黑竖条（换到右边）、两块纸白信息格
```

坐标看样稿 `index.html`（做同款时 create_deck 会复制它）。数字格数变了按下面的安全区和缝重排：

- 面板都在安全区里（left 120–1800、top 80–1000），面板之间留 24 的缝。
- **每块面板全程同一个颜色**：`.s-surface`（墨黑）和 `.s-surface-2`（纸白）不能互变，变色中途会发灰。
- 面板上的字：墨黑面板加 `.t-on-surface`，柠檬黄面板加 `.t-on-accent`，纸白面板不用加。
- 标题直接写成大写（主题不改大小写）。
- 引用顺序：`tokens.css → themes/neo-grid.css → palettes/lemon.css`。

强调色面积会超过 15%（`check-deck.mjs` 给提醒，不是错误）。柠檬黄大面板就是这个同款的气势，
但一页最多一块柠檬黄面板 —— 两块以上就没有「最亮的那格」了。

## 动效原则

```
1→2  关系：封面的四块面板就是数据页的四个格子，各自移位、改尺寸，换上数字   手法：形态变换  共享：四块面板
2→3  关系：柠檬黄那格装着最大的数，撑满整页成为结论                       手法：形态变换（卡片 → 整页）  共享：柠檬黄面板、那个数
3→4  关系：同一块整页柠檬黄，数字从实际值往后流到目标值                     手法：元素交接（left）  交接：标签、大数字、一句话
4→5  关系：整页柠檬黄缩回下一步的标题格                                   手法：形态变换（整页 → 卡片）  共享：柠檬黄面板
5→6  关系：下一步的四块面板重新拼成一张海报收尾                           手法：形态变换  共享：柠檬黄、墨黑、两块纸白
```

- **3→4 必须插一次元素交接**，不能也写形态变换：1→2、2→3 已经连着两次形态变换，再接一次就是
  「连续三次同一种手法」（`transitions.md` 组合规则）。而且这一页本来就是「版式不变、内容往后走」的关系。
  整页柠檬黄和棋盘格前后一模一样，**不写 `data-carry`**，原地不动；只有标签 `title`、大数字 `metric`、
  一句话 `caption` 写 `data-carry`（结论页上的同一批元素也要写上）。方向用 `left`，全稿只这一个方向。
- **下一步页的面板为结尾预留 `data-id`**：它们是从整页柠檬黄之后弹出来的新格（`data-enter="pop"`），
  但下一页要拿来重拼海报，所以先写好 id。挑**离终点最近**的那块墨黑去当竖条（右下那块往上长），
  没配对的那块墨黑自己淡出 —— 隔半个画面斜着飞过去的面板会和柠檬黄交叉，看起来像撞在一起。
- 柠檬黄和墨黑竖条相邻时，让它们的缝跟着一起走：柠檬黄右边缘和墨黑左边缘移动同样的距离，缝始终是 24。

- **一次最多 4 块面板配对**（1→2、5→6 都正好 4 块）。新增的格子用 `data-enter="pop"`，等面板基本落位再弹出（转场 1.2 秒，从 0.8 开始）。
- **面板上的字不跟着面板飞**：旧字淡出，新字在面板落位后出。只有「最大的那个数」做共享元素，从格子里放大到结论页。
- **转场都用 1.2 秒**：面板的位移和尺寸变化都很大，0.9 秒看不清。

## 硬规则

- 一页最多一块柠檬黄面板。
- 面板全程不换颜色。
- 不编数据。

## 自检

除了 `references/transitions.md` 末尾的通用自检，再看：

1. 封面到数据页：四块面板都是连续移过去、变尺寸的，不是在新位置淡入。
2. 面板落位之前，新格子和面板上的新字都还没出现。
3. 结论页：柠檬黄是从数据页那一格撑开的，大数字是从格子里放大过来的。
4. 每块面板在每一页都是同一个颜色。
5. 结论 → 目标：柠檬黄底和棋盘格纹丝不动，只有标签、大数字、一句话向左流过去。
6. 下一步 → 结尾：墨黑竖条是右下那块墨黑往上长出来的，柠檬黄和它之间的缝一直在，没有面板交叉压住。

## 样稿

`index.html`：6 页（封面 → 数据页 → 结论 → 目标 → 下一步 → 结尾），一份虚构公司 ACME 的金融数据平台路演，
所有数字都是占位。首页悬停只录 1–3 页（面板重排、柠檬黄撑满整页），封面取数据页落定的那一帧。

```bash
node scripts/check-deck.mjs recipes/neo-grid/index.html
node scripts/capture.mjs recipes/neo-grid/index.html -o recipes/neo-grid/index.mp4
```
