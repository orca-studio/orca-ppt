# 抽拉效果

样稿场景：分步骤年度计划。手法：抽屉拉出

## 参考拆解

参考是抖音「感觉鹿PPT」《让人念念不忘的PPT抽拉效果！》。原片的做法：

1. 整页照片做背景，左边压一个渐变矩形，再用「柔化边缘 25 磅」的黑椭圆裁一半当侧板的影子；
2. 侧板是一个填「幻灯片背景填充」的矩形，透明度 40，看着像一块磨砂板；
3. 序号格是白色半透明矩形 + 一个大数字，组合后往下复制几份，**下移一层**压到侧板底下；
4. 复制这一页、换照片换文案，把不是这一步的格子往左推进侧板里，切换选「平滑」。

看点是：观众看到的是一排抽屉，讲到第几步，那一格就从侧板里抽出来，上一格同时推回去；照片和标题同时换。

这里的写法：

| 原片 | 这里 |
| --- | --- |
| 「幻灯片背景填充」的侧板 + 下移一层 | 侧板 `.s-slot` 写在抽屉后面，抽屉从它的右边沿往右长；格子不往左移，变窄就是推回去 |
| 柔化边缘的黑椭圆当影子 | `.s-slot` 自带往右投的影子，压住抽屉根部 |
| 半透明白矩形 + 数字组合 | `.s-drawer`（磨砂、左边不画边）+ 一个 `.t-display` 数字，两个各有 `data-id`，同一个时长一起动 |
| 换文案 | 每一页的字是一个组，整份稿子同一列：上一页的滚出画面上沿，下一页的从下沿滚上来 |

原片只有一个动作（拉一格）。样稿多做两页：封面四格都收着，总览四格一起拉到最长、格里写出每一步，
当目录用；结尾四格全部收回，和封面首尾呼应。

## 适用 / 不适用

| 适用 | 不适用 |
| --- | --- |
| 年度计划、分阶段方案、培训课表：3–5 步，每步一页 | 超过 5 步：格子挤成一排细条，数字放不下 |
| 每一步有一张照片撑场面（风景、现场、产品） | 没有照片：抽屉的磨砂和侧板都靠照片透出来，压在纯色上只剩几个灰框 |
| 每步一句标题、一两句话 | 每步要讲很多内容、放图表：右栏只放得下一组字。要展开就在这一步后面加普通内容页 |
| | 几步之间没有先后（并列的产品、团队）：序号会让人以为有顺序，换 `drink-showcase` / `team-layouts` |

## 内容槽位

| 槽位 | 从哪取 | 缺了怎么办 |
| --- | --- | --- |
| **主题名、年份**（封面、结尾的小字） | brief | 写「XX · 2027 年度计划」 |
| **封面标题** | 用户的材料 | 一句概括全年的话，6 个字以内（`.t-display` 一行放得下） |
| **每一步的名字、标题、标签、一两句话** | 用户的材料 | 名字两个字（总览的格里写「名字 · 标题」）；标题 8 个字以内；标签写在圆角框里，6 个字以内 |
| **每一步一张照片** | 用户给的 | 横幅、16:9，右半边暗一点（字压在右边）。没给就生成风景，写进转场计划注释；不生成假的现场活动照 |
| **结尾一句话和下一件事** | 用户的材料 | 写下一次活动、下一个节点；没有就只留一句话 |

## 页面结构

样稿 7 页，虚构的户外俱乐部「雾岭山野社」2027 年度计划：

| 页 | 抽屉 | 照片 | 右栏 |
| --- | --- | --- | --- |
| 1 封面 | 四格都收着（宽 200） | 封面照 | `cover`：小字 + 大标题 + 一句话 |
| 2 总览 | 四格都拉到 760，格里写「名字 · 标题」 | 封面照 | `overview` |
| 3–6 第 1–4 步 | 这一步那格拉到 440，其余收着 | 换成这一步的 | `col1`–`col4` |
| 7 结尾 | 四格都收回 | 封面照 | `end` |

坐标：侧板 `left 0、width 300`，铺满整高；四格 `left 300`，`top` 170 / 365 / 560 / 755，高 150。
数字 `left = 300 + 格宽 − 156`、`top = 格的 top − 4`、宽 140 右对齐。右栏 `left 900`（总览 1160），
这一页的组 `top 340`，上一页的 `−480`，下一页的 `1100`。

**步数不同时**：三步把四格换成三格、`top` 重新等分（格高不变，间距放大）；五步格高改 120、间距 30。
每加一步加一页、一个 `col` 组和一个照片，总览里多一行。所有页的抽屉数都要一样多。

## 动效原则

样稿开头的注释里有转场计划。要点：

- **拉出来就是变宽。** 抽屉的左边永远贴着侧板右边沿，`left` 不变、只改 `width`；数字的 `left` 跟着右端算。
  不要把格子往左推进侧板：侧板只有 300 宽，推进去的那段会超出安全区，也会从侧板的磨砂里透出来。
- **一页只拉一格。** 上一步那格收回、这一步那格拉出，同时发生，同一个时长（1.2 秒），不加 `data-auto-animate-delay`。
- **右栏整列往上滚。** 每一页的字是一个 `.s-group`，翻一页这一组滚出上沿、下一组从下沿进来（`transitions.md`「共享元素」的「画外待命」）。
  组在画外时整个出画，`top` 取 −480 和 1100，不要只露一截。
- **照片原地替换**（`data-swap="bg"`），和抽屉同时长。照片上压一层从左到右变暗的底（行内 `linear-gradient`，颜色写 `var(--bg)`）。
- 总览格里的字没配对，按 0.7 起每行晚 0.08 秒出来；翻到第 1 步时淡出。
- 停留：每页 3 秒，总览、结尾 4 秒。

## 硬规则

- 侧板 `.s-slot` 写在四格和数字的后面（DOM 里更晚），影子才压得住抽屉根部。
- 抽屉和数字每页都写，`data-id` 整份稿子不变（`drawer1`–`drawer4`、`no1`–`no4`）。
- 抽屉上的数字、总览格里的字用 `.t-on-glass`：底下是照片，不跟配色走。
- 页面上只写计划本身，不写「第 1 格拉出来」这类说明。
- 样稿的雾岭山野社、活动次数、路线都是虚构的，照片是 AI 生成的：做同款时一样也不留。

## 自检

除了 `transitions.md` 末尾的通用自检，再看：

1. 2→3、3→4 的中间帧：收回的那格和拉出的那格同时动，数字一直贴在格子右端，不先跳到终点。
2. 抽屉根部压在侧板的影子里，看不出格子的左边沿。
3. 右栏中途没有两组字叠在一起；滚出去的那组整个出画。
4. 照片最亮的地方不压字：换了照片就看一眼右栏读不读得动，不行就把照片换成右边暗的。
