# 度假一日行程

手法：窗格翻转

## 参考拆解

参考是小红书「岁有昭昭PPT」《这样的PPT三维翻转动画，直接惊呆领导》的前半段（胶囊窗格 + 平面翻转）。几样东西叠出来：

1. **整页一张画**，上面叠一层黑色到透明的渐变压暗。
2. **四个空窗格**：白色、透明度 70% 的胶囊形，横排在画上。
3. **亮着的窗格**：同尺寸的胶囊，填充选「幻灯片背景填充」—— 于是它露出的是没被压暗的原画，加白边、阴影，盖在第一格上，压上文案。
4. **翻页**：复制这一页，把亮着的窗格挪到第二格，在形状格式里点「水平翻转」，换背景图和文案，切换选「平滑」。
   平滑把「位置变化 + 水平翻转」插值成「边走边翻面」：窗格横向压成一条线，再展开时已经是下一幅画。
5. **文字是独立的文本框**：只平移、淡出淡入，不跟着翻。

本同款照这个做：四幅画是同一处海岸的清晨、正午、黄昏、夜晚（构图一模一样，只有光不同），窗里的画和整页的画对齐，
翻过来的那一下背后的整页画也一起换掉。前后各加一页：封面是整页一扇窗，收成第一格；结尾是最后一格撑满整页。

看点：

> **一排窗，亮着的那扇往右走一格，边走边翻，翻过来是下一个时刻。** 窗里的画和背后的画始终对齐，像透过窗看同一片风景。

和「网页改版提案」（`style-swap`，框不动、里面换风格）的区别：那里框在原地，换的是框里的样子；这里窗自己走，翻一面换一幅画。

## 适用 / 不适用

| 适用 | 不适用 |
| --- | --- |
| 同一处地方的几个时刻、几个季节：酒店、民宿、景区的一日行程，园区四季 | 几处不同的地方：窗里的画和背后的画构图对不上，对齐就没意义了，换「城市漫游」或「营地景区介绍」 |
| 3–5 个平级的段落，每段一句标题一两句话 | 每段要讲很多：胶囊窗只有 360 宽，一段话放三四行就满了 |
| 能拿到（或生成）同一构图、只换光线或季节的几张图 | 只有几张随手拍的照片：构图不同，窗走过去会看到两张画在窗边错开 |
| 顺序往前讲：一格一格走 | 要跳着讲、来回对比：翻面一次只走一格（`transitions.md`「翻面」第 7 条） |
| 要交 PPTX 的：平滑能挪过去、交叉淡化换画 | 要求 PPTX 里也压扁翻面、窗里的画对齐背景：导不出来（`transitions.md`「导出 PPTX」） |

## 内容槽位

| 槽位 | 从哪取 | 缺了怎么办 |
| --- | --- | --- |
| **标题**（封面大字，进正文后留在页顶） | brief | 写场合和地方：「在鸥屿过一天」「园区的四季」，6 个字以内（页顶一行 `t-h1`） |
| **副标题**（封面一行小字） | brief | 「品牌 · 这份稿子讲什么」 |
| **3–5 个时刻**，每个一行时间标签、一个四字标题、一两句话 | 用户的材料 | 没给就按一天四个时段排：清晨 / 正午 / 黄昏 / 夜晚，或按四季。时间标签里的钟点**不编**：用户没给就只写「清晨」「正午」 |
| **每个时刻一张画** | 用户的图，或生成 | **默认生成**：先生成一张，再用它当参考图，一张一张改光线（codex-imagegen，「保持构图、地平线、每一处物体的位置完全不变，只改成正午的光」），要的是**构图完全一致**。都裁成 1920×1080。用户自己的照片要是同一机位拍的才行 |
| **结尾那句话** | brief | 自己补，和窗呼应：「给你留一扇窗」「下一季见」 |

## 页面结构

样稿 6 页：

| 页 | 窗 | 在动的 |
| --- | --- | --- |
| 1 封面 | 整页一扇窗（`left:0 top:0 width:1920 height:1080`，圆角 0），清晨的画 | 进页没动画：四个空窗已经排在窗下面，看不见 |
| 2 第 1 个时刻 | 收成第一格；画不换，所以不翻 | 四个空窗露出来；标题从封面中间升到页顶；三行字等窗落定再出来 |
| 3–5 | 往右走一格，边走边翻，换成下一个时刻的画 | 整页的画同时换（`data-swap="bg"`）；三行字跟着窗走、淡出换新 |
| 6 结尾 | 最后一格撑满整页；画不换，所以不翻 | 页顶标题退场，结尾的话出来 |

**时刻数不同时**：窗格横排，宽 + 间距铺满安全区宽度（120–1800，共 1680）。坐标都落在 40 的网格上：3 个：宽 400、间距 240（`left` 120 / 760 / 1400）；
4 个：宽 360、间距 80（120 / 560 / 1000 / 1440）；5 个：宽 240、间距 120（120 / 480 / 840 / 1200 / 1560），
圆角都写宽度的一半，高都是 680（`top` 280）。窗里的字左右各收 40（宽 240 的窗放不下一段话，5 个时刻时只留标签和标题）。
一个时刻一页，第 2 到第 1 + n 页；结尾是第 2 + n 页。

**每一页都写全套**：整页的画、`.s-veil`、所有空窗、窗、页顶标题。空窗和压暗层每页同位置，原地不动；窗盖在空窗上面。

## 动效原则

样稿的转场计划（写在样稿开头的注释里）：

```
1→2  共享元素 + 翻面（画相同，只收不翻）   整页的窗收成第一格，空窗露出来，标题升到页顶
2→3  共享元素 + 翻面 + 原地替换           亮着的窗右移一格翻到正午，整页的画换成正午，字跟着窗走
3→4  同上                                 翻到黄昏
4→5  同上                                 翻到夜晚
5→6  共享元素 + 翻面（画相同，只撑开不翻） 夜晚那扇窗撑满整页
```

- **窗是翻面（`data-flip`），不是共享元素。** 内容换了的卡片配成 `data-id`，reveal 会把它当一样东西挪过去，中途两张画叠着；
  翻面让它压成一条线时换，换的那一刻看不见。
- **窗里的画写 `data-fill="slide"`，和整页的画是同一张。** 窗走过去时画反着挪，透过窗看到的始终是背后那片风景，翻过来的那一下只有光变了。
- **字不翻**，写 `data-flip-mode="fade"`：跟着窗走，前半程淡出、后半程淡入。和原片一样，字是独立的文本框。
- **整页的画和窗同时换、同时长**（都是 0.9 秒）：窗翻过来时背后已经是下一个时刻，不是先换窗再换天。
- **封面和结尾借翻面「内容一样就不翻」**：整页的窗收成一格、一格撑满整页，窗里的画不动，像镜头里的取景框在收放。时长 1.2 秒。
- 时长：翻一格 0.9 秒，收放 1.2 秒；停留封面 2 秒，每个时刻和结尾 2.5 秒。连续几次翻面是「顺序往前走」，同一个动作重复正是看点。

## 硬规则

- 窗写 `data-flip="window"` + `.s-window`，**不写 `data-id`**；每页一扇，都是页面的直接子元素。
- 窗里的画写 `<img data-fill="slide">`，不写位置；它和整页的画（`data-swap="bg"`，铺满画布）用同一张图。
- 窗、空窗、窗里的字都在安全区里（整页的窗除外）；空窗和窗同尺寸、同圆角，窗落定时正好盖住一个空窗。
- 窗上的字一律 `.t-on-glass`，放在窗的上半截（渐暗托字的那一段），不压到窗底下的画上。
- 一次只走一格，往右走。
- 样稿里的鸥屿海岸民宿、行程和钟点都是虚构的，四幅画是 AI 生成的，做同款时换成用户的东西。

## 自检

除了 `transitions.md` 末尾的通用自检，再看：

1. 每次翻面压成一条线的那一帧前后：窗里换了画，字没有镜像，窗里的画和背后的画对得上（地平线、岸线连成一条）。
2. 窗落定时正好盖住一个空窗，边上看不到空窗露出来的一圈。
3. 空窗里透出来的是**这一页**的画（模糊着），整页换画时它跟着变。
4. 封面收成第一格、最后一格撑满整页时，窗里的画一动不动，只有窗的边在走。
5. 最亮的那几张画（正午）上，窗里的字也读得清。
