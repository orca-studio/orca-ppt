# 产品参数介绍

手法：实拍接进参数墙

## 参考拆解

这是我们自己的样稿（一台 1937 年的桌面电话），看点是把**一段实拍素材**和**一面信息密集的参数墙**接成一条线，叠在三样东西上：

1. **视频末帧被接住**：整页视频播完停在拨号盘上，硬切到下一页时，拨号盘外圈的位置上正好是一个同样大小的椭圆。画面其余部分全换（实拍换成暗底文字页），观众的视线被那个圆钉住，不觉得断。视频里的圆只是像素，用一个看不见的框（`.s-anchor`）把它标成 DOM 锚。
2. **椭圆长成参数墙的主格**：同一个椭圆形态变换成 bento 密集版左上的 hero 格；椭圆里的数字「10」飞进右上那张「指孔」卡片。八张小卡按行分组上浮进场。
3. **聚光在墙上走**：参数墙一出现，一块压暗全屏、中间挖圆洞的幕布（`.s-spot`）淡入，洞正罩着刚飞进来的「10」。下一页墙上一个像素都不动，只有洞移到另一张卡上。
4. **钻进被聚光的那格**：洞停住的那张卡用「放大进元素内部」长成下一页的整页深灰底，里面是这条参数的细节（横向时间线）；时间线的轴最后收成结尾页中间的短横。

成立的原因是每一次翻页都有一个**观众一直盯着的东西**：拨号盘 → 椭圆 → hero 格 / 数字 → 光斑 → 被照亮的那格 → 轴 → 短横。实拍和参数这两类本来毫不相干的内容，就靠这条视线串起来。

全部用引擎现有的手法（遮挡剪辑、匹配剪辑、形态变换、共享元素、放大进元素内部）和现成的类（`.v-full` `.s-anchor` `.s-spot`），没有手写动画。

## 适用 / 不适用

| 适用 | 不适用 |
| --- | --- |
| 介绍**一件实物**（产品、器物、设备、建筑）：先看实拍，再看参数 | 没有实拍视频。用照片或插画代替，第一下匹配剪辑就没有「从实拍里接出来」的反差，换通用流程 |
| 视频**末帧里有一个轮廓清楚的形状**（表盘、镜头、按钮、轮子、窗口），能用一个椭圆、正圆或矩形框住 | 末帧是运动模糊、远景或没有主体的空镜。隐形锚量不出来，匹配剪辑对不上就是跳帧 |
| 正好 **1 个主角 + 8 条参数**（bento 密集版），每条参数是「标签 + 短值」 | 参数不足 6 条（格子撑不满，网格散）或超过 8 条（拆两页，或换别的版式）；参数是长句说明 |
| 参数里有 **1–3 条要单独强调** | 每条都同样重要。光斑没有理由停在某一格；超过 3 条要强调也不行，洞连续移动不超过 3 次 |
| 产品发布、器物介绍、设备讲解的开场段 | 纯数据汇报、流程、对比 —— 参数墙读不出量级和先后 |

## 内容槽位

| 槽位 | 从哪取 | 缺了怎么办 |
| --- | --- | --- |
| **一段实拍视频**（3–8 秒） | 用户给的素材 | **不编素材**、不拿无关视频凑。没有就停下来要。先按 `visual-spec.md`「整页视频」第 1 条转成 1920×1080 @30fps，并且确认末帧是静的 |
| **末帧里的锚形状** | 从视频末帧量 | `ffmpeg -sseof -0.1 -i clip.mp4 -frames:v 1 last.png` 导出末帧，按颜色框出外接框，量出 `left top width height`。**不许估** |
| **封面标题 + 一句副题** | 产品名、型号 | 标题默认用型号或产品名；副题只写用户给过的事实 |
| **形状页的一句话** | 锚形状对应的那个部件 | 默认写这个部件是什么、在整机里干什么；用户没给就只放部件名 |
| **形状里的数字** | 这个部件最有代表性的一个参数 | 必须是参数墙里某一格的值（下一页要飞进那一格）。没有合适的就不放数字，只让椭圆形态变换 |
| **主角（hero 格）** | 产品名 + 一句概述 | 概述只用参数墙里已经有的事实拼，不加卖点 |
| **8 条参数** | 用户给的规格 | **不编数据**。不够 8 条就按 `visual-spec.md` 的合并变体并格，或者用明显的占位（`—`）并在转场计划注释里写明 |
| **要聚光的格子**（1–3 个） | 用户最想让人记住的参数 | 默认第一格是形状里那个数字飞进去的格子，最后一格是下一页要钻进去讲细节的那条 |
| **细节页的 4 步**（横向时间线） | 最后被聚光那条参数背后的过程 | 每步「名字 + 时间点 + 一句话」。时间用户没给就写明「示意值」，不编成实测 |
| **结尾一句** | 下一期 / 下一步讲什么 | 默认「拆完了。」+ 一句预告 |

## 页面结构

七页，默认主题（只引 `runtime/tokens.css`，没有主题和配色文件）。根节点 `data-layout="standard"`。
坐标看样稿 `examples/spec-wall/index.html`（做同款时 create_deck 会复制它）；锚和椭圆的坐标换素材后要从新视频末帧重新量。

| 页 | 状态 | 关键元素 |
| --- | --- | --- |
| 1 封面 | 型号、一句副题、一条短横 | 无 |
| 2 整页视频 | 只有 `.v-full` 视频，不压任何字；加一个隐形锚 | `data-match="dial"` 的 `.s-anchor`，坐标从末帧量 |
| 3 形状页 | 和锚**完全同位置同大小**的椭圆（`.s-accent` + `border-radius:50%`），椭圆里一个数字（`.t-on-accent`）；标题、一句说明、编号 | 椭圆同时写 `data-match="dial"` 和 `data-id="hero"`；数字 `data-id="holes"` |
| 4 参数墙 | bento 密集版：hero 格 + 8 张小卡；最后一个元素是光斑 | `data-id="hero"`（hero 格）、`data-id="holes"`（「指孔」卡里的数字）、`data-id="spot"`（洞罩住「指孔」卡） |
| 5 同一面墙 | 和第 4 页**逐个元素完全一样**，只有光斑换位置 | `data-id="spot"`（洞移到「回转一圈」卡）；那张卡写 `data-zoom="spin"` |
| 6 细节页 | 横向时间线页：整页 `.s-surface` 底（`border-radius:0`，第一个子元素）、标题、4 站，一行 `.t-label` 注明示意值 | 写 `data-st="zoom-into" data-st-direction="in" data-st-from="spin"`；轴 `data-id="axis"` |
| 7 结尾 | 整页 `.s-surface` 底照抄第 6 页（原地不动）；居中一句结尾 + 一句副题，下面一条短横 | 短横 `data-id="axis"` |

- 形状页的椭圆用 `.s-accent`（亮橙），不用 `.s-accent-soft`：默认主题的 `.t-on-accent` 是深字，压在暗橙上读不出来。亮橙 → 暗橙是同色系，3→4 形态变换中途不发灰。
- 第 4 页小卡里的数字用 `.t-h1`、文字值用 `.t-h2`、标签 `.t-label .t-dim`，全部加 `.t-on-surface`；hero 格上的字加 `.t-on-accent`。密集版的字阶规则见 `visual-spec.md`「Bento 网格页」。
- 光斑是**正圆**，直径取卡片长边再大一点（样稿卡宽 360，洞 420），圆心对准卡片中心，放在 section 的最后一个。
- 第 5 页的元素不写 `data-auto-animate-delay`、`data-enter`，其余属性和文字照抄第 4 页 —— 这样它们会原地不动（多写一个 `data-zoom` 不影响）。
- 第 6、7 页压在整页深灰底上的字一律加 `.t-on-surface`。

## 动效原则

样稿的转场计划：

```
1→2  关系：换到实拍素材，没有视觉联系                     手法：遮挡剪辑（色块上扫）
2→3  关系：视频末帧里的拨号盘轮廓，被下一页的椭圆接住      手法：匹配剪辑            锚：dial（隐形锚）
3→4  关系：那个椭圆长成参数墙的 hero 格                    手法：形态变换            共享：hero
4→5  关系：同一面参数墙，光斑从「指孔」移到「回转一圈」     手法：共享元素            共享：spot
5→6  关系：被聚光的「回转一圈」那格是下一页的细节           手法：放大进元素内部      from：spin
6→7  关系：时间线的轴收成结尾页中间那条短横                 手法：形态变换            共享：axis
```

- **六次翻页五种手法**，没有连续两次同一类（共享元素和形态变换算同一类：3→4、4→5 是连着的两次，5→6 必须换成别的，所以钻进格子用放大进元素内部，6→7 再回到形态变换）。进视频用遮挡剪辑（`data-st="mask" data-st-direction="up"`），因为封面和实拍之间确实没有视觉联系；这是整份稿子唯一一次遮挡剪辑。
- **匹配剪辑只靠摆位**：引擎这一下不做动画，只校验锚（中心差 8px、宽高差 4% 以上报警告）。椭圆和隐形锚的坐标抄同一组数。锚上一般不写 `data-id`，否则 reveal 会补一段动画；第 3 页的椭圆带 `data-id="hero"` 是给下一次翻页用的，第 2 页没有同名元素，配不上对，这一刀仍然干净。视频页停留时长自动取视频长度，切走时画面就是静的末帧。
- **反差要大**：第 3 页除了椭圆，标题、正文、编号全是新的，底色从实拍换成纯色。只换一半，观众会以为卡住了。
- **形态变换用 1.2 秒**：椭圆变 hero 格尺寸接近翻倍、位移半屏，写 `data-auto-animate-duration="1.2"`。新元素的延迟按 1.2 秒那一行排：
  - 页标题 `0.8`（第一个新元素 ≈ 时长 × 2/3）；
  - hero 格上的两行字 `0.9`、`1.0`（紧挨着还在变形的 hero，≈ 时长 − 0.2）；
  - 8 张小卡按行成对进场：`0.98 → 1.06 → 1.14 → 1.22`，每组加 0.08，同一组的卡片、标签、数值共用一个延迟，最后一组不晚于 1.5。
  - 飞进卡片的数字（`holes`）是共享元素，不写延迟。
  - 光斑写 `data-auto-animate-delay="1.3"`：不写就按默认 0.6 秒亮，洞先亮、底下的卡片还没进场，洞里空着将近一秒。等第一行卡片和「10」落位再亮。
- **配对数量**：3→4 只配 `hero` 和 `holes` 两个，4→5 只配 `spot` 一个，6→7 只配 `axis` 一个，都在 1–4 个以内。参数墙的八张卡不配对，靠分组上浮进场 —— 它们不是「整组归位」（起点不在画外），不能一起写 `data-id`。
- **光斑第一次出现是淡入，不算共享元素**；移动的那一次，墙上其余元素一个都不动，观众只看到洞在走。洞全片同一尺寸，只移不缩；一份稿子里连续移动不超过 3 次。
- **钻进格子**：5→6 的 `data-zoom` 写在洞正罩着的那张卡上 —— 观众的视线已经被光斑带到那里，从那里钻进去最顺。细节页第一个子元素是整页 `.s-surface`，和那张卡同色，卡长满画面时颜色接得上。放大进元素内部默认 1.8 秒，不改短。
- **收尾**：6→7 时间线的轴（1680×4）形态变换成结尾短横（240×8），都是细长横条，长宽比同族；尺寸变化超过 3 倍，写 `data-auto-animate-duration="1.2"`，标题 `0.8`、副题 `1.0`。整页深灰底两页完全一样，原地不动。
- **停留**：视频页 `data-hold` 写成视频长度；信息多的形状页、参数墙和细节页写 3–3.5 秒，结尾 2.5 秒。

## 硬规则

- 视频页只放视频和隐形锚，不压字。
- 隐形锚的坐标从末帧量；形状页的椭圆和锚坐标一致。
- 匹配剪辑的锚形状里内容必须换掉（视频里是拨号盘，这里是纯色加数字）。
- 第 4、5 页除光斑外逐个元素一样；光斑尺寸不变。
- 一页最多一个 `.s-spot`，放在最后。
- 不编参数、不编素材。

## 自检

除了 `references/transitions.md` 末尾的通用自检，再看：

1. 2→3：把视频末帧和第 3 页第一帧叠起来，椭圆和拨号盘外圈重合；capture 的「页面报告的问题」里没有匹配剪辑的警告。
2. 3→4：椭圆是**连续长成** hero 格的，「10」是飞进卡片的，不是在新位置淡入。
3. 参数墙的八张卡按行分组出场，没有和还在变形的 hero 格叠在一起。
4. 光斑洞把目标卡整个罩住，洞沿的强调色描边看得见。
5. 4→5：除了光斑，画面上没有任何东西在动、在闪。
6. 3→4：光斑在第一行卡片和「10」落位之后才亮，洞里不空。
7. 5→6：是被聚光的那张卡在长大，不是别的格子；细节页的内容在卡的形状里显出来。

## 样稿

`examples/spec-wall/`：7 页（封面 → 整页视频 → 拨号盘 → 参数墙 → 光斑换格 → 钻进「回转一圈」的四步时间线 → 结尾），视频素材在 `examples/_assets/clips/dial.mp4`。

```bash
node scripts/check-deck.mjs examples/spec-wall/index.html
node scripts/capture.mjs examples/spec-wall/index.html
```
