# 窗口变形

样稿场景：新品发布短片。手法：窗口变形

## 参考拆解

参考是 Apple 视频号的一支笔记本电脑广告（45 秒）：整片几乎不切镜头，画面只从黑底上一扇斜切的不规则多边形里露出来。
看点只有一个：

> **窗口自己在变形。** 多边形的边移动、换形状，下一个镜头就在变形的途中从窗里出来 —— 观众盯着窗，不觉得换了页。

拆下来六样：

1. **黑底开窗**：四周纯黑，画面只在一个斜切的四边形里。
2. **窗口形变接力**：斜带 → 宽斜带 → 竖窗 → 斜窗 → 三角 → 斜窗 → 小框，一路不断。
3. **三角交错分屏**：正三角、倒三角交错拼成一排，每块一个人，逐块出现。
4. **斜置大标题**：压缩超粗的大字斜着排，贴着窗的一条边。
5. **卖点短句**：「更快的图形处理器」这类一句话，落在窗的下沿或贴着窗边竖排。
6. **收尾**：窗收成画面正中的产品，再出标题，最后只留品牌。

| 参考 | 这里 |
| --- | --- |
| 整片一扇窗 | 一个 `data-flip="win"` 的照片框，`data-flip-mode="cross"`，每页都有 |
| 窗的边在动、画面不动 | 框铺满画布（`0 0 1920 1080`），只改行内 `clip-path: polygon(…)` 的四个顶点：照片钉在画布上，窗在上面变形 |
| 下一个镜头从窗里出来 | 换了照片的框途中交叉淡化，和形变同一段时间 |
| 一排三角 | 五个框，正倒交错，各写四个点的三角（重一个点）；中间那块是 `win`，其余四块 `data-anim="fade …"` 错开出现 |
| 收成正中的产品 | 只有这一步改框的位置和大小：铺满 → `640 × 360` 居中 |
| 实拍视频 | 静帧。交叉淡化时视频会停在当前帧，所以窗里一律放照片 |
| 斜置大标题 | 一个 `.s-group` 包住字，组写 `rotate`；字本身不转 |

## 适用 / 不适用

| 适用 | 不适用 |
| --- | --- |
| 新品发布、品牌宣传、活动预告：几句卖点，每句配一个画面 | 要讲数据、讲流程的汇报：窗里放不下图表，斜着的字也读不了长句 |
| 有 6–10 张同一种调子的实拍（人、场景、产品），能撑满整页 | 截图、图表、白底产品图：黑底开窗靠照片自己的明暗，白底图开出来是一块白板 |
| 放映时一页停 2–3 秒、一路往下翻的短片节奏 | 讲者要在一页上停很久讲解：形变是看点，停久了就只剩一张斜裁的图 |

## 内容槽位

| 槽位 | 从哪取 | 缺了怎么办 |
| --- | --- | --- |
| **产品名** | brief | 第 2 页斜标题、第 9 页标题，一行 `.t-display`；西文全大写最像（Anton） |
| **副标题**（产品名下面那行，样稿是「搭载 O6 芯片」） | 用户的材料 | 6–10 个字，第 2 页 `.t-h1`、第 9 页 `.t-display` |
| **一句短句**（第 5 页，沿窗的下沿） | 用户的材料 | 8 个字左右；没有就删掉这一组，窗照样变形 |
| **品牌标记**（第 10 页） | 用户给的 logo，或系统 emoji | 样稿用系统 emoji 🫍（虎鲸，Emoji 17.0），`.t-display` 原尺寸。没有 logo 就放品牌名一行 `.t-display` |
| **三条卖点** | 用户的材料 | 每条拆成「小字引子 + 大字关键词」：「更快的」+「图形处理器」；关键词 6 个字以内 |
| **6–10 张实拍** | 用户给的 | 横幅，同一种调子（暖、胶片感）。没给就生成，写进转场计划注释；产品图要黑底 |
| **一排三角的 5 张**（可选） | 用户给的 | 同一种机位（样稿全是俯拍桌面），不然拼起来像拼贴 |

## 页面结构

样稿 10 页，笔记本 ORCA BOOK PRO（搭载 O6 芯片）的发布短片，品牌标记是 Orca 的虎鲸：

| 页 | win 的窗口 | 照片 | 字 |
| --- | --- | --- | --- |
| 1 产品 | 铺满整页 | 黑底上合着的电脑 | 无 |
| 2 开窗 | 横贯整页的斜带 | 用它的人 | 斜置大标题，贴着斜带的下沿 |
| 3 屏幕 | 斜带加宽，几乎占满 | 屏幕特写 | 「更快的 / 图形处理器」贴着下沿 |
| 4 人像 | 左右两边竖直、上下两边斜的竖窗 | 人像 | 无 |
| 5 斜窗 | 同样的斜窗，横过来 | 另一个用它的人 | 短句沿下沿 |
| 6 三角 | 中间那块正三角（框 `560 × 620`） | 俯拍桌面 ×5 | 底下「搭配上更快的 / AI 处理能力」 |
| 7 斜窗 | 同样的斜窗 | 深夜伸懒腰的人 | 「超长 / 持久续航」贴着下沿 |
| 8 产品 | 正中小框 `640 × 360` | 产品（同第 1 页） | 无 |
| 9 标题 | 无 | — | 产品名、一句定位 |
| 10 品牌 | 无 | — | 只留品牌标记（虎鲸 emoji 🫍，滤镜调成银色） |

**主斜角 -18°**：所有斜边都是 `y = c − 0.3249 · x` 这一族平行线（往右上走，和水平线成 18°），
其余的边只用水平、竖直；斜置的字一律 `rotate:-18deg`，贴在斜边外 40–80px。窗口的四个点就是两条斜线和两条竖线
（或画布左右两边）的交点，点可以落在画布外面。

三角一排：框宽 560、高 620，左边距 120，每块错开 280（正三角 `polygon(50% 0, 50% 0, calc(100% - 8px) 100%, 8px 100%)`，
倒三角 `polygon(8px 0, calc(100% - 8px) 0, 50% 100%, 50% 100%)`），留出 8px 的黑缝。

## 动效原则

样稿开头的注释里有转场计划。要点：

- **只有一扇窗在走。** 整份稿子一个 `win`，每一页都在（标题页、品牌页除外）。第二扇窗一出现，观众就不知道该看哪扇。
  三角那一页是唯一的例外：中间那块是 `win`，其余四块是它「分出来」的，下一页又收回去。
- **画面不动，窗动。** 框铺满画布，只改四个顶点。改框的位置和大小会让照片跟着缩放，像推拉镜头，不像开窗 ——
  只在要收成一个小东西（三角、产品）时才改。
- **每一页都换形状，也都换照片。** 形状没变只换图就是普通的淡入淡出；形状变了图没换，又没有「下一个镜头」。
- **四边形一律写四个点，三角写四个点、重一个。** 顶点数不同不插值，窗直接跳过去（`transitions.md`「共享元素」第 11 条）。
  前后两页顶点的顺序也要对得上（都从左上起顺时针），不然窗会拧成麻花。
- **整份只有一个斜角。** 窗口的斜边、斜标题、短句都是同一个角度、同一个方向（样稿 -18°）：斜边是一族平行线，字顺着它排，动起来也不乱。
  每页换的是斜线的位置和竖边的位置，不是角度。例外只有三角那一页：正三角、倒三角本来就是对称的两个角度。
- **字跟着窗的边走。** 贴在斜边外 40–80px；字不配对，翻页时淡出，新页的字晚 0.6–0.9 秒出来，等窗落定。
- 整份统一 1.2 秒；停留 2–3 秒，三角那页 4 秒（要等四块出完）。

## 硬规则

- 配色用纯黑底（`ember`，`--bg: #0a0a0b`）：窗以外一律是底色。产品图的黑底要和 `--bg` 一样黑，不一样就在框里看得出一块方形。
- 字只用 `.t-display` / `.t-h1` / `.t-h2`，不用 `.t-body`：短片里没有正文。
- 一页最多一组斜字。斜字和窗之间留缝，不压在窗里的人脸上。
- 样稿的 ORCA BOOK PRO、O6 芯片是虚构的，照片是 AI 生成的：做同款时换成用户的。
- 品牌标记放在黑底上要是浅色的：深色 logo 先做一个银色或白色版（保留透明底），不要直接贴上去。用 emoji 时写 `filter:grayscale(1) contrast(0.45) brightness(1.6)` 调成银色；emoji 的位图最大 160px，用 `.t-display`，放大就糊。

## 自检

除了 `transitions.md` 末尾的通用自检，再看：

1. 每次翻页的中间帧：窗的边在动、形状在变，两张照片在交叉淡化；没有一帧窗口先跳成新形状。
2. 窗口落定后，窗里露出的是照片的主体（人脸、屏幕、产品），没被斜边切掉。照片的主体偏了就左右镜像，或者挪窗。
3. 每一页的斜边、斜字都是 -18°（或你定的那个主斜角），没有第二个角度；斜字读得动，不出安全区。
4. 三角那一页：五块一样大、缝一样宽，四块是一块一块出来的。
