# 拼图形

样稿场景：活动照片汇报。手法：拼图形

## 参考拆解

参考是小红书「旁门左道PPT」《领导随手拍的丑图，PPT咋排才能倍有面儿...》，按照片张数教排版。原片自己说的关键是
**「学会拼图形」**：把照片装进形状里，再把形状拼起来。每种张数一页：

1. **1 张，笔刷叠图**：插一个大写字母 I，换成笔刷字体，复制几份叠在图上；先选图再选笔刷，合并形状「拆分」，
   删掉多余的部分，剩下的「结合」成一个形状。照片只从笔刷里露出来。
2. **2 张，开窗**：三维旋转，左图「透视向右」、右图「透视向左」，中间空出一大块放字。
3. **3 张，拼三角**：三角形叠在图上，合并形状「相交」；另两个三角形转 90°、180°，三块拼成一个整齐的长方形。
4. **4–6 张，三招**：
   - 错位：「裁剪为形状」选平行四边形，上下错开，后面垫色块；人物照抠出来叠在上面做破格；
   - 折卡片：三维旋转一左一右交替，相邻两张的边对齐；
   - 改弧度：照片从外到内一张比一张小，上下各压一个超大的渐变椭圆。
5. **7–9 张，网格**：参考线加一个小正方形量间距，格子间距一样宽。
6. **几十张，照片墙**：母版里放图片占位符，Ctrl 拖动 + F4 复制，新建页一键导入；上下两个椭圆压出弧形。

参考每种张数是一页孤立的静态排版。本同款把它们串成一份汇报：**每一页用几张图由场景定**，
一眼看得出为什么是这个张数（开场一张主图、前后对比两张、三个并列的对象三张……）。
九个照片框整份稿子是同一组，翻页时框换位置、换形状，框里的照片换成这一页场景的。

PowerPoint 的功能在这里的写法：

| 原片 | 这里 |
| --- | --- |
| 笔刷字体的 I「拆分 → 结合」 | 几道干刷画成一个 SVG，当照片的 `mask`（写成 `data:` 地址） |
| 合并形状「相交」、裁剪为形状 | `clip-path: polygon(…)`，统一写四个顶点（`transitions.md`「共享元素」第 11 条） |
| 三维旋转开窗 | `rotate: y 34deg`，透视写在页面上（`transitions.md`「共享元素」第 12 条） |
| 三维旋转折卡片 | 不用 3D：裁成一左一右的梯形首尾相接（见「动效原则」） |
| 参考线、母版占位符 | 不需要：坐标按网格算好写进页面 |

## 适用 / 不适用

| 适用 | 不适用 |
| --- | --- |
| 年度汇报、活动总结、门店 / 项目复盘：手上一堆现场照片，每段要配图 | 每张照片都要讲很多字：形状裁过的照片旁边只放得下一行标题和一两句话 |
| 每一段的照片张数不一样，而且张数本身有意思：一张主图、一组对比、一个流程、一个系列 | 每段都是一样多的照片：用不上「张数由场景定」，换普通内容页 |
| 照片本身不精彩，要靠排法撑场面 | 照片里有要看清的细节（产品参数、图表、文件截图）：三角、平行四边形、开窗都会裁掉、压扁一部分 |
| | 专门介绍团队成员：用「团队介绍」（`team-layouts`），一个人从头跟到尾 |
| | 要交 PPTX 的：笔刷、三角、开窗导出后都是图片，不能再改（`transitions.md`「导出 PPTX」） |

## 内容槽位

| 槽位 | 从哪取 | 缺了怎么办 |
| --- | --- | --- |
| **公司 / 活动名、年份**（封面小字） | brief | 写「XX · 2026 年度汇报」 |
| **每一段的场景**（页顶大标题）和**上一级**（页顶小字） | 用户的材料 | 大标题直接写场景：「改造前后」「获奖团队」，不写「第 N 站」「两张图」。小字写哪家店、哪条线 |
| **每段的照片** | 用户给的现场照片 | 按场景挑张数（见「页面结构」）。不生成假的现场照片冒充真实活动；缺图就少做那一页 |
| **人物照**（人物介绍那页） | 用户给的 | 要透明底抠图才能做破格。没有就不探出框，只放在平行四边形里。不生成假人 |
| **结论数字**（前后对比那页中间） | 用户的材料 | **不编**（`references/data.md`）：没有就只写一句结论，不放数字 |
| **每页的一两句话** | 用户的材料 | 写场景里的话（「旧仓库，变成一家咖啡店」），不写排版说明（「左边改造前，右边改造后」） |

## 页面结构

样稿 8 页，一家虚构咖啡连锁「禾屿咖啡」的 2026 年度汇报。每页用几张图由场景定：

| 页 | 张数 | 场景 | 排法 | 照片框的形状 |
| --- | --- | --- | --- | --- |
| 1 封面 | 1 | 新店开业：一张最有代表性的现场主图 | 左边标题，右边照片只从五道干刷里露出来 | `mask`（笔刷） |
| 2 | 2 | 改造前后：前后对比 | 开窗：两张左右镜像转向中间，中间一组字（小字、数字、一句话）；页面写 `perspective:1400px` | 长方形，`rotate: y ±34deg` |
| 3 | 3 | 三座城市的新店：三个并列的对象 | 三块三角形拼成一个长方形，城市名在下面 | 三角形（四个点，重一个） |
| 4 | 4 | 年度获奖团队：人物 | 平行四边形上下错开，后面垫两块色块；人物抠图站在框里，头探出框外，名字在框下 | 平行四边形 |
| 5 | 5 | 从生豆到你手里：一个流程的五步 | 折卡片：五张同宽首尾相接，步骤名在下面 | 梯形，一左一右 |
| 6 | 6 | 2026 新品系列：一个系列 | 改弧度：从外到内一张比一张矮，上下压两个渐变椭圆 | 长方形 |
| 7 | 9 | 这一年的花絮：分量一样的一堆 | 九宫格，左边放字 | 长方形 |
| 8 | 50 格 | 年度回顾：全年的照片 | 照片墙：九宫格那九张归位，其余补满；上下两个底色椭圆压出弧形 | 长方形 |

**场景和样稿不同时**：先按场景定张数，再从上表挑排法，用不到的页整页删掉。张数不用一页比一页多。坐标看样稿：

- 开窗：两张同尺寸（540 × 580），`left` 互为镜像（左 180，右 `1920 − 180 − 540`）。中间一组字和两张图的垂直中线对齐。
- 三角：长方形宽 1680，左右两块各占一半宽，中间那块占满宽、尖朝上。
- 平行四边形：宽 420、斜出去 100，下一张的 `left` 加 344（420 − 100 + 24 的缝），上下错开 80。
- 折卡片：卡宽 300、高 560，首尾相接；矮的那条边上下各收 9%。
- 九宫格：格子 344 × 264，间距 24。照片墙：10 × 5 格，156 × 116，间距 13。

## 动效原则

样稿的转场计划（写在样稿开头的注释里）：

```
1→2  共享元素               开场主图收成「改造前」那扇窗，改造后从右边转进来
2→3  共享元素               两扇窗放平，裁成三角形，三座城市的店拼成一块
3→4  共享元素               三角形变成平行四边形错开，获奖的人从框里探出来
4→5  共享元素（整组重排）    平行四边形变成梯形，首尾相接折成流程的五张卡片
5→6  共享元素（整组重排）    卡片放平，排成一道弧，换成六款新品
6→7  共享元素（整组重排）    弧放平成九宫格，换成九张花絮
7→8  共享元素（整组重排）    九宫格归位进照片墙，其余补满
```

- **照片框整份稿子同一个 `data-flip`（`s1`–`s9`），写 `data-flip-mode="cross"`。** 框跟着换位置、换形状、换转角，
  框里的照片换成这一页场景的，途中交叉淡化（`transitions.md`「翻面」第 3 条）。观众看到的是「同一组框换了一种拼法」，
  不是每页重新摆一遍，也不是第一帧硬换图。不写 `data-id`：内容不同，reveal 配成共享元素会第一帧就换图。
- **每页都写四个顶点的 `clip-path`。** 不要形状的那一页写满长方形，三角形重一个点。这样三角 → 平行四边形 → 梯形 → 长方形，
  形状跟着位置一起变；只有一页写的话，翻页一开始形状就跳过去了。
- **开窗用 3D 转角，折卡片用梯形。** 整页只有一个消失点（画布中心）：开窗的两张以中线镜像，转出来正好对称；
  折卡片五张排开，离中线远的卡会转得更窄，没法同宽对齐，所以改用裁剪画出折页。
- **笔刷不插值。** 1→2 翻页时笔刷直接撤掉，露出整张照片再收成窗。所以笔刷只放在封面。
- **整组同时动，新照片等整组落位再入场**（1.2 秒转场，新照片延迟 0.8，字 0.9 起）。人物抠图、名字最后出。
- 停留：每页 3 秒。

## 硬规则

- 照片框一律 `<img data-flip="s…" data-flip-mode="cross">`，不写 `data-id`，每页都写 `object-fit:cover` 和四个顶点的 `clip-path`。
- 笔刷遮罩用位图（PNG）写成 `data:` 地址放在 `mask` 里。写成 `url(art/…)` 时，用本地文件打开稿子（检查、导出）会被浏览器拦掉，照片整张消失；
  用 SVG 的话，转场里框每帧变尺寸，遮罩每帧都要重新栅格化，第一帧来不及会闪一下。
- 转过的照片，近的那条边会变大：安全区按转完的样子量。
- 照片墙补位的照片不写 `data-id`，用 `art/thumb/` 里 320 宽的缩略图：几十张原图同时第一次画出来，解码会让转场冻住几帧。
  不用九宫格那九张（墙上已经有归位的那九张）。
- 页面上只写场景文案，不写排版说明；不出现真实品牌、链接、二维码。
- 样稿的禾屿咖啡、门店、人名和「45 天」都是虚构的，照片是 AI 生成的，人像借自「团队介绍」样稿：做同款时一张也不留。

## 自检

除了 `transitions.md` 末尾的通用自检，再看：

1. 2→3、3→4、4→5 的中间帧：照片框的形状是边走边变的，不是一开始就跳成新形状。
2. 开窗页两张严格镜像：同宽同高，外侧边等长、内侧边等长；中间一组字不碰图。
3. 三角拼图的三块之间缝一样宽，拼起来是一个完整的长方形。
4. 折卡片五张同宽，相邻的边对齐、不互相盖住，步骤名都在卡片下面的空白里。
5. 文字不叠图、不叠文字，没有孤字成行。
6. 改弧度、照片墙页：上下椭圆压出来的弧左右对称，照片的上下边都被压到。

## 样稿

`index.html`：虚构的「禾屿咖啡 · 2026 年度汇报」，8 页，主题 Editorial Forest，配色 mist。
`art/` 里：
- 现场、门店、流程照片：codex-imagegen 生成。新品六张、花絮九张各是一张拼格图切出来的；改造后那张是拿改造前当参考图生成的，机位一样。
- `thumb/`：照片墙补位用的 320 × 240 缩略图。
- 四张人像：从 `team-layouts/people/` 拷来的。

```bash
node scripts/check-deck.mjs recipes/photo-layouts/index.html
node scripts/capture.mjs recipes/photo-layouts/index.html
```
