# 形状接力

样稿场景：演变故事。手法：一张照片接一张照片

## 参考拆解

这是故事稿的招牌手法，常见于讲「某样东西是怎么演变过来的」的短视频：

1. **一页一张整页照片**，左下角只有编号和名字，没有别的字。
2. **推近匹配**：镜头加速推近上一张照片里的某个形状（拨号盘的圆），推到画面正中、足够大的那一刻，
   切到下一张照片 —— 它的同一种形状（相机镜头的圆）也在正中、一样大，然后减速拉远。
   切点是整段运动最快的一帧，观众看不出是硬切，只看到「圆还在」。
3. **遮挡变形**：形状变了（圆变成方形屏幕）时，引导框填满颜色盖住画面，换照片后再缩成新的形状。

转场本身就是论据：观众自己看出「圆一直都在」，不用旁白说。

## 适用 / 不适用

| 适用 | 不适用 |
| --- | --- |
| 讲演变、讲历史：同一类东西的几代（电话 → 相机 → 电视、第一代到第五代产品） | 没有可用的照片，或者照片里找不到能前后呼应的形状 |
| 品牌故事：一个形状、一个元素贯穿始终（标志里的圆、产品上的某个部件） | 要讲数据、讲方案的内容 —— 用汇报稿 |
| 4 到 8 张照片 | 只有 2 到 3 张，撑不起「演变」 |

## 内容槽位

| 槽位 | 从哪取 | 缺了怎么办 |
| --- | --- | --- |
| **4–8 张照片**（同一类东西的不同阶段） | 用户提供 | 没有就停下来要，不要拿无关照片凑 |
| **每张照片上的锚点**（用来匹配的形状和它在原图里的坐标） | 用户提供，或者和用户确认 | **不要自己猜坐标**（`story-mode.md` 的规则）。不知道就告诉用户缺什么：哪张图、哪个形状 |
| **一个论点** | 用户想说的那一句（「屏幕越来越小，也越来越近」） | 从照片的共同点里提一句，写进转场计划的故事线，请用户确认 |
| **每页的编号和名字** | 照片里的东西 | 编号用 No.01、No.02 …；名字用那样东西的名称，不写形容词 |

## 页面结构

照着 `references/story-mode.md` 写，每页一个 `<section>`：

- 一张 `class="st-photo"` 的整页照片，写原图的 `width` `height` 和 `data-anchors`；
- `data-guide` 写这一页的锚点名（引导框常驻在它上面）；
- 左下角编号 `.t-body` 和名字 `.t-h1`，不放别的字。

坐标看样稿 `examples/story-circle/index.html`（做同款时 create_deck 会复制它）。

## 动效原则

转场计划就是故事线 —— 每次翻页的「关系」连起来读，应该就是这个论点：

```
1→2  关系：拨号盘和镜头都是圆，同位置同大小       手法：推近匹配   锚点：dial → lens
2→3  关系：镜头的圆又成了耳机罩                   手法：推近匹配   锚点：lens → earcup
3→4  关系：圆变成了屏幕                           手法：遮挡变形   锚点：earcup → screen
4→5  关系：手机的屏幕和电脑的屏幕，同位置同大小   手法：推近匹配   锚点：screen → screen
5→6  关系：屏幕越来越大                           手法：遮挡变形   锚点：screen → screen
```

- **形状相同用推近匹配，形状变了用遮挡变形**，不要反过来。
- **推近匹配至少占一半的翻页**，它是最有说服力的那一种。
- **不要连续两次遮挡变形**，中间至少隔一次推近匹配。
- 时长用默认值（推近匹配 1.8 秒、遮挡变形 1.4 秒），不要改短 —— 太快看不清切点。
- 锚点挑**中等大小**的（旋钮、镜头、按键），太大推不近，太小会糊；半径小于 40 的不要用。
- **在照片里太大的锚点（整块电视屏幕）只能用遮挡变形进来，而且只能放最后一页** —— 它推不出去。排顺序时先找出这种照片。

## 硬规则

- 故事稿里不用汇报稿的手法和 `.s-*` 形状类。
- 锚点坐标来自用户或经用户确认，不猜。
- 一页一张照片，文字只在左下角。

## 自检

除了 `references/transitions.md` 末尾的通用自检，再看：

1. 推近匹配的切点那一帧：前后两个锚点的轮廓重合，引导框没有跳。
2. 录制输出里没有「推近不够」「推近后会露出照片边缘」这两条警告；有的话按 `story-mode.md` 换锚点或换顺序。
3. 把每次翻页的「关系」连起来读一遍，是不是一句完整的论点。

论点是「圆一路传下来，最后变成越来越大的屏幕」。三次推近匹配、两次遮挡变形，交替排开。照片由 AI 生成。
