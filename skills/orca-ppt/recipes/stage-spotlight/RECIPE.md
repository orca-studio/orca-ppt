# 嘉宾介绍

手法：舞台射灯

## 参考拆解

参考是抖音 RonniePPT 的《射灯》：红底上一行黑色大字，字母 O 的字孔里填一个奶白色的圆当灯，
一束半透明的光从灯里斜着打下来，落在地上一块椭圆光斑上，光斑里站着一个黑色剪影。几样东西叠出来：

1. **灯**：一个圆，复制一份压扁成椭圆当地上的光斑，置于底层。
2. **光柱**：插一个平行四边形，编辑顶点拉成上窄下宽的光柱，调透明度。
3. **光里的字变色**：副标题复制一份，和光柱「合并形状 · 相交」，得到光柱里那几个字，换成底色叠回原位 —— 光扫过的字是红的。
4. **剪影**：插一张人像，抠图去背景，亮度调到 -100%，就成了纯黑剪影，站进光斑里。
5. **动画**：标题、副标题、人「飞入」，光柱「擦除」从灯口往下擦出来。

本同款把一页海报做成一份讲者介绍：四个人站成一排，灯每页转向一个人，光照到谁就介绍谁。

看点只有一个：

> **光照到谁，就讲谁。** 舞台不动，只有灯在转，观众的视线跟着光走。

## 适用 / 不适用

| 适用 | 不适用 |
| --- | --- |
| 讲者、嘉宾、获奖人、新成员的逐个介绍，3–5 个人 | 只有一个人：没有「灯转向下一个」，做成一页封面就够了 |
| 发布会、年会、分享会的开场和嘉宾页 | 每个人要讲一整页成就的：这里每人只有名字、一句话题目、一行介绍 |
| 标题里有一个 O（或圆形的字：0、Q、〇）能当灯 | 标题里没有圆形的字 —— 灯就没处放，换成普通封面 |
| 用户有每个人的全身照（剪影要看得出轮廓） | 只有半身证件照：剪影没有脚，站不进光斑；换「团队介绍」 |

## 内容槽位

| 槽位 | 从哪取 | 缺了怎么办 |
| --- | --- | --- |
| **标题**（带一个 O） | 活动名、品牌名 | 没有就用稿子的主题词（样稿用 `ON STAGE`）；用户的名字里没有 O 时先问能不能换个说法 |
| **讲者名单**（姓名、时间、一行介绍、一句话题目） | 用户给的议程 | **不编人名**，没给就写占位「讲者 1」并在转场计划注释里写明待补 |
| **每个人的全身照** | 用户给的照片 | 抠成透明底再用 `filter:brightness(0)` 压成剪影。**不为真实讲者生成人像**；缺照片就用一块 `.s-surface-2` 的竖条占位 |
| **封面那句话、结尾那句话** | brief | 自己补：封面吊胃口（「今晚，灯会照到谁？」），结尾把灯留给观众 |

## 页面结构

样稿 6 页：

| 页 | 灯照哪 | 在动的 |
| --- | --- | --- |
| 1 封面 | 来回找人，最后停在空地 | 标题、灯、副标题从右边飞入；灯亮，光柱从 O 里长出来落地（`data-light-grow`）；光在空台上往左、往右扫一遍找人 —— 台上还没有人 —— 最后停在一块空地上 |
| 2 第 1 位 | 1 号位 | 四个人从台下站上来，灯转向 1 号位，名字和题目出来 |
| 3–5 第 2–4 位 | 2–4 号位 | 灯转一格，名字和题目换掉 |
| 6 结尾 | 那块空地 | 四个人淡出，灯转回空地，留给下一个人 |

**人数不同时**：一个人一页，站位等距排开，`x = 起点 + 间距 × 序号`，间距不小于剪影宽度加 80。
光斑整份稿子只有一块（`data-id="spot"`），跟着光柱走。

**几何怎么算**（样稿开头的注释和下面这些就够了，坐标看样稿）：
- 灯在 O 的字孔中心。字孔位置要在浏览器里量（字体不同位置不同）：先把画布调成 1:1（`Reveal.configure({ margin: 0, minScale: 1, maxScale: 1 })`，不然 reveal 的缩放会让量出来的坐标偏十几像素），截图，量出 O 的字形框，再按像素找字孔。灯的直径约等于字孔宽，灯写在标题**前面**，O 的笔画压住灯的边，灯才像嵌在字孔里。
  标题**左对齐**，O 写在第一个字：右对齐或居中时，O 的位置取决于整串字的宽度，字体、字距稍有差别灯就偏出字孔。
- 地面是一条水平线（样稿 950）。被照的一层 `height` 写到地面，光柱在那里截住；光斑骑在地面线上（`top` = 地面 − 光斑高的一半）。
- 灯照向第 k 个人的角度：`a = atan2(x_k − 灯x, −(地面 − 灯y))`，换成度、取 0–360。光束是从枢轴点沿元素的「上方」射出去的，所以朝下是 180 左右。
- 光柱和地面的夹角别太小：灯和最远的人横向距离不超过竖向距离（偏角 ≤ 45°），否则光斑拉成一长条。标题放在离人群中心近的一侧。
- 灯转向写 `data-path`，关键帧按 `power2.inOut` 每 0.1 秒取一个样（`data-path` 的样条是匀速的，缓动靠关键帧的疏密）；**下一页第一个关键帧 = 上一页最后一个**。
- 横穿光柱的那行字（题目）放在灯和人头之间，整行居中，每一位的光柱都会扫过它。

## 动效原则

样稿的转场计划（写在样稿开头的注释里）：

```
1→2  共享元素（舞台不动）+ 页内动画  四个人站上来，灯转向 1 号位
2→3  同上                          灯从 1 号位转到 2 号位
3→4  同上                          灯从 2 号位转到 3 号位
4→5  同上                          灯从 3 号位转到 4 号位
5→6  同上                          四个人退场，灯转回空地
```

- **舞台不动，只有灯在转。**标题、灯、被照的一层、四个人都写 `data-id`，前后两页位置一样 —— 翻页时它们一动不动，
  动的只有灯（页内动画）。转场写 `data-auto-animate-duration="0.5"`，旧的文字淡出就够了，不要拖长。
- **光斑是完整的椭圆，不放进被照的那一层。**放进去会被光束的楔形裁掉两边，成了一块截断的梯形。
  光斑是光落在地上的地方，**要跟着光柱一起滑**，不能等灯停了再冒出来：它写 `data-light-spot="beam"`（和灯的 `data-light` 同键），
  引擎每一帧按灯的姿态算光轴和「过光斑中心的水平线」的交点，把它横着挪过去；光柱还没长到地面时它看不见，落地时淡进来。
  **光斑不写自己的路径**：两份关键帧迟早分家（静帧、缩略图、录制里一个停在上一个人脚下，一个已经转走）。
  光斑宽要比光柱落地的宽度大（样稿 300，四个站位光柱底宽 190–260），光柱的两条边才收在椭圆里。
- **先转灯，再出字。**名字和题目的 `data-anim` 从灯停下前 0.2 秒开始；光还在扫的时候出字，观众不知道该看哪。
- **光里的字是同一行字的两份。**原字写在被照的一层前面，层里抄一份换成 `color:var(--bg)`；两份的位置、`data-anim` 一字不差。
- **封面的光要「擦出来」，再「找人」**：`data-light-on` 等标题飞入落定（0.9 秒），`data-light-grow` 1 秒；
  落地后往左扫、往右扫、回到空地，每段之间停 0.15 秒 —— 台上没有人，观众会等着看灯最后照到谁。
- **退场写在离场的那一页上。**下一页不再有的人，在这一页写 `data-anim="out …"` 自己淡出。
- 停留：封面 1.5 秒（页内动画约 5.5 秒放完再停），讲者页 2.5 秒。

## 硬规则

- 灯（`data-light`）和被照的一层（`data-lit`）都是页面的直接子元素；被照的一层写在灯和标题**前面**。
- 灯每页都写 `data-path`，首个关键帧等于上一页的末帧，灯的 `style` 位置每页一样。
- 被照的一层只画到地面；光斑不写进这一层。
- 光斑写 `data-light-spot`，不写 `data-path`、不写 `data-anim`；它的 `style` 位置只定地面高度（`top`）和大小，横向位置全听引擎算。
- 剪影一律 `filter:brightness(0)`，同一个人整份稿子一张图、一个 `data-id`、一个站位。
- 不为真实讲者生成人像。样稿里的四个人是 AI 生成的虚构人物，做同款时一个也不许留。

## 自检

除了 `transitions.md` 末尾的通用自检，再看：

1. 封面：光柱从灯口往下长出来，落地的那一刻光斑亮起，不是整束一下子出现；之后光来回扫，光斑贴着光柱走，台上一直是空的。
2. 每次翻页：切页那一帧前后，灯的角度、光柱、光斑完全一样；之后灯才开始转，光斑全程贴着光柱的底，不落后、不跳。
3. 灯停下时，光斑正好在那个人脚下，是一个完整的椭圆，光柱两条边落在椭圆里；剪影的脚落在光斑中线附近。
4. 光扫过题目时，光里的字是红的、光外是黑的，两份字严丝合缝，没有重影。
5. 灯在 O 的字孔里，四周被 O 的笔画压住，没有压到笔画外面。

## 样稿

`index.html`：6 页（封面 → 四位讲者 → 结尾），主题 Neo-Grid，配色 stage（番茄红底、墨黑字、奶油色的光）。
四个人在 `people/`：AI 生成的虚构人物全身照，透明底，裁到人、缩到 900 高存成 WebP；剪影是页面里 `filter:brightness(0)` 压出来的，
换成用户的照片不用另做剪影。「OPEN TALK」和讲者都是虚构的。首页样片只录 1–3 页（封面亮灯找人 → 四人上台照第一个 → 转向第二个），
封面取第一位的名字出来之后。

```bash
node scripts/check-deck.mjs recipes/stage-spotlight/index.html
node scripts/capture.mjs recipes/stage-spotlight/index.html -o recipes/stage-spotlight/index.mp4
```
