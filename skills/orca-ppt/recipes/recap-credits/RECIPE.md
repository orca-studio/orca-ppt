# 项目收尾致谢

手法：电影级回顾片尾

## 参考拆解

参考视频在 PowerPoint 里做，四样东西叠出来：

1. **回顾片段**：除封面外的每一页设「平滑」切换，自动换片 0.7 秒，导出成视频。
2. **屏幕感**：把这段视频导回 PPT，三维旋转选「透视右」（左边缘近、右边缘远），加「映像」（底下倒影），黑底。
3. **片尾名单**：右侧「职责 · 姓名」两列，进入动画「字幕式」（从下往上滚出画面）。
4. **同时起播**：名单和视频都设「从上一项开始」，一起开始。

PPT 要绕「导出视频 → 再导回」这一圈，是因为它的一页没法引用其他页。
本 skill 的稿子是 HTML，结尾页直接把这份稿子自己嵌进来放，所以有三点比参考强：

- 回顾里是**真转场**（共享元素、形态变换现场播），不是压过一次的视频；
- 稿子改了，回顾跟着变，不用重导；
- 进入片尾的那一下也是连续运动：上一页整页缩小、倾斜，落进屏幕。参考里这一下是硬切。

## 适用 / 不适用

| 适用 | 不适用 |
| --- | --- |
| 有团队分工的汇报、毕业答辩、项目结项、课程作业 —— 有「幕后成员」可以谢 | 一个人做的稿子。名单只有一行，撑不起滚动，用普通结尾页 |
| 稿子里有 3 页以上**用了转场**的内容页 | 少于 3 页可回顾，或者内容页之间全是遮挡剪辑 —— 回顾里看不到连续运动，等于放幻灯片缩略图 |
| 结尾要情绪收束、要「电影感」 | 需要在结尾留联系方式、二维码、行动号召 —— 那是另一种结尾页，信息会被滚动名单抢走注意力 |

## 内容槽位

| 槽位 | 从哪取 | 缺了怎么办 |
| --- | --- | --- |
| **回顾范围**（`data-recap="起-止"`） | 稿子本身 | 默认第 2 页到倒数第 2 页（跳过封面和结尾页自己）。章节页多、内容页少时，可以只回顾内容最丰富的一段 |
| **名单**（职责 · 姓名） | 用户给的分工表、brief 里的团队信息 | 用户没给就**不要编人名**。写占位「职责 / 姓名」，并在转场计划注释里写明「名单待用户提供」 |
| **每页停留**（`data-recap-hold`） | — | 0.7 秒（参考的值）。回顾的页里有大段文字也不加长：回顾是让人认出来，不是让人重读 |
| **底色** | 主题 | 用整页 `.s-surface`。深色配色直接用 `--bg` 也行，参考就是黑底 |

## 页面结构

配方本身只有一页：稿子的最后一页。前面的页不用为它改任何东西 —— 但回顾放的就是它们，
所以整份稿子要先像样：被回顾的内容页至少 3 页，页与页之间用了不同手法（见「动效原则」）。

样稿是一份 8 页的季度复盘，演示「前面讲了什么、片尾怎么回顾到」：

| 页 | 内容 | 主角 |
| --- | --- | --- |
| 1 | 封面 | 整页绿底 |
| 2 | 目录：五个议题 | 绿色第 01 格（就是封面那块绿） |
| 3 | 01 数据页：五个季度的营收柱 | 整页绿底 + 粉柱 |
| 4 | 02 拐点：粉柱收成一张「Q3」粉卡 | 粉卡 |
| 5 | 03 现状：三张数字卡 | 第三张绿卡（最重要的数） |
| 6 | 04 路线：三张卡长成三级台阶 | 最高那级绿台阶 |
| 7 | 05 结论：一个大数字 | 整页绿底 |
| 8 | 回顾片尾：回顾 2–7 页 + 名单 | 回顾屏 |

回顾范围从目录开始、到结论结束：封面不放（回顾里第一眼就该是内容），结尾页自己不放。

片尾这一页三样东西：整页 `.s-surface` 底、`.s-recap` 屏幕（`data-recap` / `data-recap-hold`）、`ol.t-credits` 名单。
坐标看样稿 `index.html`（做同款时 create_deck 会复制它）。

- 屏幕宽高必须 16:9，否则回顾的页会留黑边。
- 名单条目行高 80，样稿的名单框放得下 10 条；更多也行，滚动会走完。
- 屏幕绕左边缘倾斜，右边缘往里退。名单放在右边，正好占住退出来的空间 —— 名单别放左边。
- 写在屏幕**前面**的元素是底，**后面**的在转场末尾依次淡入。标题之类（「感谢」「Credits」）想加就写在名单后面，用 `.t-label`。

## 动效原则

片尾这一次翻页在转场计划里写一行：

```
7→8  关系：结论页整页缩小、倾斜，落进回顾屏；回顾 2–7 页 + 名单   手法：回顾片尾（data-st="recap"）
```

样稿前面六次翻页是这样排的，回顾时观众会把它们按 0.7 秒一页再看一遍：

```
1→2  形态变换（整页绿 → 目录第 01 格）            共享：page
2→3  共享元素（第 01 格撑满，格子标题变页标题）     共享：page, topic1
3→4  多合一（五根粉柱收成一张粉卡，绿底不动）       合并：shift
4→5  遮挡剪辑 up（换话题：发生了什么 → 现在在哪）
5→6  形态变换（三张数字卡原地长成三级台阶）         共享：s1, s2, page
6→7  形态变换（最高那级绿台阶撑满成结论页）         共享：page
```

- **被回顾的那一段，手法要交替。** 回顾把每次翻页压到「转场 + 0.7 秒」，连着三次同一种手法，
  回顾里就是同一个动作放三遍。样稿里共享元素最多连两次，中间插多合一和遮挡剪辑，
  回顾时每一下的运动方向都不一样。遮挡剪辑整份最多 2 次，回顾里它是唯一一下「没有东西连过去」的，再多就碎。
- **一种颜色串一条线。** 样稿里的绿是同一块形状：封面整页 → 目录格 → 数据页整页 → 现状绿卡 → 绿台阶 → 结论整页。
  跨页变色只在同色系里（粉柱 → 粉卡；米色卡 → 米色台阶），回顾里也就没有一帧发灰的中间色。
- **共享元素一次配 1–4 个。** 5→6 配了三张卡，是上限以内；卡上的字不配对，换掉的字在 0.6–1.04 秒间依次上浮。

- **上一页就是回顾的「来处」**。屏幕缩小时里面放的还是上一页，落位后才切到回顾的第一页。
  所以上一页最好是一页收束的内容（结论、总结数字），观众看到的是「刚才那页缩进了屏幕，整份稿子开始倒带重放」。
- **回顾和名单一起放完。** 名单滚动的时长等于回顾的总时长（引擎自动算），名单最后一条落进框里时回顾刚好停在最后一页。
  不要给名单另设时长。
- **回顾里的转场就是正文里的转场**，节奏不另调。正文转场做得好，回顾自然好看；回顾看着乱，回去修正文。
- 录制时这一页的停留 = 回顾总时长 + 1.5 秒定格。`data-hold` 写得更长才按 `data-hold`。

## 硬规则

- 一份稿子只有一个回顾片尾，而且它就是结尾页（结尾页一份只有一个，见 `visual-spec.md`）。
- `data-recap` 的范围不许包含这一页自己。
- 屏幕里只放这份稿子自己的页。要放外部视频，用整页视频，不是这个配方。
- 名单不编人名。

## 自检

除了 `transitions.md` 末尾的通用自检，再看：

1. 转场第一帧和上一页最后一帧一样；屏幕缩小时里面是上一页，不是回顾的第一页。
2. 屏幕落位后才切到回顾，切的那一下只发生在屏幕里，屏幕外不动。
3. 回顾里每次翻页的连续运动都看得见，和正文放映时一样。
4. 名单滚动匀速，没有卡顿；回顾停在最后一页时，名单最后一条在框里读得出。
5. 倒影跟着屏幕一起倾斜，没有被裁掉。

## 样稿

`index.html`：8 页（封面 → 目录 → 数据页 → 拐点 → 现状 → 路线 → 结论 → 回顾片尾），主题 Editorial Forest，回顾 2–7 页。
回顾 6 页、5 次翻页，片尾这一页约 12 秒，名单 10 条刚好滚完。首页样片只录 6–8 页（台阶撑满成结论 → 落进回顾屏），封面取回顾放到台阶那页、名单滚到一半的那一帧。

```bash
node scripts/check-deck.mjs recipes/recap-credits/index.html
node scripts/capture.mjs recipes/recap-credits/index.html
```
