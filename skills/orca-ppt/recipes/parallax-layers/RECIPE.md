# 营地景区介绍

手法：分层视差

## 参考拆解

参考是抖音 RonniePPT 的《视差》：一张草原上两匹马的照片，复制几份分别抠图，叠成一个有纵深的画面，
再复制这一页、把各层挪到画布外，切换选「平滑」—— 翻页时整幅风景从下面升起来，近的层追上远的层。
四样东西叠出来：

1. **拆层**：原图复制四份 —— 底层是去掉马的整张图（天空和雪山），往上是只留林带和草地的一份、只留草地的一份，
   顶层是抠出来的两匹马。叠回去还是那张照片。
2. **字夹在层间**：标题放在倒数第二层（天空之上、林带之下），树梢和马挡住字的一部分；图标放在第三层。
   字被前景挡住，画面才「有纵深」，不是贴在照片上的一行字。
3. **按纵深挪**：复制这一页，各层挪到画布外，越近的层挪得越远。
4. **平滑**：两页之间切平滑，各层同一个时长走完不同的距离，近的层走得快 —— 视差就是这么来的。

原片只做了一次入画。本同款把同一个动作做成一整份稿子：入画、横摇、推近、抬头、复位，每次翻页都是一次「镜头运动」。

看点只有一个：

> **一张照片里，近的东西动得快，远的东西动得慢。** 观众看到的是镜头在走，不是图片在挪。

## 适用 / 不适用

| 适用 | 不适用 |
| --- | --- |
| 地点、目的地、营地、园区、楼盘介绍：有一张能拆出前中后景的风景照 | 室内照、产品照、人像特写：没有远近，拆不出层 |
| 开场、章节页、结尾：一份稿子里几页「看风景」的页 | 数据页、要密集读文字的页 —— 画面一直在动，字要放进面板里才读得动 |
| 品牌名、地名短（2–6 个字），能夹在层间 | 标题很长：夹在层间会被挡掉一半读不全 |

## 内容槽位

| 槽位 | 从哪取 | 缺了怎么办 |
| --- | --- | --- |
| **一张风景照**（有天空 / 远景、中景、近景） | 用户给的照片 | 只有一张整图时要抠图拆层（抠图工具、修图软件，或者用生图把各层分别生成成透明底，见「样稿」）。**真实地点不要用 AI 生成的风景冒充** |
| **前景主角**（马、人、车、建筑） | 照片里本来就有的 | 没有就只拆三层（天空、中景、前景地面），不硬加 |
| **地名 / 品牌名** | 用户给的 | 没有就用稿子的主题词 |
| **每一页的一段话**（在哪、有什么、什么时候） | 用户的内容 | 文案可以补；**日期、海拔、价格这类数字不编**，见 `references/data.md` |

## 页面结构

样稿 6 页，一个虚构的高山牧场营地：

| 页 | 镜头 | 各层怎么挪 | 文字 |
| --- | --- | --- | --- |
| 1 | 封面 | 四层在画面下方待命：天空压低 1530，标题 1560，林带 1600，草地 1840，马 2100 | 封面标题，页面底上 |
| 2 | 入画 | 全部升到位（1.6 秒） | 标题夹在雪山和林带之间，树梢挡住字脚 |
| 3 | 横摇 | 往左：天空 100，标题 200，林带 300，草地 340，马 360 | 右边空出来，放一块面板 |
| 4 | 推近 | 放大：天空 1.05 倍，林带 1.17，草地 1.33，马 1.5；标题退场 | 左上一块面板 |
| 5 | 抬头 | 往下：天空 100，林带 380，草地和马整个沉出画面 | 一块面板压在天上 |
| 6 | 复位 | 回到第 2 页的位置 | 标题位置换成结尾的一句话 |

**页数不同时**：入画（第 2 页）和复位（结尾）留着，中间的横摇、推近、抬头按内容挑，一种镜头一页，
内容多了可以再摇回去（往右摇），但同一个方向不要连摇三次。

**坐标怎么定**：
- 先摆好第 2 页（「家」的位置），其余页都从它算。远景层要比画布大（样稿天空 2304 宽），给横摇和抬头留余量：
  横摇最远那层挪多少，那层就要比画布宽出多少。
- 位移按纵深分档：天空 1 份、林带 3 份、草地 4 份左右，前景主角和草地差不多或再多一点。
  分档太平（都挪 300），看起来是整张图在平移，视差就没了。
- 比画布窄的前景主角每一页都要整个在安全区里，或者整个在画外 —— 只露半匹马 `check-deck` 会报。
- 标题夹在哪两层之间就写在 HTML 里的哪两层之间；它的 `top` 要让前一层（林带）刚好挡住字脚。

## 动效原则

样稿的转场计划（写在样稿开头的注释里）：

```
1→2  共享元素（分层视差·入画）  画面从画外升起来，近的层追上远的层
2→3  共享元素（分层视差·横摇）  镜头往右摇，右边空出来放营地信息
3→4  共享元素（分层视差·推近）  镜头推近到两匹马
4→5  共享元素（分层视差·抬头）  镜头抬头看天，草地和马沉出画面
5→6  共享元素（分层视差·复位）  镜头落回全景，标题位置换成结尾的一句话
```

- **一次翻页所有层一起配对**：用的是 `transitions.md`「共享元素」第 4 条的**分层视差**例外，不受 1–4 个的限制，三个条件都要满足。
- **同一个时长，不同的距离。**整页写一个 `data-auto-animate-duration`，层上不写延迟。
  视差来自「同样的时间走不同的路」—— 给近的层加延迟或者单独调时长，各层就不再是一个画面了。
- **时长按最远那层算**：入画最远的层走 2000 多像素，写 1.6 秒；横摇 1.2 秒；推近、抬头、复位 1.4 秒。
- **面板和文字等镜头停下再出**：`data-auto-animate-delay` 从 0.8–1.0 起，每个加 0.08。镜头在动的时候出字，字会跟着画面一起「漂」。
- **照片上的字放进面板**（`.s-surface` + `.t-on-surface`）。只有夹在层间的大标题直接压在照片上，而且它要压在照片里最安静的那一块（雪山、天空）。
- 停留：入画、复位 2.5 秒，有面板的页 3 秒。

## 硬规则

- 每一层整份稿子同一个 `data-id`、同一张图，`width` / `height` 按原图比例写，不压扁。
- 每次翻页所有层同向动，位移按纵深分档；同一页里不许有一层往反方向走。
- 层上不写 `data-auto-animate-delay`，也不单独写时长。
- 比画布窄的层要么整个在安全区里，要么整个在画外。
- 不用 AI 生成的风景冒充用户的真实地点。

## 自检

除了 `transitions.md` 末尾的通用自检，再看：

1. 按正常速度看入画：远的层先露出来，近的层后到、走得更快，最后同时落定 —— 看得出纵深，而不是一整张图往上推。
2. 每次镜头运动的中间帧，层与层之间没有露出页面底色（远景层不够大时，横摇和抬头会在边上露底）。
3. 夹在层间的标题，字脚被前一层挡住一点，但整个词读得出来。
4. 面板和文字是在镜头停下之后才出来的。

## 样稿

`index.html`：6 页（封面 → 入画 → 横摇 → 推近 → 抬头 → 复位），主题 Editorial Forest，配色 forest。
四层素材在 `art/`：天空雪山 `sky.jpg`，林带 `forest.webp`、草地 `meadow.webp`、马 `horses.webp` 是透明底，
都是用生图分别生成的（1536×1024，透明的层裁掉上方的空白），所以四层本来就对得上光线和色调；
「云岭牧场」和营地信息是虚构的。首页样片只录 1–3 页（封面 → 入画 → 横摇），封面取入画落定之后。

```bash
node scripts/check-deck.mjs recipes/parallax-layers/index.html
node scripts/capture.mjs recipes/parallax-layers/index.html
```
