# 门店指标对比

手法：百分比玻璃柱

## 参考拆解

参考是抖音 RonniePPT「设计灵感」的一条（PowerPoint 做的百分比柱状图）。几样东西叠出来：

1. **一个立体盒子**：一个菱形当顶面，两个平行四边形转 90° 当左右侧面（一个水平翻转），拼成一根等轴方柱。
2. **复制成三段**：同样宽，高度不同 —— 玻璃外壳（最高，代表 100%）、彩色数值段、白色底座。数值段的底正好落在底座顶面上。
3. **调颜色**：数值段左面深、右面中、顶面最亮；底座左面浅灰、右面白；外壳三面白色调透明，做出玻璃感，放在最上层。
4. **遮罩**：数值段加「飞入 · 自底部」，再画一块和背景同色的矩形盖住底座以下到页面底边，层次在数值段之上、底座之下 ——
   数值段飞上来时像是从底座里长出来。
5. **映像和阴影**：底座两个侧面加「映像」；底座下一个扁椭圆，深灰、柔化边缘、调透明，当落在地上的影子。
6. **五根一排**：橙、洋红、紫、青、绿，底座侧面写名字和百分比。放映时空柱子先依次进来，数值段再一根根升起。

本同款照这个做：方柱是 `.s-prism`（全用背景渐变画，宽 160、顶面菱形 160×40），数值段写 `data-anim="emerge"`
（飞入 + 遮罩做成一个效果：底边以下一直看不见，`transitions.md`「入场和强调」）。底座拆成前后两半夹住数值段，
代替参考里那块和背景同色的遮罩矩形 —— 背景不是纯色时遮罩矩形就露馅了。

看点：

> **一排空玻璃柱先立好，彩色的数一根接一根从底座里升上来。** 换一组数时柱子不动，数值段原地长高或落下，数字逐位滚到新的数。

和「季度数据报告」（`cobalt-grid`，平面柱子从坐标轴上长出来）的区别：那里是一条线变成图表；这里每根柱子是一个立体的容器，满格看得见，读的是「装了多满」。

## 适用 / 不适用

| 适用 | 不适用 |
| --- | --- |
| 4–6 个并列对象的同一个指标，都是 0–100% 的占比、完成度、满意度 | 绝对数（营收、人数）：玻璃外壳代表 100%，绝对数没有「满格」，换 `data-report` 或 `cobalt-grid` |
| 同一组对象换几个指标、几个季度对比（柱子不动，数在变） | 一个对象的时间序列（十二个月）：柱子太多，立体柱一排放不下，换折线 |
| 每个对象的名字 2–4 个字（写在底座左面，竖排） | 名字很长：底座侧面只有 80 宽 |
| 数据来自用户的表格 | 没有数：**数字一律不编**（`references/data.md`），没有就停下来要 |
| 深底、中灰底都行：样稿用深藏青（abyss），浅一点换 pewter；底座上的店名用 `.t-on-surface`，两种底都读得清 | 浅色、白底：白底座和玻璃外壳会糊进背景里 |
| 要交 PPTX：柱子导成图片，换页时平滑能把高度挪过去 | 要求 PPTX 里也有升起动画：PPTX 里是放完的样子（`transitions.md`「导出 PPTX」） |

## 内容槽位

| 槽位 | 从哪取 | 缺了怎么办 |
| --- | --- | --- |
| **封面标题、副标题** | brief | 「五家店成绩单」；副标题列这份稿子比哪几个指标 |
| **对象名**，4–6 个 | 用户的表格 | 不编。写在底座左面，竖排 |
| **每个指标一页**：标题 + 一行口径（数据从哪来、怎么算） | 用户的表格 | 口径不写就是没出处，按 `data.md` 补；标题写指标名：「一季度目标完成度」 |
| **每页的百分比** | 用户的表格 | 不编；取整数 |
| **下半年的目标**（结尾页） | 用户的材料 | 结尾不写「谢谢」「下半年见」，写往前看的目标：柱子一起长到目标值，一条虚线目标线（`.l-accent`，`data-anim="wipe left"`）画过去。目标数也不编，用户没给就停下来要 |

## 页面结构

样稿 6 页：封面（五根柱子挨着站在右半边，数值依次升起）→ 一季度完成度（柱子散开排成图表）→ 二季度完成度（原地长高）→ 满意度（换指标，重新升起）→ 复购率（原地落下）→ 下半年目标（一起长到目标，画一条目标线）。

**柱子的坐标是定的，换数只算数值段**：

- 五根：`left` 240 / 560 / 880 / 1200 / 1520，宽 160，间距 160。封面挨着站：`left` 840 / 1040 / 1240 / 1440 / 1640（间距 40），标题两行 `.t-display` 放左边。四根：`left` 400 / 720 / 1040 / 1360；六根：间距 120，`left` 180 / 460 / 740 / 1020 / 1300 / 1580，影子改成 `left: 柱 − 40`（不然第一根的影子出安全区）。
- 玻璃外壳 `top:240 height:600`；底座两半都是 `top:640 height:200`；影子 `left: 柱 − 80, top:808, 240×64`。
- 数值段：侧面高 = 400 × 百分比 / 100（取整），元素高 = 侧面高 + 40，`top` = 680 − 元素高。满格（100%）正好顶到外壳的顶面。
- 名字：`left: 柱 + 24, top:704, width:32`，竖排，`skewY(14deg)`；数字：`left: 柱 + 80, top:706, width:80`，`skewY(-14deg)`；`%` 在数字下面 `top:764`。

**一个指标一页**。同一个指标换季度：数值段写同一个 `data-id`（共享元素，原地长高），数字写同一个 `data-text` + `data-roll`（逐位滚）。
换指标：数值段换一组 `data-id`（上一页的淡掉，这一页的重新 `emerge`），数字照样逐位滚。

## 动效原则

样稿的转场计划（写在样稿开头的注释里）：

```
封面  五根玻璃柱挨着站在右半边，数值从底座里依次升起，一根比一根高   页内动画（升起）
1→2  五根柱子往左散开排成图表，数值落到一季度的高度               共享元素（sh / bb / bf / gl / q 1–5）
2→3  同一组柱子，换成二季度的数：数值段原地长高，数字逐位滚       共享元素（q1–q5）+ 文字级匹配（逐位滚轮）
3→4  换一个指标：旧的数值淡掉，新的一组重新升起                   页内动画（升起）+ 文字级匹配
4→5  同一组柱子，换成复购率：数值段原地落下                       共享元素（s1–s5）+ 文字级匹配
5→6  同一组柱子一起长到下半年的目标，目标线从左往右画过去       共享元素（s1–s5）+ 文字级匹配 + 页内动画（擦除）
```

- **封面就是主角**：五根柱子挨着站在右半边，玻璃外壳和底座先在，数值 0.2 秒起 `emerge .8s` 依次升起（每根错开 0.15 秒），排成一级级台阶。
  参考就是这个顺序：先看到「满格是多少」，再看「装了多少」。封面只有字的话，第一眼什么都没有。
- **封面到正文是同一组柱子散开**：柱子的每一层（影子 sh、底座 bb、前一半 bf、玻璃 gl、数值 q）都写 `data-id`，转场 1.2 秒往左散开排成图表，
  数值同时落到一季度的高度；底座侧面的名字和数字等柱子落定再淡入（`fade`，每根错开 0.08 秒）。
- **升起的底边就是底座顶面的前角**：数值段的底边写在 y=680，`emerge` 把底边以下裁掉；底座的前一半（`.is-open`）写在数值段后面，盖住升起时露出来的两个底角。
- **换季度用共享元素，不用重新升起**：同一个对象的同一个指标，前后两页是「同一根柱子变高了」，原地长比落回去再升起更读得出变化。转场 1.2 秒。
- **换指标才重新升起**：数的意思变了，旧的淡掉（0.35 秒），新的从底座里重新升起，转场写 `data-auto-animate-duration="0.6"`，新的尽快开始。
- 停留：封面 2 秒；第一次进场 3.5 秒；原地变化 3 秒。

## 硬规则

- 数值段只写 `.s-prism`，颜色写 `--prism:var(--cat-n)`，一根柱子从头到尾同一个颜色；底座上的数字写 `.t-prism` + 同一个 `--prism`。
- 叠放顺序不能乱：影子 → 底座（带顶面）→ 数值 → 底座前一半 → 字 → 玻璃。
- 柱子的每一层每页写同一个 `data-id`（sh / bb / bf / gl + 序号），正文页之间位置不变就原地不动。影子统一写在所有柱子前面：柱子挨着站时，后一根的影子不会盖到前一根的底座。
- 底座侧面的字用 `fade`，不用 `fly` / `rise`：它们靠 `transform` 斜着贴在侧面上，会被位移动画盖掉。
- 数字一律来自用户的数据；样稿里的青柚茶饮、五家门店和全部数字都是虚构的。

## 自检

除了 `transitions.md` 末尾的通用自检，再看：

1. 升起时数值段的底一直贴着底座顶面，底座下面、两侧看不到彩色。
2. 落定时数值段顶面在外壳里面，满格的那根正好顶到外壳顶面，不冒出去。
3. 底座侧面的字顺着侧面斜，数字颜色和柱子一致、读得清。
4. 原地长高时数值段的底不动，只有顶在走；数字滚动中途变了的位上下各露半个字。
5. 影子和倒影是淡的，不抢柱子。
