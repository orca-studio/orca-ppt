# 竞选自我介绍

手法：吊灯点亮

## 参考拆解

参考是小红书「皮皮踢ppt」的《3D 灯 + 平滑》教程：黑底上吊着一盏 3D 灯，一整套团支书竞选介绍只用 PowerPoint 的「平滑」切换。
几样东西叠出来：

1. **灯**：PowerPoint 自带的 3D 模型。每页只改它的位置和角度，平滑会让它转过去、抬起来。
2. **开灯、关灯**：两页素材一模一样，关灯那页的字透明度调到 86% 左右，开灯那页调回 0%。
3. **光圈**：一个偏白的圆，加柔化边缘、调透明度。上一页小，下一页拉大，跟着灯指的方向挪。
4. **进出场**：下一页的内容提前放在画面外的下方，平滑时升上来；讲完的推出画面上方。

本同款把「开灯字变亮」推进一步：**光照到哪，哪里才看得见**。东西放在被照亮的那一层（`.s-lit`）里，
光圈里显形、光圈外只剩余光；灯一转，看得见的地方就跟着光挪过去。灯是一张透明底的实物图，挂在吊线下面绕吊点转，
光束、光圈由引擎按灯的姿态算（`transitions.md`「吊灯」）。
结构和口吻照原视频的自我介绍：基础信息 / 个人技能 / 兴趣爱好 / 竞选宣言，中文标题下面一行英文，正文第一人称（「大家好，我是……」）。
每一章的光里照一件和这一章有关的**物件**（样稿：学生证、笔记本和钢笔、胶片相机、扩音喇叭）。光里有实物，画面就不空；讲的还是这个人。

看点：

> **黑屋子里，光照到哪，哪里才看得见。** 每讲一章，灯换一种动作去照亮下一件物件：摆过去、关灯换位、降下来、反向大摆。

和「嘉宾介绍」（`stage-spotlight`，舞台射灯）的区别：射灯钉在标题的 O 里不动，光柱扫过一排人，适合逐个介绍几位讲者；
吊灯自己会摆、会升降、会关了再开，一个人用几件物件把自己讲清楚。

## 适用 / 不适用

| 适用 | 不适用 |
| --- | --- |
| 竞选、求职自我介绍、述职：3–5 章，每章能找到一件相关的物件 | 要点是数据、图表的汇报：光照着一件物件说不清数，换「经营数据汇报」 |
| 产品线、一套器具、作品集（变种 `product.html`）：每件一张实物照 | 要点抽象到找不到物件的（「格局」「赋能」）：硬配物件观众看不懂，换「价值观宣讲」 |
| 物件照能拍成（或生成成）黑底顶光：光圈里显形最自然 | 白底电商图、生活场景图：背景本身是亮的，光圈显不出来 |
| 能用深底配色（`midnight`、`neon-night`、`amber`） | 要求浅底：暖白的光在浅底上看不见 |
| 关着灯开场有悬念：上台第一句话之前的那一秒 | 要交 PPTX 再改的：灯不会绕吊点转，被照亮那一层的遮罩导不出来（`transitions.md`「导出 PPTX」） |

## 内容槽位

| 槽位 | 从哪取 | 缺了怎么办 |
| --- | --- | --- |
| **标题、副标题**（封面） | brief | 标题写场合（「学生会主席竞选」「2026 年度述职」）；副标题写「姓名 · 身份」。**不编人名**，没给就写占位并在注释里写明待补 |
| **3–5 章**，每章一个四字中文标题、一行英文、一两句第一人称的话、一件物件 | 用户的材料 | 没给结构就用原视频那套：基础信息 / 个人技能 / 兴趣爱好 / 竞选宣言（求职换成「求职意向」，述职换成「明年计划」）。物件跟着这一章的内容挑，一眼看得懂（身份 → 学生证、工牌；写作和策划 → 笔记本；爱好 → 相机、球拍、乐器；宣言 → 扩音喇叭）。**数字不编** |
| **每件物件的照片** | 用户的照片，或生成 | **默认生成透明底的物件图**（codex-imagegen，`--background transparent`；不行就绿幕再抠），只要物件本身，不要地面、阴影和光晕，四件用同一段打光描述。**别拿黑底照片按亮度抠**：阴影和哑光黑亮度差不多，抠出来在光圈里是一块块暗斑。产品展示时用用户的产品图，抠成透明底 |
| **灯** | 样稿的 `art/lamp.webp` | 直接用；品牌要换灯型时生成一张透明底的吊灯图（正面略仰视、灯罩口能看见灯泡），量出罩口高度写 `data-mouth` |
| **结尾那句话** | brief | 自己补：竞选写「谢谢观看，请投我一票」，述职写一句承诺；配四件物件回到一排 |

## 页面结构

样稿 7 页：

| 页 | 灯 | 在动的 |
| --- | --- | --- |
| 1 封面 | 正中朝下；`data-lamp-on="0.6"`：进页关着，0.6 秒后自己亮起来 | 先只剩余光，灯一亮，光圈里显出标题 |
| 2 一排 | 收上去（`len` 变短），光圈放大（`pool` 1100） | 标题推出画面上方；四件东西从下面升上来排成一排 |
| 3 第 1 件 | 摆过去：吊点不动，`angle` 往左 | 这一件放大到左栏，其余三件沉下去；说明文字从下面升到右栏 |
| 4 第 2 件 | 关灯换位：`data-lamp-via="dark"`，吊点挪到右边 | 黑着的时候上一件沉下去、这一件升上来 |
| 5 第 3 件 | 降下来：`len` 加长 | 灯凑到这一件头顶，像凑近了看（东西不放大：放大了会顶到灯罩） |
| 6 第 4 件 | 反向大摆：吊点在右，`angle` 一路摆到左边 | 这一件从左栏正下方升上来 |
| 7 结尾 | 回到正中，收上去，光圈放大 | 四件回到一排，结尾那句话在光里 |

**件数不同时**：一件一页，第 3 到第 2 + n 页。一排的位置用四栏网格（`left` 120 / 560 / 1000 / 1440，3 件三等分，5 件收到 300 宽）。
每件东西在它那一章放大的位置（样稿 640×640，左栏 `left` 200 或右栏 1040）记下来；**不讲的那几件在画面下方、自己放大位置的正下方待命**（`top` 1200），
轮到它时竖直升上来 —— 待在一排的位置会斜着飞过来，穿过说明文字。灯的四种动作按顺序轮着用，件数多于 4 时从头再来，相邻两次不重复。

**灯照哪怎么算**（样稿就是这么生成的）：
- 灯轴就是「吊点 → 目标中心」的方向：`angle = atan2(吊点x − 目标x, 目标y − 吊点y)`，换成度。
- `reach = 吊点到目标的距离 − (len + 灯图高 × data-mouth)`。样稿灯图显示成 320×210，`data-mouth` 0.81。
- 吊点 `y` 写 -40（天花板在画面上方一点），`len` 平时 140，收上去 100，降下来 200。
- 照一整排时写 `pool`（样稿 1100），否则两头的东西在光圈外。

## 动效原则

样稿的转场计划（写在样稿开头的注释里）：

```
1     页内动画  进页关着灯，0.6 秒后自己亮起来
1→2  共享元素  封面让位给一排物件：标题出画、物件入画、灯收上去
2→3  共享元素  摆过去：第一件放大，其余沉下去
3→4  共享元素  关灯换位：上一章出画、这一章入画
4→5  共享元素  降下来：灯凑近第三件
5→6  共享元素  反向大摆
6→7  共享元素  灯回正中，四件回到一排
```

- **翻页只用共享元素**，和参考一样「只用平滑」。灯、被照亮的那一层、照片、说明文字全写 `data-id`。
- **开灯不单独占一页。** 参考里关灯、开灯是两页一模一样的素材；网页里写成封面的页内动画（`data-lamp-on`），放映时不用多按一次，开场那一下还在。
- **四次换件，灯的动作各不相同。** 同一个动作重复四次，第二次以后就没有新东西了。关灯换位最省事：东西在黑暗里换位置，观众看不见搬动。
- **说明文字不进光里。** 光负责让东西显出来；字放在 `.s-lit` 外面，整组从画面下方升上来、讲完推出画面上方，一直读得清。
- 时长：转场 1.2 秒，关灯换位和反向大摆 1.4 秒（灯要走的路长）；停留封面 2 秒（开灯放完再停）、一排 2 秒、每件和结尾 2.5 秒。

## 硬规则

- 灯（`.s-lamp`）和被照亮的那一层（`.s-lit`）都是页面的直接子元素，每页都写，各自同一个 `data-id`，每页都是共享元素页。一页一盏灯。
- 每页的光圈落在这一页要讲的那件东西上（按上面的算法算），不是随手摆个角度。
- `.s-lit` 里的东西都写 `data-id`；不在这一页的放在画面外待命，**完全出画**。
- 照片是透明底（黑底转透明），不带方块边。
- 只用深底配色。
- 样稿里的林一、竞选内容和 DARKROOM 都是虚构的，照片和灯是 AI 生成的，做同款时换成用户的东西。

## 自检

除了 `transitions.md` 末尾的通用自检，再看：

1. 封面：进页先暗着，灯亮起来时只有灯和光在变，别的一个像素都没动。
2. 每一页停下来时，光圈落在这一件东西上，它是整页最亮的地方；说明文字在光外也读得清。
3. 四次换件，灯的动作各不相同；关灯换位时，东西的搬动全在黑暗里。
4. 灯摆动时绕的是吊点：吊线跟着转，灯不会脱离吊线。
5. 照片贴在深底上看不出方块边，哑光黑的地方没有被抠穿。

## 样稿

两份样稿，同一套版式和灯的动作，只换内容。**默认是竞选**（首页展示、`create_deck` 的 `from: "recipe:pendant-lamp"` 复制的就是它）；
用户要介绍的是一套产品时，从 `product.html` 起头：

| 样稿 | 讲什么 | 光里照的 |
| --- | --- | --- |
| `index.html` 竞选（默认） | 学生会主席竞选的自我介绍：基础信息 / 个人技能 / 兴趣爱好 / 竞选宣言，中英双语标题、第一人称 | 学生证、笔记本和钢笔、胶片相机、扩音喇叭 |
| `product.html` 产品展示 | 一套手冲器具：DARKROOM 手冲套装 | 磨豆机、手冲壶、滤杯、咖啡杯（产品本身） |

都是 7 页（封面开灯 → 一排 → 四件 → 结尾），无主题，配色 midnight，共用 `art/lamp.webp`。
`art/` 里的灯和八件物件都是 codex-imagegen 直接生成的透明底图（顶光打亮物件本身，不带地面和阴影），四周留了一点边。
首页样片只录竞选那份的 1–3 页（开灯 → 一排 → 摆向第一件），封面取开灯之后。

```bash
node scripts/check-deck.mjs recipes/pendant-lamp/index.html recipes/pendant-lamp/product.html
node scripts/capture.mjs recipes/pendant-lamp/index.html -o recipes/pendant-lamp/index.mp4
```
