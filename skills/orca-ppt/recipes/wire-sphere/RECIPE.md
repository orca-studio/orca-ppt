# 三维旋转

样稿场景：一年十二个月（年度回顾）。手法：线框球（3D 转角插值）

## 参考拆解

参考是抖音 RonniePPT《三维旋转》（PowerPoint 做的线框球）：

1. **一个圆，无填充**，只留一圈细线。
2. **复制 12 份，每份调三维旋转**：第一个 X 轴 175°、Y 轴 40°、Z 轴 20°，后面每个 X 轴减 15°。十二个圆同一个圆心，叠出一个线框球。
3. **居中对齐，两边加字**：十条内容左五条、右五条，围着球。
4. **复制这一页，把所有圆的旋转都改成 1，文字移到画布外**，切换选「平滑」：十二个圆从一个平面圆转开成球，或者从球合拢成一个圆。

原片的球只是装饰，十二个圆没有含义。本同款给它一个：**十二个圆就是十二个月**，整个球是一年。
每页写不同的 3D 转角（`rotate`），引擎在两页之间逐帧插值。

看点：

> **大标题缩到顶上，十二个圆排成一页日历，一个圆写一个月；翻一页，十二个圆一个接一个飞到一起、各自转开，叠成一个球。**
> 之后翻一页球转一下，这一季的三个圆亮起来；最后十二个圆一起变成强调色、放平，叠成一个圆。

日历飞成球那一步就是原片的「居中对齐」：PowerPoint 里是操作过程，这里做成了转场。

## 适用 / 不适用

| 适用 | 不适用 |
| --- | --- |
| 年度回顾、全年总结：每个月都有一件拿得出手的事 | 只有三五件大事：凑满十二个月会很虚，换「大事记年表」（`digit-roll`） |
| 按季度讲：一季一页，每页三个月 | 要讲很多数据、图表：每个月只有一个标题一句话，数据换「经营数据汇报」 |
| 结尾落在一个全年的数上：多少场活动、多少位读者 | 回顾加明年规划：这里只往回看，要规划换「年度回顾与规划」（`forest-timeline`） |
| | 要交 PPTX 还要动画：导出后每页是放完的样子，转角的过渡导不出来（`transitions.md`「导出 PPTX」） |

## 内容槽位

| 槽位 | 从哪取 | 缺了怎么办 |
| --- | --- | --- |
| **公司 / 团队名、年份**（封面小字） | brief | 写「XX · 2026 年度回顾」 |
| **封面标题** | brief | 「XX 的 2026」，一行十个字以内；日历页顶上那行小字就是它 |
| **成球那页的一句话** | brief | 四个字左右，说十二个月合成一年：「叠成一年」 |

| **每季的名字** | 自己概括 | 四个字以内，写这一季的势头：「安顿下来」「人多起来」 |
| **全年的数**（结尾圆里） | 用户的材料 | **不编**（`references/data.md`）：没有就写一句话收尾，不放数字 |

## 页面结构

样稿 9 页：

| 页 | 内容 | 球 |
| --- | --- | --- |
| 1 封面 | 一行大标题「鹿鸣书店的 2026」，下面一行小字 | 没有 |
| 2 日历 | 大标题缩成顶上一行小字（`data-id="title"`）；十二个圆排成两行（每行六个），一个接一个浮上来，圈里写月份 | 还没成球：每个圆放平，直径 240 |
| 3 成球 | 左边一句「叠成一年」（等球成形后 1.8 秒才出来），右边球 | 十二个圆一个接一个飞过来（每个晚 0.05 秒），转到自己的角度，叠成球，圆心 (1320, 540) |
| 4 全年 | 十二个月左六右六，每条月份 + 标题 | 挪到中间 (960, 540)，自转 30° |
| 5–8 四个季度 | 右边季度名 + 这一季的三个月（标题 + 一句话），从全年那页移过来 | 收到左边 (560, 540)，每页自转 45°，这一季的三个圆加粗，其余暗下去 |
| 9 结尾 | 圆里写全年的数 | 回到中间，十二个圆一起变成强调色、放平，叠成一个圆 |

坐标：

- **一个圆三层**：外层组 `data-id="g{n}"` 管位置和大小；中间一层 600×600，写 `perspective:2400px`，组比 600 小时再写 `scale` 缩到组的大小（`transform-origin:0 0`）；
  最里面是圆 `data-id="m{n}"`，框永远 600×600，只变转角、颜色、粗细。成球的那几页十二个外层组叠在同一个位置（框 600）；日历页每个组 240，中间那层 `scale:0.4`。
- 日历页的圆放平（`rotate:z 0deg`），缩到 0.4 以后描边变细，所以写 5px（看着 2px）。圈里的月份是页面上单独的 `.t-h2`，翻页时淡出。
- 第 n 个圆写 `data-id="m{n}"`，就是第 n 个月。
- **每个月一个颜色**：四季各取一个分类色（冬 `--cat-4` 青、春 `--cat-5` 绿、夏 `--cat-1` 橙、秋 `--cat-2` 洋红），
  中间的月份用 `color-mix(in oklch, …)` 在这一季和下一季之间混，一年绕一圈回到青。月份标签（`.t-label`）写同一个颜色，圆和月份对得上。
  分类色不跟配色走：深底、浅底都看得清。
- 每个月是一个宽 440 的组（`data-id="M1"`–`"M12"`）：月份 `.t-label`（行内写这个月的颜色），标题 `.t-h2` 在 36，季度页多一句 `.t-label .t-dim` 在 104。
- 全年：左列 `left:140`、右列 `left:1360`，`top` 从 110 起每条加 148。
- 季度页：季度小字在 `top:190`、季度名 `.t-h1` 在 232，都是 `left:1020`；三个月从 340 起每条加 180。

## 线框球怎么写

每个圆是一个只有描边的 `<div>`，转角写 CSS 的独立属性 `rotate`。PowerPoint 的三维旋转是分 X、Y、Z 三个角度填的，
CSS 的 `rotate` 只接受「一根轴 + 一个角度」：先把三次旋转合成一根轴，再写进去。

第 i 个圆（0–11）：绕 z 转 20°，再绕 x 转 −40°，再绕 y 转 `15i − 82.5 + 自转`°。放平那页三个角度都是 0。

**快侧对着镜头的圆会断成虚线。** 圆转到几乎侧对镜头时，朝镜头那个方向被压扁十几倍，1.5px 的描边压到不足 1px，浏览器画出来是一串点。
所以每个圆再做两件事：先在自己的平面里转一下（圆转了看不出来），让被压扁的方向对上左右两边；左右两边的描边按压扁的倍数加粗，
压扁以后正好又是原来的粗细。上下两边不动。

下面这段 Node 一次算出十二个圆的描边和转角，直接贴进行内：

```js
// node -e '…' -- 75 1,2,3   → 自转 75°、一到三月亮起来（负的自转角也要那个 --）
// node -e '…' -- flat        → 放平（结尾）
const [arg = '0', litArg = ''] = process.argv.slice(1)
const flat = arg === 'flat', spin = flat ? 0 : Number(arg)
const lit = litArg.split(',').filter(Boolean).map(Number)
// 每个月一个颜色：四季各取一个分类色，月份在两季之间混
const SEASON = ['--cat-4', '--cat-5', '--cat-1', '--cat-2']
const mcolor = (n) => { const k = Math.floor((n - 1) / 3), r = (n - 1) % 3
  return r ? `color-mix(in oklch, var(${SEASON[k]}) ${100 - 33 * r}%, var(${SEASON[(k + 1) % 4]}))` : `var(${SEASON[k]})` }
const q = (x, y, z, d) => { const t = (d * Math.PI) / 360, s = Math.sin(t); return [Math.cos(t), x * s, y * s, z * s] }
const mul = ([a, b, c, d], [e, f2, g, h]) => [a*e - b*f2 - c*g - d*h, a*f2 + b*e + c*h - d*g, a*g - b*h + c*e + d*f2, a*h + b*g - c*f2 + d*e]
const f = flat ? 0 : 1
let worst = 1
for (let i = 0; i < 12; i++) {
  const on = flat || lit.includes(i + 1), line = on ? 3 : 2
  let r = mul(mul(q(0, 0, 1, 20 * f), q(1, 0, 0, -40 * f)), q(0, 1, 0, f * (15 * i - 82.5 + spin)))
  // 镜头方向在圆自己坐标里的样子：z 分量是压扁的倍数，x、y 是被压扁的方向
  const [, vx, vy, vz] = mul(mul([r[0], -r[1], -r[2], -r[3]], [0, 0, 0, 1]), r)
  const c = Math.abs(vz); worst = Math.min(worst, c)
  if (Math.hypot(vx, vy) > 1e-6) r = mul(r, q(0, 0, 1, (Math.atan2(vy, vx) * 180) / Math.PI))
  const side = c < 0.999 ? Math.min(line / Math.max(c, 1e-3), 16 * line) : line
  let [w, x, y, z] = r
  if (w < 0) [w, x, y, z] = [-w, -x, -y, -z]
  const deg = (2 * Math.acos(Math.min(1, w)) * 180) / Math.PI, s = Math.sqrt(1 - w * w)
  const rotate = deg < 0.01 ? 'z 0deg' : `${(x / s).toFixed(3)} ${(y / s).toFixed(3)} ${(z / s).toFixed(3)} ${deg.toFixed(1)}deg`
  const color = flat ? 'var(--accent)' : mcolor(i + 1), dim = on || !lit.length ? '' : ' opacity:0.25;'
  console.log(`m${i + 1}: border:solid ${color}; border-width:${line}px ${side.toFixed(1)}px; border-radius:50%;${dim} rotate:${rotate};`)
}
if (!flat && worst < 0.09) console.error(`有个圆几乎正好侧对镜头（${worst.toFixed(3)}），自转角换成 15 的倍数`)
```

**自转角取 15 的倍数。** 十二个圆隔 15° 一个，自转角是 15 的倍数时，离侧对最近的那个圆还差 7.5°，加粗救得回来；
取别的值可能有一个圆正好侧对，加粗也救不回来，脚本会报出来。

## 动效原则

样稿的转场计划（写在样稿开头的注释里）：

```
1→2  大标题缩成顶上一行小字，十二个圆一个接一个浮上来，圈里写月份
2→3  十二个圆一个接一个飞到右边，各自转开，叠成球；左边的字等球成形后出来
3→4  同一个球挪到中间，绕自己的轴转 30°；十二个月分列两边入场
4→5  球收到左边、转过来，一到三月的圆亮起来；这三个月从全年移到右边
5→6  球再转 45°，四到六月的圆亮起来、一到三月暗下去；换一季的三个月
6→7、7→8  同上
8→9  十二个圆全部亮起来、放平，叠成一个圆，圈住全年的数
```

- **十二个圆整份稿子是同一组（`m1`–`m12`），每页都写 `rotate`**，包括放平那页（`z 0deg`）。两页之间引擎按四元数插值，
  每个圆沿最短的路径转过去，看着是整个球在自转。
- **这一季的三个圆描边 3px，其余 2px、`opacity:0.25`。** 粗细、透明度跟着转场一起变：这一季亮起来的同时上一季暗下去，像时间在球上走。
  封面和全年那页十二个圆一样亮，是一个彩色的球。
- **结尾十二个圆一起变成强调色**（`var(--accent)`）再叠成一个：十二种颜色汇成一种。
- **自转每页 30–45°**（样稿：成球那页 90、全年 60、四个季度 75 / 30 / −15 / −60、结尾放平）。球是对称的，转 15 的倍数后停住的样子一样，
  看得出转是因为亮的圆换了位置。
- **转场 1.6 秒，结尾 1.8 秒**：3D 的转动比平移慢才看得清；结尾的字等圆叠好（延迟 1.2）再出来。
- **月份用 `data-id` 跟着走**：全年那页的一到三月直接移到第一季度的列表里，看得出「这一页讲的是全年里的这三个月」。
- **日历页的圆错开浮上来**：组上写 `data-auto-animate-delay`，从 0.4 起每个加 0.06；圈里的月份再晚 0.2。
- **成球转场 2.2 秒，十二个圆每个晚 0.05 秒起步**（外层组和圆写同一个 `data-auto-animate-delay`）：一个接一个飞，比一起飞更像在搭。
- 停留：封面 2 秒，日历 3 秒，成球 3 秒，其余 4 秒。

## 硬规则

- 每个圆包在自己的组里，挪位置、换大小只改组。**不要直接挪圆**：reveal 用 `transform` 做位移，它排在 `rotate` 后面，
  会在每个圆自己转过的方向上平移，十二个圆在转场里各飞各的，球就散了。
- 圆的框每页一样大（样稿 600）。组和圆同时变大小，缩放会叠两次；要变小就在中间那层写 `scale`。
- 透视写在中间那层（`perspective:2400px`），不写在页面上：透视只管直接的子元素，管不到组里的圆。
- `border-width` 和 `rotate` 一起用上面的脚本算，不要只改其中一个：在自己平面里转的那一下和左右加粗是配套的。
- 描边颜色只写变量（`var(--cat-…)`、`color-mix` 里也只写变量）。
- 样稿的鹿鸣书店和全年的事、数字都是虚构的，做同款时换成用户的东西。

## 自检

除了 `transitions.md` 末尾的通用自检，再看：

1. 每次转场的中间帧：十二个圆一直围着同一个圆心，没有散开成好几个圆。
2. 每个季度页亮的正好是这一季的三个圆（m1–m3、m4–m6……），颜色和右边三个月的标签对得上。
3. 结尾十二个圆完全叠成一个圆，看不出重影。
4. 停住的每一页放大看：没有哪条线断成虚线。
5. 全年那页两边的字不碰球。
