# 黑底撞色

样稿场景：商业计划路演。手法：版式（黑底 + 一种撞色 + 纹理大图），橙卡接力

## 参考拆解

参考是公众号「妙想Design」的每周版式分享（vol21）：40 页深色商业演示的缩略图拼板，五条手法：

1. **深色背景**：大面积黑，靠文字和图片的明暗对比出质感；
2. **撞色突出**：只用一种橙色，点在按钮、数据、重点信息上；
3. **大图造势**：有纹理、有流动感的图片铺开面积；
4. **标题错位**：大标题放在版面边缘或图片旁边，不居中；
5. **信息分层**：字号、色块、间距分开标题、数据和说明。

参考只有静态版式。它的页与页之间本来就有几样反复出现的东西：顶上一条细导航、一块橙色（有时是按钮，
有时是高亮卡，有时是数字卡）、一张纹理大图。这里把这三样做成共享元素，翻页时橙色和大图在页与页之间走，
导航不动。

| 参考 | 这里 |
| --- | --- |
| 每页顶上一条细导航 | `brand` `nav` `date` 三个 `.t-label`，每页同位置，翻页时不动 |
| 橙色按钮、橙色高亮卡、橙色数字卡 | 同一个 `data-id="hi"` 的 `.s-accent`：胶囊（圆角写高度一半）和卡片（`var(--radius-l)`）互变 |
| 每页一张纹理图，位置各不同 | 一个 `data-flip="art"` 的照片框，`data-flip-mode="cross"`：走位置、变大小，换图时途中交叉淡化 |
| 标题细、不加粗 | 主题 `noir`：Inter 400、收紧字距，小标签不转大写 |

## 适用 / 不适用

| 适用 | 不适用 |
| --- | --- |
| 公司介绍、商业计划、融资路演、产品发布：要显得贵、显得稳 | 活泼的场合（校园、亲子、节日）：黑底压着，热闹不起来 |
| 有几张能撑场面的图：纹理、材质、建筑、产品特写 | 只有现场合影、截图：大图的位置要的是质感，杂乱的照片放上去就散了 |
| 每页一个重点（一个数字、一个按钮、一个高亮项），橙色给它 | 每页好几个并列重点：橙色一多就不是撞色了，换 `editorial-tri-tone` 这类多色主题 |

## 内容槽位

| 槽位 | 从哪取 | 缺了怎么办 |
| --- | --- | --- |
| **公司名、日期**（导航条） | brief | 导航中间四个词写稿子的章节或公司的栏目，不要写「About / Product」占位 |
| **封面标题、一句话定位** | 用户的材料 | 标题 8 个字以内（`.t-display` 一行）；定位一句话 |
| **三个关键数字** | 用户的材料 | 没有真数字就去掉这一排，不编 |
| **目录**（4–6 项，每项一句小字） | 用户的材料 | 少于 4 项就把格子改成 2 × 2 |
| **每章一个重点数字或一句话** | 用户的材料 | 给橙卡；没有数字就放一句短话，用 `.t-h2` |
| **3–4 张纹理大图** | 用户给的 | 横幅；只要一种主色（和撞色同色系）+ 黑。没给就生成抽象纹理，写进转场计划注释；不生成假的产品图、现场图 |

胶囊 `220 × 56`、圆角 `28px`；卡片圆角 `var(--radius-l)`。

## 动效原则

样稿开头的注释里有转场计划。要点：

- **只有两样东西在走**：橙色 `hi` 和大图 `art`。其余的字每页换，没配对，淡入淡出。走的东西一多，画面就乱，高级感先没了。
- **橙色每页都有、只有一块。** 它是胶囊、是高亮格、是数字卡，但永远是同一个 `data-id`。
  某一页真的不需要橙色，宁可让它缩成胶囊放在角落，也不要让它消失：断一页，接力就断了。
- **大图换图用照片框交叉淡化**（`data-flip="art"` + `data-flip-mode="cross"`，`transitions.md`「翻面」第 3 条），不写 `data-id`。
  同一张图连续两页（7→8）只走位置和大小。
- **导航条每页写、同位置**，翻页时纹丝不动，眼睛有个落点。
- 整份统一 1.2 秒；照片框写 `data-duration="1.2"`，和橙色一起落定。
- 停留：每页 3 秒，目录、结尾 4 秒。

## 硬规则

- 配色用 `ember`（或别的深底 + 单一强调色）：撞色只有一种，第二个彩色进来就没有撞色了。
- 橙色面积守 `visual-spec.md` 的 15%：一页一块 `hi`，最多再加几个 `.t-accent` 小标签。
- 橙色上的字一律 `.t-on-accent`（近黑）；深灰卡上的字用 `.t-on-surface`，要灰就写 `opacity`，不要用 `.t-dim`。
- 标题不居中：贴左、贴右、放在图旁边。一页只有一个大标题。
- 大图压字时（封面、结尾）铺一层渐变把字下面压黑，颜色写 `var(--bg)`。
- 样稿的赤野能源、站点数、电价、收入构成都是虚构的，纹理图是 AI 生成的：做同款时一样也不留。

## 自检

除了 `transitions.md` 末尾的通用自检，再看：

1. 每一次翻页，橙色都是从上一页的位置长过去的，没有一页突然冒出来或突然消失。
2. 换图的那几页（3→4、4→5、5→6、6→7）：中间帧里照片框在动，两张图在交叉淡化，没有先闪一下白框。
3. 封面、结尾的标题压在大图最亮的地方读不读得动；读不动就加深渐变，或者把标题挪到图暗的地方。
4. 导航条翻页时没有跳动。
