# 两阶段规划

手法：S 形回旋圆环

## 参考拆解

参考是抖音 RonniePPT「设计灵感」的一条（PowerPoint 做的 S 形回旋）。几样东西叠出来：

1. **一个圆环切成四个扇形**：圆 + 两个十字交叉的矩形「结合」再「减除」，挖掉中间一个圆，用任意多边形「拆分」，每个扇形是一个独立形状。
   扇形之间留一道细缝。
2. **两组，各删一个扇形**：左组缺右上、右组缺左下，两组错开半个身位对齐，缺口互相咬住，拼成一个 S。
3. **深浅两圈**：左组深色在外圈、浅色在里；右组反过来，深色在里圈。两组接上的地方，左组的外圈深色正好接上右组的内圈深色，S 的笔画连成一条。
4. **圆心一个小圆**，写这一组的名字；每个扇形一个序号（深色那圈里；本同款换成了强调带）和一两句话（浅色那圈里），字顺着扇形斜。
5. **动画**：每组加一个透明的圆一起组合，让组的中心落在圆心上，再加进入动画「回旋」——整组绕自己的圆心转着、由小到大长出来。左组先，右组后。

本同款照这个做：一组是一个 `.s-group`（框 720×720，中心就是圆心），写 `data-anim="spin"`（`transitions.md`「入场和强调」）。
组的框本身就让中心落在圆心上，不需要那个透明圆。

看点：

> **两组扇形各绕各的圆心转着长出来，落定时咬成一个 S。** 换一组内容就再转一次。

和「发展历程」（`ring-timeline`，一个大圆环、高亮扇形一格一格转）的区别：那里圆环一直在，转的是高亮；这里整组是入场动画，讲的是「两段并列」。

## 适用 / 不适用

| 适用 | 不适用 |
| --- | --- |
| 两个阶段、两个方面，每个三件事：上半年 / 下半年、理论 / 实践、线上 / 线下 | 一个阶段、四个阶段：S 只有两笔。四件事以上换「发展历程」或通用的卡片网格 |
| 每件事一个四字标题 + 一句八个字以内的话 | 每件事要讲一段话：扇形的浅色那圈只有 160 宽，放两行就满了 |
| 两组之间有先后或对照（先做 A 再做 B） | 六件事其实是一条时间线：S 的顺序不好读，换「大事记年表」或「发展历程」 |
| 换一组内容再讲一遍（每个方面一页，同一个 S 再转一次） | 要交 PPTX 还要动画：PPTX 里是放完的样子，回旋导不出来（`transitions.md`「导出 PPTX」） |

## 内容槽位

| 槽位 | 从哪取 | 缺了怎么办 |
| --- | --- | --- |
| **封面标题、副标题** | brief | 标题写这份计划的一句话：「两步走」「先站稳，再扩张」，8 个字以内 |
| **每页的标题** | brief | 「全年两步走」「门店：先做深，再做广」—— 冒号前是这一页讲哪个方面 |
| **两个阶段的名字**（圆心里，一个小标签 + 一个两三字的词） | 用户的材料 | 小标签写阶段（上半年 / 理论），大字写这一段的意思（站稳 / 打底） |
| **每个阶段三件事**，一个四字以内的标题 + 一句八字以内的话 | 用户的材料 | 用户给的是一段话就拆成三件；不够三件就别凑，换版式 |
| **结尾：四个复盘点 + 一句话** | brief | 自己补：四个季度各一个时间点（三月底 / 六月底 / 九月底 / 十二月）和要对表的事；结尾大字「年底见」，下面一句「按这六件事对表」 |

## 页面结构

样稿 6 页：封面 → 四页 S（全年、门店、团队、会员，各是两组三件事）→ 结尾。页数随方面多少增删，一个方面一页。

- **封面**：左边标题（`.t-display`，`left:120`），右边一个缩小到 0.6 的 S，扇形上不写字、圆心照写，两组先后回旋出来 —— 第一眼就是这份稿子的动作。
  一组套三层：最外层的框是缩小后看得见的大小（432×432，出稿检查按 `left + width` 量安全区，不认 `scale`）；
  中间一层 720×720、`left/top:-144`、`scale:0.6`；回旋写在最里面那层（GSAP 动 transform 时会把同一个元素上的 `scale` 属性清掉）。
  两组最外层 `left` 1000 / 1288、`top` 324：缩小后圆心相距 288，S 的中心在 (1360, 540)。
- **结尾**：两段走完合成一整圈。一个 720×720 的组（`left:1000 top:180`），四个象限是四次季度复盘（Q1–Q4，顺时针），圆心深色写「年底」，整圈回旋出来；
  左边是结尾的话。不写「谢谢」，落到往前看的节点上。

坐标都是定的，换内容不用重算：

- 左组 `.s-group` 在 `left:360 top:180`，右组在 `left:840 top:180`，都是 720×720。圆心 (720, 540) 和 (1200, 540)，相距 480 = 内径 120 + 外径 360。
- 扇形是组里铺满 720×720 的 `.s-arc`（120 以内挖空，`--band-in` / `--band-out` 定强调带），`clip-path: inset(…)` 裁出一个象限，留 4px 缝。
- **强调带顺着 S 从琥珀烧到火橙**：六段走七个节点，0（`--accent-soft` 琥珀）到 1（`--accent` 火橙），一段比一段热。
  只变深浅、不变色温的渐变（深靛蓝由浅到深）看着是平的；暖色往热里走，压在冷的浅蓝底上，才有往前冲的势能。带子上的序号用 `.t-on-accent`。
  `.s-arc` 的渐变是顺时针画的（`--arc-start` 是象限顺时针的起始角：右上 0、右下 90、左下 180、左上 270）；左组 01→02→03 是逆时针走的，
  所以左组每段的 `--arc-a` 取这一段终点的浓度、`--arc-b` 取起点的。结尾那一整圈也一样，Q1 到 Q4 顺时针越走越深。
- 左组：浅圈 120–280、强调带 280–360，象限 左上 / 左下 / 右下（01–03）。右组：强调带 120–200、浅圈 200–360，象限 左上 / 右上 / 右下（04–06）。
- 序号在强调带的正中半径上，标题 + 一句话在浅圈的正中半径上，都放在象限的 45° 角上；上半圈 `rotate` 写这个角，下半圈再转 180°，字不倒着。
- 圆心的小圆直径 200，和圆环之间空 20 露出底色；左组圆心浅、右组圆心深（`.s-surface` 上的字加 `.t-on-surface`）。

页面标题放左上 `left:120 top:80`（`.t-h1`），不压到左组的弧。

## 动效原则

样稿的转场计划（写在样稿开头的注释里）：

```
封面  左边标题，右边一个缩小的 S 先后回旋出来               页内动画（回旋）
1→2  封面淡出，正文的两组圆环先后回旋长出来，拼成一个 S      页内动画（回旋）
2→3  换一组内容：旧的 S 淡出，新的两组再回旋一次              同上
3→4、4→5  同上
5→6  S 淡出，一整圈（四次季度复盘）回旋出来，圆心是年底      页内动画（回旋）
```

- **一组一个 `.s-group`，组上写 `data-anim="spin 1.2s @…"`**：扇形、序号、字、圆心都在组里，跟着组转；组的框以圆心为中心，所以绕圆心转。
- **左组 `@0`，右组 `@0.45`**：右组在左组转到一半时起步，落定时两组先后咬上，比同时转更像参考里「一个接一个」。
- 回旋 1.2 秒、`power2.out`：开头转得快、长得快，最后半圈慢下来对准位置，落定那一下读得出 S。
- S 页之间的转场写 `data-auto-animate-duration="0.6"`：旧的 S 0.35 秒淡出，新的尽快开始转，不要空等。
- 组上加 `.s-lift`：整组一道柔和的投影，右组的影子落在左组的扇形上，两组有前后。
- 停留：封面 2 秒，每页 S 3 秒（回旋放完约 1.65 秒，再留时间读六件事）。

## 硬规则

- 一组一个 `.s-group`，框 720×720，中心就是圆心；`data-anim="spin"` 写在组上，不写在扇形上（写在扇形上各绕各的框中心转，就散了）。
- 组里不写 `data-id`：每页的 S 都是新入场的，不和上一页配对。
- 扇形用 `.s-arc`，行内只写它的变量；强调带和浅圈在两组里正好反过来，两组的强调带要接上（圆心距 = 内径 + 外径），接口两边的 `--arc-a` / `--arc-b` 相等，颜色不跳。
- 字顺着扇形斜，但不倒着：下半圈的角度再转 180°。
- 样稿里的栖岸咖啡和全部计划都是虚构的，做同款时换成用户的东西。

## 自检

除了 `transitions.md` 末尾的通用自检，再看：

1. 回旋时两组各绕自己的圆心转，不是绕页面中心、不是绕组的左上角。
2. 落定时两组的强调带在 x 1000–1080 接成一条，颜色接得上，缝和别处的缝一样宽；从 01 到 06 一路越来越热。
3. 每个扇形里的字没有压到缝、没有出浅色那圈；下半圈的字是正的。
4. 换页时上一页的 S 先淡掉，新的从小开始转，中途两套不叠在一起。
