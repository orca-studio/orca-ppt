# 四栏产品切换

## 参考拆解

参考是一段 6 秒的饮料产品分栏视频，看点叠在三样东西上：

1. **一块色块在四栏之间移动**：同一块彩色面板一栏栏向右，每到一栏换成那个产品的颜色。观众看到的是「焦点在移动」，不是「换了一页」。
2. **产品上下交接**：旧主角向上离开画面，新主角从画面下方进来；没轮到的栏原地不动。
3. **最后一栏展开成详情**：第四栏的色块向左撑满全屏，同一只产品移到正中放大，大字产品名在产品背后出现。

样稿用五页状态实现，全部是共享元素和形态变换，没有手写动画。

## 适用 / 不适用

| 适用 | 不适用 |
| --- | --- |
| 正好四个并列的产品、口味、方案、套餐，每个有一张主图 | 不是四个。三个或五个硬塞进四栏，空栏或挤栏一眼就露馅；换别的版式 |
| 产品之间是平级的，要逐个亮相，最后落到一个主推款 | 产品之间有先后、有大小（流程、排名、增长）—— 并排四栏会被读成「对等」 |
| 每个产品有一张抠好背景的图 | 只有带背景的照片。上出下入时背景会跟着飞，读出来是一张卡片在动，不是产品在动 |
| 产品发布、品牌介绍、电商详情的开场 | 文字为主的汇报内容 |

## 内容槽位

| 槽位 | 从哪取 | 缺了怎么办 |
| --- | --- | --- |
| **四张产品图** | 用户给的素材（透明背景的 PNG、WebP 或 SVG） | 没有就**停下来要**，不要拿别的图凑。四张图画布比例、主体位置、留白要一致，否则同样的尺寸看起来大小不一 |
| **四个名称 + 一句说明** | 用户给的产品信息 | 说明没给就只放名称，不编卖点 |
| **四种颜色** | 产品本身的识别色 | 没给就从产品图里取主色；四种颜色要在色相上分得开，相邻两种别太像 |
| **主推款（最后展开的那一个）** | 用户指定 | 默认第四个。要换主推款就调整顺序，让它排在第四栏 |
| **详情页的大字和规格** | 用户给的产品名、容量或规格 | 大字默认用主推款的英文名或短名；规格没给就不放 |

## 页面结构

五页，同一套元素，只改坐标、尺寸、颜色类和透明度：

| 页 | 状态 |
| --- | --- |
| 1 | 第一栏激活：色块在第一栏，第一个产品在展示位，其他产品在画布下方待命 |
| 2 | 同一块色块移到第二栏、换成第二种颜色；第一个产品移到画布上方，第二个产品移到展示位 |
| 3 | 同上，换到第三栏 |
| 4 | 同上，换到第四栏 |
| 5 | 同一块色块撑满全屏；第四个产品居中放大；前三栏文字退场，大字在产品背后出现，规格在右侧 |

- 每个产品在五页里都存在，用同一个 `data-id`（例如 `bottle-<名字>`）和同一份图片文件。临时新建的图片只会做短距离淡入，接不上「从画外进来」。
- 色块全程是同一个 `data-id`（`active-panel`）。名称、说明、编号、按钮各有自己的稳定 `data-id`。
- 层次从下到上：色块 → 详情页的大字 → 产品和产品文字 → 导航和规格。大字不能盖在产品上面。
- 全出血四栏（每栏 480）、画外待命、局部字阶这些是**这个同款专用的版式例外**，规则和取值见 `references/product-showcase.md`，样稿根节点要带 `data-demo="product-showcase"` 才会启用，普通稿子不继承。

## 动效原则

转场计划四行，前三行同构：

```
1→2  关系：同一组产品里把主角换成第二个，色块向右，两个产品上下交接   手法：共享元素
2→3  关系：主角继续向右                                                手法：共享元素
3→4  关系：主角继续向右                                                手法：共享元素
4→5  关系：第四栏就是详情页的底色，产品留在视野里移到中央              手法：共享元素 + 形态变换
```

- **焦点只走一个方向**：色块一路向右，最后一下反过来向左撑满。中途来回跳会让观众失去「这是同一块焦点」的感觉。
- **交接方向固定**：旧的永远向上、新的永远从下面来。四次都一样，观众第二次就能预判，第三次开始看产品而不是看动画。
- **前三次快，最后一次慢一点**：前三次是节奏（样稿每次约 0.73 秒），最后一次是落点（约 0.8 秒），给展开留出分量。时长和缓动是这个同款的参考节奏，不是通用默认值。
- **没轮到的栏不动**：哪怕一像素的抖动，都会让「只有焦点在动」这个看点失效。

## 硬规则

- 正好四个产品。不是四个就别用这个同款。
- 每个产品五页都在、同一个 `data-id`、同一份图片。
- 只改坐标、尺寸、颜色类和透明度，不写新的动画代码。
- 产品图不编、不拿无关图片凑。

## 自检

除了 `references/transitions.md` 末尾的通用自检，再看：

1. 色块是连续横移过去的，不是在新位置淡入。
2. 每次交接旧产品向上、新产品从下方进入，两者都看得见在动，没有原地出现。
3. 没轮到的栏在整个转场里纹丝不动。
4. 最后一次色块撑满时产品一直在视野里，大字在产品背后。
5. 四张产品图在展示位上看起来一样大。
