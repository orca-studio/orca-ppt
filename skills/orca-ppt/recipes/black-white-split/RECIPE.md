# 黑白分屏

样稿场景：商业计划书。手法：版式（黑白分屏 + 一种荧光撞色 + 压缩粗标题），黑块变形

## 参考拆解

参考是公众号「妙想Design」的每周版式分享：一套 Business Plan 的缩略图拼板。看点：

1. **黑白轮换**：有的页整页黑，有的页白纸，有的页左栏黑、右半边黑，一份稿子里黑白一直在换位置；
2. **荧光绿撞色**：只用一种荧光绿，做色签（斜贴在标题尾巴上的「OUR COMPANY」）、下划线、高亮格；
3. **压缩超粗的大标题**：窄体粗字铺满一行，数字也是；
4. **每页一个绿色圆章**（地球图标），位置每页不同；
5. **页眉**：左边公司名，右边日期和地址，每页同一位置。

参考是静态的。这里把「黑」做成一块会变形的形状，黑白分屏就是它在页与页之间变形；圆章和色签跟着跳。

| 参考 | 这里 |
| --- | --- |
| 整页黑 / 左栏黑 / 右半边黑 / 一条黑线 | 同一个 `data-id="panel"` 的 `.s-surface`（直角），每页一个形状，翻页时变过去（`transitions.md`「整页 ↔ 卡片」） |
| 斜贴的荧光色签 | `data-id="tag"` 的 `.s-group`，`rotate:-6deg`，里面一块 `.s-accent` + 一行 `.t-tag` |
| 地球圆章 | `data-id="globe"` 的 `.s-group`：`.s-dot` 大小的 `.s-accent` 正圆 + 三条线的地球图标 |
| 窄体粗标题 | 主题 `split`：`.t-display` `.t-h1` 用 Anton，中文落到苹方粗体 |
| 页眉 | `brand` `date` `city` 三个 `.t-label`，每页同位置；压到黑上时加 `.t-on-surface`，翻页时颜色跟着变 |

## 适用 / 不适用

| 适用 | 不适用 |
| --- | --- |
| 商业计划、品牌提案、年度策略：要有冲劲、显得年轻 | 严肃的财报、学术汇报：荧光绿和压缩粗字太跳 |
| 每页内容不多：一个大标题 + 三四条 | 一页要放很多字：黑白分屏把一页切成两半，每半边放不下 |
| 内容里有数字、序号 | 照片是主角的稿子：这里照片只是点缀，换 `black-orange` 或 `drawer-tabs` |

## 内容槽位

| 槽位 | 从哪取 | 缺了怎么办 |
| --- | --- | --- |
| **公司名、日期、城市**（页眉） | brief | 日期写汇报那天 |
| **封面标题** | 用户的材料 | 5 个字以内（`.t-display` 一行，左边要留给色签） |
| **色签上的字**（2–3 页用） | 从标题里取 | 4 个字以内：「2027 版」「要解决的」「一起出发」 |
| **目录 4 项、每章 3–4 条** | 用户的材料 | 每条一个名字（6 个字以内）+ 一句小字 |
| **三个大数字** | 用户的材料 | 没有真数字就把这页换成三条文字，不编 |
| **2–3 张照片** | 用户给的 | 浅色、近单色，最多带一点荧光绿。没给就生成，写进转场计划注释；不生成假的产品、门店照 |

## 页面结构

样稿 8 页，虚构的电单车换电公司「绿点出行」2027 商业计划：

| 页 | 黑块 panel | 其他 |
| --- | --- | --- |
| 1 封面 | 整页 | 色签贴在标题尾巴上；珊瑚雕塑照片 |
| 2 目录 | 底下一条线（`560, 900, 1240 × 6`） | 四项错开排 |
| 3 公司介绍 | 左栏（`0, 0, 640 × 1080`） | 照片放在黑栏里 |
| 4 问题 | 中间一条线（`120, 520, 1680 × 6`） | 上面三条问题；下面照片 + 大标题 + 色签 |
| 5 方案 | 右半边（`960, 0, 960 × 1080`） | 三条方案写在黑的那边 |
| 6 市场机会 | 标题下的线（`120, 400, 1680 × 6`） | 三个大数字，各压一道荧光绿下划线 |
| 7 商业模式 | 整页 | 三格荧光绿一字排开 |
| 8 融资计划 | 整页 | 四格绿色方阵；色签回来收尾 |

页眉：`brand left 120`、`date left 1200`、`city left 1560 width 240` 右对齐，都在 `top 72`。圆章 72 × 72。

## 动效原则

样稿开头的注释里有转场计划。要点：

- **黑是一块形状，不是背景。** 白纸是 `--bg`，黑是 `.s-surface` 的 `panel`。每页都写，`data-id` 不变：
  整页 → 一条线 → 左栏 → 一条线 → 右半边，翻页时它变形过去，观众看到的是黑白在推移。
  不要用换背景色来做黑页：背景色是硬切，变不过去。
- **线是黑块的「收起」状态。** 白纸页不需要黑块时，把它收成一条 6px 的线放在版面里当分隔线，不要让它消失：
  消失了下一页就只能淡入，推移断了。
- **圆章每页都有，只跳位置。** 色签只在两三页出现（封面、某个章节、结尾），出现时贴在大标题的尾巴上。
- **页眉压到黑上就加 `.t-on-surface`**：翻页时字的颜色跟着黑块一起变。
- 整份 1.2 秒；照片框写 `data-flip="art"` + `data-duration="1.2"`。
- 停留：每页 3 秒，目录、结尾 4 秒。

## 硬规则

- 配色用 `lime`（或别的「浅底 + 纯黑 `--surface` + 一种荧光色」）：`--surface` 必须是黑，分屏才成立。
- 荧光绿只做色块（`.s-accent` / `.s-accent-soft`），不做白纸上的字：它在白底上对比度不到 1.3:1。
  白纸上要强调的字用 `.t-accent`（配色给的是深橄榄绿）。
- 绿色面积守 `visual-spec.md` 的 15%：一页一块 `.s-accent`，其余高亮格用 `.s-accent-soft`。
- 黑块上的字一律 `.t-on-surface`，要灰就写 `opacity`。
- 标题不居中，贴左或贴在黑白交界旁边。
- 样稿的绿点出行、城市数、换电次数、融资额都是虚构的，照片是 AI 生成的：做同款时一样也不留。

## 自检

除了 `transitions.md` 末尾的通用自检，再看：

1. 每次翻页，黑块都是从上一页的形状变过去的，没有一页黑白是硬切的。
2. 页眉压在黑白交界上时（左栏页、右半边页），每个字都在它自己那半边，颜色对。
3. 色签斜着贴在标题尾巴上，压住标题最后一个字的一角，不压住整个字。
4. 压缩粗字：中文和数字混排时（「9 分钟」）两种字的高度差不多，不难看。
