# 用户调研洞察

手法：三色卡片收成图表

## 参考拆解

这是我们自己的样稿 `examples/soft-editorial/`：一份用户研究的阶段汇报（Field Notes），
六页 —— 封面 → 三条洞察 → 三个数字 → 一张留存曲线图 → 留存最高那一组的细节 → 三项实验。
核心看点在第 2–4 页，叠在三样东西上：

1. **三张卡片从头到尾是同一组东西**：第 2 页的三张等宽洞察卡（粉 `.s-accent`、黄绿 `.s-surface`、桃 `.s-accent-soft`），
   翻到数字页时不换新卡，是这三张换了布局：黄绿那张向左撑成两倍宽的大面板，粉和桃缩成右侧上下两块。
   观众读到的是「同样三件事，现在看它们的分量」。
2. **三块面板收进一张图表卡**：翻到留存页，三块面板依次飞向右侧，叠成一张奶白的图表卡（`.s-surface-2`），
   卡里的曲线一条条画出来。前一页是三块颜色，这一页是带颜色的线 —— 「三个东西收进来了」。
3. **页眉页脚不动**：左下日期、右下刊名每页同一位置、同一段文字，翻页时原地不动；只有卡片在动。

前后加的三次翻页把这条线讲完整：封面上一枚黄绿胶囊（这次研究）**一分为三**散成三张洞察卡；
图表里粉线终点的圆点**钻进去**是留存最高那一组的细节页，那一页的三块事实条还是粉、黄绿、桃，
最后回到第 2 页三张卡的位置，变成「一条洞察对一项实验」。

五次翻页全是引擎现成的手法（一变多、形态变换、多合一、放大进元素内部、形态变换），没有手写动画。
六页的颜色都来自同一套配色，没有临时写的色值。

## 适用 / 不适用

| 适用 | 不适用 |
| --- | --- |
| 研究汇报、复盘、阶段总结：**正好三个**并列的发现，后面跟一组数字和一张图 | 不是三个。两张卡撑不满宽度，四张以上每张太窄放不下标题加一句话；换别的版式 |
| 三个发现之间是平级的，但第二页要突出**其中一个**最重要的数字 | 三个数字同等重要、没有主次 —— 第二页「一大两小」的布局会读出假的主次 |
| 结尾是一张**最多三个系列**的折线图（三组人群、三个方案的对比） | 图表有四个以上系列，或者是柱状图、饼图 —— 合拢后颜色对不上，看不出「三块收进来了」 |
| 文字量中等：每张卡一个短标题 + 一两句话 | 每张卡一大段文字，或者需要列表、表格 |

## 内容槽位

| 槽位 | 从哪取 | 缺了怎么办 |
| --- | --- | --- |
| **三条洞察**（各一个短标题 + 一两句说明） | 用户的研究结论 | 标题不超过 5 个词或 12 个字，说明不超过两句。说明没给就只放标题，不替用户编结论 |
| **主数字**（第二页大面板里的那个） | 数据里最想让人记住的那一个 | 默认放在黄绿大面板里，配一句话说它是什么、跟什么比。**不编数据**：没有就停下来要，或用明显的占位（00%）并在转场计划注释里写明 |
| **两个辅助数字** | 样本量、覆盖范围这类背景数字 | 没有就用研究本身的规模（访谈几人、几个团队），仍然只用用户给过的数 |
| **一张折线图的数据**（最多三条线，每条一个结束值） | 用户给的分组数据 | **不编曲线**。只有终点值没有过程时，不画假装有过程的曲线，换成三根横条（仍然沿用三种颜色） |
| **结论标题 + 一句解读** | 用户对图表的结论 | 只写图里看得出来的话（「第 90 天留下的几乎翻倍」），不加推测 |
| **重点那一组的细节**（一句原话 + 三条它拿到了什么） | 访谈记录、用户给的分组说明 | 原话只用用户给的、匿名的（「Participant 14」），**不编引语**。没有原话就把左边换成一句结论；三条事实没有就砍掉第 5 页，第 4 页直接接第 6 页（形态变换不成立时用遮挡剪辑） |
| **三项下一步**（各一个短标题 + 一句话） | 用户的行动计划 | 一条洞察对一项，顺序和第 2 页三张卡一致。没有计划就不做第 6 页，不替用户编行动 |
| **页眉、日期、刊名** | 汇报名称和日期 | 刊名默认用汇报标题；日期用汇报当天。素材里没有的 logo、照片不放，**不编素材** |

## 页面结构

六页，主题默认就是 soft-editorial，引用顺序：

```
tokens.css → themes/soft-editorial.css → palettes/sage.css
```

坐标看样稿 `examples/soft-editorial/index.html`（做同款时 create_deck 会复制它）。

| 页 | 主角 |
| --- | --- |
| 1 封面 | 刊名 + 副标题；下面一枚黄绿胶囊 `.s-surface`（`data-split="cards"`），里面一行 `.t-label .t-on-surface`。**不写** `data-auto-animate` |
| 2 洞察 | 三张等宽卡并排：`c1` 粉 `.s-accent`、`c2` 黄绿 `.s-surface`、`c3` 桃 `.s-accent-soft`；三张同时写 `data-split="cards"`（顺序 c1, c2, c3）。卡上各一组 label + `.t-h2` + `.t-body`。这一页写 `data-st="split"` 加 `data-auto-animate` |
| 3 数字 | 同三张卡换布局：`c2` 撑成左侧大面板放主数字（`.t-metric`）；`c1` 缩到右上、`c3` 缩到右下，各放一个 `.t-display` 数字加一行说明。三张同时写 `data-merge="panel"` |
| 4 图表 | 左边是结论标题、一句解读和图例；右边一张 `.s-surface-2` 图表卡（`data-merge="panel"`），里面是坐标线、三条 `data-enter="draw"` 的曲线、终点数值和横轴标签。粉线终点放一个粉色小圆点（`.s-accent` + `border-radius:50%`，`data-zoom="top"`，`data-enter="pop"`），终点数值往右让开圆点 |
| 5 细节 | 左边：哪一组、一句原话、出处。右边三块事实条 `c1` `c2` `c3` 上下排，每块一个 `.t-h1` 数字加一段 `.t-body`。写 `data-st="zoom-into"` 加 `data-auto-animate` |
| 6 实验 | 一行标题；三张卡回到第 2 页的三栏，卡上 label + `.t-h2` + `.t-body` |

- 卡片用 `div` 写，`data-id` 只给三张卡（`c1` `c2` `c3`），卡上的文字不配对，跟着上浮淡入淡出。
- 卡片和颜色是绑定的：`c1` 永远是粉、`c2` 永远是黄绿、`c3` 永远是桃。之后每页换的是**位置和大小**，不换颜色。
- 第 3 页 HTML 里三张卡的顺序是 `c2, c1, c3` —— 这也是第 4 页合拢的顺序（后写的叠在上面）。
- 页眉右侧的页码（01–06）每页文字不同，会淡出淡入；页脚的日期、刊名每页一模一样，不动。
- 曲线颜色用线条类：`l-text`（墨色）、`l-surface`（黄绿）、`l-accent`（粉）；图例的小线段用同样的类。
- 卡上的数字别用单个「1」「0」：Cormorant 的老式数字里 1 像小写 i、0 像 o，样稿第 5 页因此用了「48」。

## 动效原则

样稿的转场计划：

```
1→2  关系：封面那枚黄绿胶囊（这次研究）一分为三，散开成三张洞察卡              手法：一变多         拆分：cards
2→3  关系：三张洞察卡还是那三张，换了布局：黄绿那张长成放 68% 的大面板，粉和桃缩到右侧   手法：形态变换       共享：c1, c2, c3
3→4  关系：三块数据面板合成一张图表卡，卡里三条留存曲线沿用这三种颜色，依次画出来       手法：多合一         合并：panel
4→5  关系：粉色那条线（留存最高的一组）终点的圆点就是下一页：钻进这一组看它拿到了什么   手法：放大进元素内部 from：top
5→6  关系：三块事实条还是粉、黄绿、桃那三块，回到第 2 页三张卡的位置，变成三项实验      手法：形态变换       共享：c1, c2, c3
```

- **手法交替**：一变多 → 形态变换 → 多合一 → 放大进元素内部 → 形态变换，没有连续两次同一种。
  形态变换出现两次，中间隔了两种别的手法，观众不会觉得是同一下重放。
- **一次配对 3 个**：三张卡就是全部的共享元素，正好在「1 到 4 个」以内。别再给卡上的标题、数字加 `data-id`，多了画面就乱。
- **封面不写 `data-auto-animate`**：第 2 页要写（给 2→3 用），封面也写的话 reveal 会在一变多之外再配一遍 `c1`–`c3`，两套动画打架。
- **1→2 卡上的字等散开完再出**：一变多 1.2 秒，三张卡依次落位约在 1.06 秒，页眉 `data-enter-delay="0.7"`，三张卡上的字 0.9 / 0.98 / 1.06，一张卡一个延迟。
- **2→3 用 1.2 秒**：粉卡从最左跳到右上，位移超过半屏；黄绿卡宽度翻倍。按规范写 `data-auto-animate-duration="1.2"`。
  新文字等卡片落位再出：页眉 0.84、主数字说明 0.92、三个数字 1.0、数字说明 1.08，每组加 0.08，同一行共用一个延迟。卡片还在动时文字不出，否则会压在移动中的色块上。
- **卡片不变色**：形态变换只改位置和尺寸。sage 配色虽然允许这几种颜色互变，但卡片和颜色绑定，一变色观众就认不出是哪张。
  一变多和多合一里颜色会变（黄绿胶囊变成粉、黄绿、桃三张；三张变成奶白），那是「拆开 / 收拢」本身，不算换卡。
- **3→4 合拢时卡里的东西等合拢完再出**：多合一默认 1.2 秒，图表卡里的坐标线、图例 `data-enter-delay="1.0"`～`1.36`，曲线 1.1 开始依次画（每条错开 0.15），三个终点数值 2.0 / 2.15 / 2.3 依次出，钻入点圆点和最后一个数值同时弹出 —— 先有线，后有数。
- **颜色要在合拢后找得到**：三块彩色面板收进奶白卡，观众靠曲线的颜色认出「它们进来了」。所以曲线和图例必须用卡片的颜色类，不要另起一套图表色。例外是桃色：它在奶白卡上画成细线几乎看不见，样稿把第三条线换成墨色 `l-text`（基准组），粉和黄绿两条照用卡片色。
- **4→5 钻入点用粉色圆点**：放大进元素内部要求元素小，24×24 的圆点正好；它是粉的，长大时整屏先变粉，再显出第 5 页 —— 第 5 页右上角第一块就是粉色事实条，颜色接得上。时长用默认 1.8 秒，不改短。
- **5→6 用 1.2 秒**：粉条从右上飞到左边一栏，位移超过半屏。标题和页眉 0.8，三张卡上的字 1.0 / 1.08 / 1.16。
  第 6 页的三张卡回到第 2 页三栏的横向位置，观众会自己对上「这张卡当初是哪条洞察」，不用再写一遍。
- **主数字那张卡决定第 3 页的布局**：主数字在哪张卡上，那张就撑成大面板。样稿是 `c2`（中间那张），它向左撑，粉卡换到右边 —— 两张卡交叉而过，是这一下最好看的地方。
- **强调色面积**：第 2 页三张 520×680 的卡里粉卡占 17%，check-deck 会提醒（只是提醒）；新加的页把粉色块压在 15% 以内（第 5 页 800×200，第 6 页 520×560）。

## 硬规则

- 正好三张卡，第 2、3、5、6 页都在、同一个 `data-id`、同一个颜色类。
- 只用配色里的颜色类（`.s-accent` `.s-accent-soft` `.s-surface` `.s-surface-2`，线条用 `l-*`），不在页里写色值。
- 拆分源只有一个 `data-split="cards"` 元素，合拢目标只有一个 `data-merge="panel"` 元素，都是 `div`。
- 钻入点是一个小圆点（不超过 40×40），写在第 4 页，第 5 页写 `data-st="zoom-into" data-st-direction="in" data-st-from="top"`。
- 不编数据、不编曲线、不编素材。
- 卡上的文字要加对应的「上面的文字」类：`.s-surface` 上加 `.t-on-surface`，`.s-accent` / `.s-accent-soft` 上加 `.t-on-accent`。

## 自检

除了 `references/transitions.md` 末尾的通用自检，再看：

1. 1→2：胶囊是**散开**成三张卡的（三张从胶囊的位置依次飞出、变大），不是在新位置淡入；卡上的字在卡落位后才出。
2. 2→3：三张卡都是**连续移过去、变大变小的**；粉卡和黄绿卡交叉时没有一帧闪成别的颜色；第 3 页的文字在卡片基本落位之后才出现。
3. 3→4：三块面板是依次飞进图表卡的位置，合拢后才出现坐标线和曲线；正常速度下能说出「三块收成了一张图」。
4. 粉、黄绿两条曲线和图例的颜色能和第 3 页的卡片对上；第三条（墨色）在奶白卡上清楚可读。
5. 4→5：圆点是从粉线终点长大、移到画面正中的，第 5 页在它的形状里显出来；能说出「钻进了这一组」。
6. 5→6：三块事实条连续飞到三栏的位置，颜色没变；第 6 页的字没有压在还在动的卡上。
7. 页脚的日期和刊名五次翻页都纹丝不动。
8. 卡片里的文字没有超出卡片，第 3 页右侧两张小卡、第 5 页三块事实条里数字和说明不打架。
