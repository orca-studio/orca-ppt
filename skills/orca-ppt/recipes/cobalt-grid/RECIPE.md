# 扫描线变柱状图

## 参考拆解

配色和版面借自 [beautiful-html-templates](https://github.com/zarazhangrui/beautiful-html-templates)
的 Cobalt Grid 模板（MIT）。它是日本杂志式的趋势报告，看点在三样东西：

1. **严格双色**：米色纸面，加一种电光钴蓝。标题、正文、细线、图形全是这一种蓝，没有第二种强调色。
2. **方格纸常驻**：每一页背后都是一层淡蓝的方格纸，上下各一条细线框住版面。
3. **扫描线装饰**：封面右侧有一列阶梯状、里面排满竖线的色块，像印刷的网点。

原模板是逐页的静态版面，页和页之间没有关系。我们按转场原则加的看点是：

> **封面的扫描线阶梯就是数据。** 翻到数据页时，四级阶梯各自移位、变高，直接成为四个季度的柱状图。
> 之后最高的那根展开成关键数字旁边的大竖条，结尾阶梯回到封面的位置，首尾呼应。

方格纸和上下细线每页同一位置，翻页时一动不动 —— 只有数据在动。

## 适用 / 不适用

| 适用 | 不适用 |
| --- | --- |
| 年报、季报、趋势报告，有一组**随时间变化的数**（季度、月份、年份） | 没有数据，或者数据之间没有大小关系（四个并列概念做成柱子，读出来的高低是假的） |
| 想要克制、读物感的版面，字少、数据说话 | 需要多种颜色区分很多系列 —— 这套配色只有一种墨色，最多一组柱子 |
| 3 到 5 个数据点 | 超过 5 个。阶梯一多封面就挤，柱子一多就细得看不出纹理；拆成两页或换图表 |

## 内容槽位

| 槽位 | 从哪取 | 缺了怎么办 |
| --- | --- | --- |
| **一组数据**（3–5 个，带标签） | 用户给的数据 | **不编数据**。没有就停下来要，或者用明显的占位（Q1…Q4、00%）并在转场计划注释里写明 |
| **标题** | 主题 | 用一个简短的名词加年份（"Index 2026"、"年度复盘 2026"） |
| **关键数字** | 数据里最想让人记住的那一个 | 默认取最后一个点（最新的那个季度） |
| **一句解读** | 用户的结论 | 只写数据本身能支持的话（"比年初高了多少"），不加推测 |

## 页面结构

```
1 封面      标题 + 一句副题；右下角 N 级扫描线阶梯（data-id: q1…qN）
2 数据页    同一组阶梯移位、变高成柱子，底边对齐坐标轴；左边是关键数字和一句解读
3 关键数字  最后一根柱子展开成右侧的大竖条；关键数字放大成 .t-metric
4 结尾      大字致谢；竖条缩回阶梯的最后一级，前面几级依次回来
```

每页的前三个元素固定不变：方格纸 `.s-grid`（铺满整页，写在最前）、上细线、下细线：

```html
<div class="s-grid" style="left:0px; top:0px; width:1920px; height:1080px;"></div>
<div class="s-accent" style="left:120px; top:80px; width:1680px; height:2px;"></div>
<div class="s-accent" style="left:120px; top:1000px; width:1680px; height:2px;"></div>
```

阶梯和柱子都用 `.s-scan`（主题 `cobalt-grid` 新增的类，每块固定 8 根竖线）：

- 封面阶梯：每级宽 120、间隔 20，底边对齐 `top:960`，从左往右一级比一级高。
- 数据页柱子：宽 160、间隔 80，底边等于坐标轴的 `top`（样稿是 880），高度按数据比例。
- 数值标注在柱顶上方 56，季度标签在轴下方 32。

引用顺序：`tokens.css → themes/cobalt-grid.css → palettes/cobalt.css`。

## 动效原则

```
1→2  关系：封面的阶梯就是四个季度的数据，四级各自移位、变高，成为柱状图   手法：共享元素  共享：q1…q4
2→3  关系：最后一根柱子展开成大竖条，关键数字从标注放大成主角             手法：形态变换  共享：q4, figure
3→4  关系：竖条缩回阶梯的最后一级，前几级回来，回到封面的构图             手法：形态变换  共享：q4
```

- **一次配对不超过 4 个**（共享元素的规则）。数据点超过 4 个时，阶梯还是 N 级，但只让其中 4 级做共享元素会读不懂 —— 所以这个同款最多 4 到 5 个点，5 个点时整组同时移动、不错开。
- **阶梯和柱子用同一个类**（`.s-scan`），不要一个用线条、一个用实心色块：共享元素不会在两种纹理之间过渡，中途会硬换。
- **数据页的标题、坐标轴、标注等柱子基本落位再出**：转场 1.2 秒，第一个新元素从 0.8 开始，标注 1.3、季度标签 1.4。
- **方格纸和细线不动**：每页同一位置、同一个类，翻页时不会闪。别给它们加 `data-id`，也别改位置。

## 硬规则

- 只用一种墨色：不引别的配色，不在页里写颜色。
- 柱子的高度按数据比例，底边对齐坐标轴。
- 不编数据。
- `.s-grid` 和两条细线每页都有、位置不变。

## 自检

除了 `references/transitions.md` 末尾的通用自检，再看：

1. 封面到数据页：每一级阶梯都是**连续移过去、长高的**，不是在新位置淡入；纹理始终是 8 根线，落定那一帧不跳。
2. 柱子底边全部压在坐标轴上，没有悬空。
3. 方格纸和上下细线在每次翻页时纹丝不动。
4. 关键数字页：大竖条是从最后一根柱子展开的，82% 是从标注放大过来的。
5. 结尾的阶梯和封面的阶梯位置完全一样。
