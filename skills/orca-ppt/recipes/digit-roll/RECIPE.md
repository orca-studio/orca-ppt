# 数字滚动时间轴

## 参考拆解

参考的是 PowerPoint 里流行的「数字滚动时间轴」（小红书「Kitty｜PPT定制」《PPT动态数字滚动时间轴》）：
画面正中一个超大的年份，翻一页，年份的每一位像老虎机滚轮一样滚到下一个数，背景照片和标题跟着换。
它在 PowerPoint 里的做法是「每一位是一个 0–9 竖排的文本框，上下各盖一块和背景同色的矩形，只露中间一格；
复制页面，把每个竖排拖到新数字，切换选平滑」。叠出来的是三样东西：

1. **一排竖条**：每一位一条 0–9，0 在上、9 在下，遮罩只露一格。所以数字变大往上滚、变小往下滚，
   中间经过的数字都会露一下；滚到一半时一格里上下各露半个字。
2. **没变的位不动**：`1978 → 1996` 只有后两位在滚，前面的 `19` 一直钉着 —— 观众一眼看出「变的是哪几位」。
3. **其余内容原地换**：标题、一句话说明、整页背景，在同一个位置换成下一年的。

看点只有一个，重复走完全程：

> **年份逐位滚到下一个数，变化大的位滚得远、没变的位不动。**

## 适用 / 不适用

| 适用 | 不适用 |
| --- | --- |
| 发展历程、城市 / 公司年表：4 到 6 个年份节点，每个节点一句话 | 节点不是数（「一期」「V3」）—— 没东西可滚，用 `ring-timeline` |
| 想要「数字本身就是主角」的节奏：大年份占画面中心 | 每个节点要讲很多内容（三句以上、带图表）—— 大年份会挤掉内容，用 `forest-timeline` 或分页 |
| 位数相同或只差一位的数（年份、版本号、四位以内的计数） | 带小数点、千分位的数（`1,200`、`3.5`）—— 用普通的文字级匹配，数值连续滚动 |

## 内容槽位

| 槽位 | 从哪取 | 缺了怎么办 |
| --- | --- | --- |
| **年份**（或其他纯数字节点） | 用户给的时间线，4–6 个，按先后排 | 只接受纯数字（可以带相同的前后缀，如「第 3 季」）；不是数就换同款 |
| **每个年份一段** | 标题（≤ 8 字）+ 一句话（≤ 40 字） | 一句话缺了就只放标题；**不编事件** |
| **封面** | 主语 + 「一座 X 的 N 个年份」这类总括 + 起止年份 | 用节点数自己写 |
| **结尾** | 往后看的一句话，年份滚到「下一个年份」（最后一年 + 1） | 没有就写「下一个年份」 |

## 页面结构

```
1 封面      顶部年份刻度（全部压暗）+ 游标藏在画面左外；中间主语 + .t-display 总括 + 一句话
2–6 节点    每页一个年份：游标移到这一格；标题 .t-h1；大年份 .t-metric（逐位滚轮）；说明 .t-body
7 结尾      年份只滚个位到「下一个年份」；游标走出画面右外；说明一句往后看的话
```

做转场锚的元素照样稿抄坐标：

| 元素 | 坐标 | 写法 |
| --- | --- | --- |
| 大年份 `year` | `left:0 top:380 width:1920`，居中 | `.t-metric`，`data-text="year" data-roll`；**每页同位置同字号** |
| 标题 `title` | `left:0 top:230 width:1920`，居中 | `.t-h1`，`data-swap="title"` |
| 说明 `desc` | `left:360 top:740 width:1200`，居中 | `.t-body`，`data-swap="desc"` |
| 刻度 `t1953`… | `top:96`，宽 160 居中，五格间隔 180（中心 560 / 740 / 920 / 1100 / 1280） | `.t-label .t-dim`，每页写同样的 `data-id` |
| 游标 `cursor` | 刻度正下方 `top:150`，16×16 | `.s-dot`，`data-id="cursor"` |
| 光晕 `glow` | 620×620，每页换个位置（落在安全区里） | `.s-accent-soft` 圆，`opacity:0.18`，`data-id="glow"` |

节点数不是 5 时：刻度间隔 180 不变，整排居中重新算中心。

主题和配色：样稿用 `clearing` 主题 + `midnight` 配色（深底、琥珀大年份）。
参考里每页换一张背景照片；本 skill 不放照片，用一团柔和光晕换位置代替「整页背景换了」的感觉。

## 动效原则

```
1→2  关系：游标从画面外移到第一个刻度，大年份第一次出现        手法：共享元素  共享：cursor, glow
2→3  关系：年份逐位滚到下一个数，标题、说明原地换，游标右移   手法：共享元素  元素级：逐位滚轮 year，原地替换 title / desc
…    （每个节点一样）
6→7  关系：年份只滚个位到下一年，游标走出画面                 手法：共享元素  元素级：同上
```

- **同一个动作连续用**：时间轴就是「顺序往前走」，和元素交接走列表一样，是组合规则允许的例外。
- **滚轮用默认 0.7 秒**（参考里平滑的时长，`ease-in-out`），不要改慢 —— 慢了中间经过的数字会一个个读得出来，像在数数。
- **年份第一次出现（1→2）按普通新元素入场**，不滚：封面上没有年份，没东西可滚。
- **标题、说明用原地替换**，不做共享元素：每页内容都不同，交叉溶解最干净。
  参考里说明文字是横向接力（旧的左出、新的右进）；本 skill 不做元素级的横移，用原地替换代替。
- 往回翻是直接切，不会反着滚。

## 硬规则

- 大年份每页**同位置、同字号、同类**（`.t-metric`），写 `data-text="year" data-roll`；字号不同滚轮会退回普通文字级匹配（控制台有提醒）。
- 年份只写纯数字（可带相同前后缀），不写千分位、小数点。
- 一页只有一个 `.t-metric`（`check-deck` 会核）。
- 光晕、游标、刻度都写 `data-id`，每页都在；光晕不出安全区。
- 不编事件：年份和事件从用户给的材料来。

## 自检

除了 `references/transitions.md` 末尾的通用自检，再看：

1. 滚动中途抽一帧：变了的位上下各露半个字，没变的位**完全不动**。
2. 方向对：数字变大的位往上滚，变小的位往下滚（`9 → 0` 是往下滚过 8、7…1，不是往上绕一圈）。
3. 滚完的一帧和下一页静止时一模一样，没有跳一下（字距、位置）。
4. 标题和说明是在原地换的，没有位移；游标每次只走一格。
5. 6→7 只有个位在滚。
