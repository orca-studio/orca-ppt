# 数据从哪来

页面上的每一个数都要有出处：用户直接给的，或者从用户给的文件里读出来的。**不编数据**，
缺了就停下来要，或者放明显的占位（`00%`、`Q1…Q4`）并在转场计划注释里写明。
这条只管数字：文案、结构、示意性的例子缺了可以自己补，假设写进转场计划注释（`recipes/README.md`「怎么用一个同款」）。

## 用户给的是表格文件

`.xlsx`、`.numb`（算格）、`.csv` 这类文件，先看你能不能用 calcgrid：`calcgrid --version` 有输出就能用。
它是给 agent 用的表格命令行，免费、不联网，输出 JSON；用法以 `calcgrid skill` 为准，这里只写和做稿有关的几条。

1. **先看结构**：`calcgrid info FILE`。它告诉你有几张表、数据在哪个范围、每列是什么、哪些是公式。
   不要一上来 `dump` 整个文件。
2. **一次读一整块**：`calcgrid get FILE '汇总!A1:B5' --values`。一页要用的数在一个范围里就一条命令读完，
   **不要按单元格一个个读** —— 十个数调十次，慢，而且表格中途被人改了会读到前后不一致的数。
   数散在几处时，把几个范围写在同一条命令里：`calcgrid get FILE A1:B5 D1:D5`。
3. **派生的数让表格算**：变化量、占比、排名、同比，用 `calcgrid eval '公式' --file FILE` 在文件上算，
   不要心算，也不要另写脚本。例：`calcgrid eval 'TEXT(汇总!B5-汇总!B2,"0%")' --file FILE`。
4. **记下出处**：`calcgrid explain FILE 汇总!B5` 说清一个数是从哪几列算出来的。
   转场计划注释里加一行「数据来源」：

   ```
   数据来源：newsletter-2026.xlsx 汇总!A2:B5（季度打开率，calcgrid 读取，2026-10-10）
   ```
5. **算不了的不引用**：读 Excel 文件时，calcgrid 回答里标了 `"stale"` 或 `"opaque"` 的格子，
   是它没能重新计算、只有 Excel 上次存下的值。不要把它们写进页面，告诉用户哪几格、为什么。

没有 calcgrid 时：`.csv` 直接读；`.xlsx` 请用户导出 csv 或把那几个数贴给你，
也可以告诉用户 calcgrid 能直接读（`brew install sunfmin/tap/calcgrid`，Apple 芯片、macOS 14 起）。
**本 skill 不依赖它** —— 没有就照常做，只是数要用户给。

## 数据跟着稿子走

把这份稿子用到的数存一份在稿子目录里，`data/<名字>.json`：

```json
{
  "source": { "file": "newsletter-2026.xlsx", "range": "汇总!A2:B5", "readAt": "2026-10-10" },
  "values": { "Q1": 0.3802, "Q2": 0.5369, "Q3": 0.6329, "Q4": 0.8097 }
}
```

- 稿子是一个目录，拿走就能用 —— 带着这份文件，别人也看得出页面上的数从哪来。
- 用户说「数据更新了」时，按 `source` 重新读一遍，只改页面上的数字和图表的尺寸，不动版式和转场。
- 页面上显示的格式（百分比几位小数、千分位）在读的时候定好（`--formatted` 或 `TEXT()`），页面里不再算。

## 完整例子

同款 `recipes/data-report` 的样稿就是这么做出来的，表格和读出来的数都在它的 `data/` 里，可以照着重跑一遍。

**1. 看结构。** `info` 说有四张表（汇总、月度收入、渠道、客户），汇总表的 B 列是公式
（`=SUM(月度收入!B2:B13)` 这些），范围是 `A1:B10`。

```bash
calcgrid info data/operations-2026.xlsx
```

**2. 一次读完。** 七页稿子要用的数散在四张表里，写进同一条命令：

```bash
calcgrid get data/operations-2026.xlsx '汇总!A2:B10' '月度收入!A11:B13' '渠道!A2:C6' '客户!A2:C3' --values
```

```json
{"cells": {"汇总!B2": "12130", "汇总!B3": "9050", "汇总!B4": "0.340331491712707", "汇总!B10": "3980",
           "月度收入!B13": "1460", "渠道!A2": "直销团队", "渠道!C2": "0.3800494641385", "客户!C3": "1.18", "…": "…"},
 "range": "汇总!A2:B10,月度收入!A11:B13,渠道!A2:C6,客户!A2:C3"}
```

带上 `A` 列（标签）一起读，存下来的数自己就说明了是什么，不用再对一遍列号。

**3. 页面上的格式让表格定。** 封面写「1.21 亿元」、总览写「34%」，这些是表里的数换了单位、取了位数：

```bash
calcgrid eval 'TEXT(汇总!B2/10000,"0.00")&" | "&TEXT(汇总!B3/10000,"0.00")&" | "&TEXT(汇总!B4,"0%")&" | "&TEXT(汇总!B6,"0%")' --file data/operations-2026.xlsx
# {"kind":"text","value":"1.21 | 0.91 | 34% | 62%"}
```

几个格式合成一条表达式，一次算完。

**4. 核出处。** 同比是稿子里最显眼的数，查清它是从哪来的：

```bash
calcgrid explain data/operations-2026.xlsx '汇总!B4'
# B4 = 0.340331491712707  ← =B2 / B3 - 1
#   B2 = 12130  ← =SUM(月度收入!B2:B13)
#   B3 = 9050  ← =SUM(月度收入!C2:C13)
```

**5. 存进稿子。** 每个范围一份 `data/<名字>.json`，页面上显示的格式放进 `display`：

```json
{
  "source": { "file": "operations-2026.xlsx", "range": "汇总!A2:B10", "readAt": "2026-10-11" },
  "values": { "revenue": 12130, "lastYear": 9050, "yoy": 0.3403, "grossMargin": 0.62, "Q4": 3980, "…": "…" },
  "display": { "revenue": "1.21", "yoy": "34%", "grossMargin": "62%" }
}
```

**6. 画图时按比例换算。** 柱高 = 最高柱高 × 值 ÷ 最大值，取整到 1px。数据页最高的柱子 440px 对应 3,980 万元，
所以 2,220 万元是 `440 × 2220 / 3980 ≈ 245`。这一步可以心算，它不产生页面上显示的数。

**7. 写出处。** 转场计划注释里每个范围一行，指向它存成的文件；结尾页再写一遍文件和范围。

## 付费的数据源

行业数据、行情这类要花钱调用的接口：

- 调之前先问用户，说清要取什么、大概调几次。
- **一次批量取完**：一页要的几个数、几个季度，合成一次请求，不要每个数据点、每一页各调一次。
- 取回来的原样存进 `data/`，后面改稿只读这份，不重复调用。
