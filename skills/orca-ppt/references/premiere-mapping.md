# Premiere Pro 转场怎么对应

用户常用剪辑软件里的名字提需求：「这里来个推」「做个交叉缩放」「用圆形划像」。
这份文档把 Premiere Pro 自带的 44 个视频过渡，对应到本 skill 的手法上。

**出处**：转场列表来自 Adobe 帮助中心的
[视频过渡列表](https://helpx.adobe.com/cn/premiere/desktop/add-video-effects/effects-and-transitions-library/list-of-video-transitions.html)。
下面「为什么」一栏里的适用、慎用和手工做法说明，取自 pr-style-transitions 项目整理的剪辑经验，不是 Adobe 官方文档。

## 先理解差别

Pr 的过渡是**套在剪辑点上的效果**，不管两个画面里是什么，都用同一种方式换过去。
本 skill 的转场是**从内容里找联系**：哪个东西留下来，哪个东西变成了什么。

所以用户说出一个 Pr 转场名时，**不要照着复刻效果**，先弄清楚他想要的感觉，再选手法：

| 用户想要的感觉 | 通常会说的 Pr 名字 | 本 skill 的手法 |
| --- | --- | --- |
| 「往下一页走」 | 推、滑动、带状滑动、甩转 | 元素交接 |
| 「钻进去 / 推进去」 | 交叉缩放、圆形划像 | 推近匹配（故事稿）、整页推近（汇报稿） |
| 「展开 / 打开」 | 拆分、中心拆分、插入、矩形划像 | 一变多、形态变换 |
| 「换个话题 / 换章节」 | 黑场过渡、划像、双侧推门 | 遮挡剪辑 |
| 「柔和一点地换」 | 交叉溶解、胶片溶解 | 共享元素（找一个留下来的东西） |

Pr 的工艺说明里，「怎么做得像样」的做法几乎都在向本 skill 的原则靠：
推要加缓动，交叉缩放要对准两边共同的点，带状滑动要错开出发，圆形划像要对准画面里的光源。
这些本 skill 都已经内置了。

## 逐个对应

### 滑动类

| Pr 转场 | 对应 | 为什么 |
| --- | --- | --- |
| 推 Push | **元素交接** | Pr 的推是线性位移，所以显得便宜。元素交接是按元素逐个推，带缓动、错开和运动模糊。 |
| 滑动 Slide | **形态变换** | 「新卡片盖上来」：让上一页的一个小元素长成新面板，比凭空滑进来更有来处。 |
| 拆分 Split / 中心拆分 Center Split | **一变多** | 「从中间打开」的本意是一个东西展开成几块，一变多正是这个。 |
| 带状滑动 Band Slide | **元素交接** | 工艺说明是「降到 3 条，错开 2 帧到位」，这就是元素交接的错开交接。 |
| 甩转 Whip | **元素交接**（带运动模糊） | 甩转的观感来自模糊，元素交接在最快的几帧自动加方向模糊。 |

### 缩放类

| Pr 转场 | 对应 | 为什么 |
| --- | --- | --- |
| 交叉缩放 Cross Zoom | **推近匹配**（故事稿）/ **整页推近**（汇报稿） | 工艺说明原话：「推近中心对准 A、B 里共同的一个点，就成了一次无限缩放」。推近匹配按锚点对准；整页推近按 `data-zoom` 元素对准，整个画面一起推。不要用匹配放大代替：它只放大一个元素，读起来像圆点跳了一下，没有推进感。 |

### 光圈类

| Pr 转场 | 对应 | 为什么 |
| --- | --- | --- |
| 圆形划像 Iris Round | **遮挡变形**（故事稿）/ **匹配放大**（汇报稿） | 圆形划像年代感强，是因为圆从画面中心凭空张开。遮挡变形的圆从锚点长出来，有来处。 |
| 矩形划像 Iris Box | **形态变换** | 「从一张卡片展开到整屏」，用共享元素让卡片直接长大。 |
| 十字划像 Iris Cross / 菱形划像 Iris Diamond | 不做 | 形状本身带强烈语义（医疗、扑克），读不成单纯的过渡。 |

### 划像类

| Pr 转场 | 对应 | 为什么 |
| --- | --- | --- |
| 划像 Wipe / 双侧推门 Barn Doors | **遮挡剪辑** | 都是「一条边扫过去把 B 刷出来」，遮挡剪辑是它们的克制版本，只用在换话题。 |
| 插入 Inset | **形态变换** | 工艺说明是「卡片展开」，用共享元素做。 |
| 螺旋框 Spiral Boxes | **共享元素** | 本意是「把注意力聚拢到中心的一个元素」，直接让那个元素做共享元素飞到中心。 |
| 时钟式划像 Clock Wipe / 径向划像 Radial Wipe | 不做 | 形状会让观众去找「表」和「雷达」。真要表达时间进度，用 `data-enter="grow-right"` 的进度条。 |
| 带状划像、棋盘划像、棋盘、百叶窗、随机块、随机划像、之字形块、风车、油漆飞溅 | 不做 | 这些是包装特效，形状会盖过内容。 |

### 溶解类

| Pr 转场 | 对应 | 为什么 |
| --- | --- | --- |
| 交叉溶解 Cross Dissolve / 胶片溶解 Film Dissolve | 不做页间转场，改用**共享元素** | 两页之间整体淡入淡出，观众看不到任何东西的去向。找一个能留下来的元素，其他内容会自动退场和入场。 |
| 相加溶解 Additive / 非相加溶解 Non-Additive | 不做 | 依赖实拍素材的高光结构，对幻灯片没有意义。 |
| 黑场过渡 Dip To Black | **遮挡剪辑**（`data-st-mask-color="bg"`） | 用在章节切换和结尾。和黑场一样，滥用会让片子一直像在「结束」。 |
| 白场过渡 Dip To White | 不支持 | 规范里没有白色，满屏白闪和深色主题冲突。 |
| 变形剪辑 Morph Cut | 不适用 | 这是给口播素材删「嗯」「那个」用的，不是页间转场。 |

### 翻页类、沉浸式视频类

| Pr 转场 | 对应 | 为什么 |
| --- | --- | --- |
| 翻页 Page Peel / 翻页（空白背面）Page Turn | 不做 | 「纸」的隐喻会盖过内容本身。 |
| VR 色度泄漏、VR 渐变擦除、VR 光圈擦除、VR 光线泄漏、VR 光线、VR 莫比乌斯缩放、VR 随机块、VR 球面模糊 | 不适用 | 这些是给 360° 全景素材用的。 |

## 用户点名要「不做」的转场时

不要直接拒绝，用一句话说清楚替代方案和理由，然后照替代方案做：

> 「百叶窗会把画面切成条纹，盖过内容。这两页之间标题是一样的，我用共享元素让标题留在原地，
> 其他内容换过去，效果更干净。要是你就想要百叶窗的复古味，告诉我。」

用户坚持要的话，说明本 skill 不提供这种转场，不要自己写 CSS 或 GSAP 去实现
（SKILL.md「不许做的」）。
