# 做同款

用户从 Orca PPT 首页复制「做同款」提示词发给你时，照这份做。提示词里写着同款的 id（`recipe:<id>`）、
样稿在哪、用户的内容；做法都在这里。

下面的工具名是 Orca PPT 的工具：配了 MCP 就直接调；用 `orca-ppt` 命令的，按 `workbench.md` 用
`orca-ppt call <工具>` 调，规则一样。

## 1. 读配方和样稿

用 `read_skill` 读 `recipes/<id>/RECIPE.md`，再读样稿的 `index.html`（提示词里给了路径）。
**样稿就是这个同款的答案**，开头的转场计划注释写着每次翻页的手法。样稿比一次返回的长：
结果里 `next` 不为空就带着它接着读，读到底再动手。

## 2. 先看合不合适

对照配方的「适用 / 不适用」看用户的内容。不适合就直接告诉用户为什么、该换哪个同款，别硬套。

**用户的内容是空的**（只发了提示词，槽位都空着）：不要拿样稿换一套你编的公司名和数字。
用 `present_recipe` 在工作台里打开样稿给用户看效果，再照配方的「内容槽位」列出要准备什么，
等用户给了再做。

## 3. 从样稿起头，在画布上换内容

- 用 `create_deck` 新建，`from` 填 `recipe:<id>`：复制一份样稿，主题、配色、素材都带上。
  紧接着 `open_deck` 打开它 —— 之后每一处改动，画布都会翻过去框给用户看。
- 改字用 `edit_text`：一段一段换，能撤销，不会碰坏转场靠的属性。转场计划注释里的字用 `edit_plan`，
  删页用 `edit_pages`。
- 要多一页同样结构的页：先 `edit_pages` 插一页，再 `read_page` 读相邻那一页，改好用 `write_page`
  写进新插的那一页。
- 要改转场锚的坐标：逐页 `read_page`，改好 `write_page` 写回，按配方的「页面结构」算锚点。
- 不要用你自己的文件工具改 `deck.html` —— 画面上看不见，也撤销不了。不要从空白重写，
  也不要写脚本整份替换。

没有 Orca PPT（工具和 `orca-ppt` 命令都没有）时：复制样稿目录，把里面的 `../../` 改成到本 skill
根目录的相对路径，再换内容。

## 4. 内容

- 缺的细节（标题措辞、口径的写法）你自己定，把假设写进转场计划注释里。
- **人名和数据不编**（`data.md`）：用户没给的留占位，或者停下来问。
- 样稿里的示例年份、公司名、标语和句子都是别人的，一条也别留：换成用户的，或者删掉。

## 5. 看图自检，再交付

- 用 `capture_slide` 把每一页都截下来看，漏一页就不算看过。按配方的「自检」和 `transitions.md`
  末尾的「自检标准」过一遍。
- 交给用户时说一声「在 Orca PPT 里看」；要发给别人，用 `export_pptx` 导出。
- 不要把 `deck.html` 当成品单独交出去 —— 它引着本机的 skill，拷到别处就丢样式；单独用浏览器打开也没有
  画布上的翻页、框选和撤销。
