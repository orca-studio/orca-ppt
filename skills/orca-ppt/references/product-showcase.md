# 产品分栏 → 全屏详情

适用：用户要复刻“四栏饮料依次展示，最后一栏展开全屏”这类共享元素动画，或要用自然语言替换内置案例的产品。入口：`examples/drink-showcase/index.html`；教学页：同目录 `tutorial.html`。

## 五页状态，不写新动画

1. 第一栏激活：色块在第一栏，橙瓶在展示位，其他瓶子在画布下方。
2. 第二栏激活：**同一个**色块移到第二栏、变粉；橙瓶放到画布上方，粉瓶移到展示位。
3. 第三栏激活：重复交接，色块变淡紫。
4. 第四栏激活：重复交接，色块变青。
5. 详情页：同一个青色块铺满，第四瓶居中放大；前三栏信息淡出；新标题在瓶子后面入场。

所有页保留相同的瓶子 `src`、标签和 `data-id`。色块用 `active-panel`，瓶子用 `bottle-<产品名>`，名称、说明、编号和按钮各有自己的稳定键。只改坐标、尺寸、语义颜色类和必要的透明度。瓶子要在两页里都存在，才能从画外连续进入；临时创建图片会变成默认的短距离淡入。

页面顺序：色块 → 背后的大字（详情页）→ 瓶子与产品文字 → 导航与容量。不要把大字画在瓶子上面。

## 仅此案例的局部规范

根节点同时使用 `data-layout="standard" data-demo="product-showcase"`，加载 `tokens.css → themes/product-showcase.css → palettes/fruit-soda.css`。普通汇报稿不继承以下例外：

- 全出血四栏：1920×1080，每栏 480。文字安全区左右 72、顶部 48、底部 80；背景可以铺到边缘。
- 画外待命：仅允许有跨页同标签、同 `data-id` 配对的元素完全放在画布外；页面裁切溢出。部分露出、未配对的误出界仍要修。`check-deck.mjs` 按这个规则检查。
- 多元素联动：一条“激活下一产品”的动作可配对整组瓶子、文字、编号和背景；未参与切换的元素保持原位。普通页面仍沿用 1–4 个共享主角的建议。
- 色彩：橙、粉、淡紫、青是参考案例的产品识别色，可按案例次序插值。替换品牌配色时检查中间帧，不把它扩展为所有深浅色都可直接互变。
- 字阶：`product-showcase.css` 的 `.t-product-*` 是产品页面角色，允许超大背景词与紧凑说明。它们不改变普通 `.t-*` 字阶；正文配深色提高可读性，白色大字只作装饰。
- 时长：前三次转场各 22/30 秒，最后一次 0.8 秒，这是参考节奏，不作为其他演示稿的默认值。讲解时可用教学页的 2 倍慢放，或将共享元素时长改为 1.2 秒。元素延迟也要随之调整。

这是已验证的示例配置，不是新动画 API。无需修改 engine.js。教学页的 JavaScript 只调用 Reveal 翻页、调节现有时长和安排播放顺序，不实现元素动画。

## 替换素材

内置四只瓶子是自制 SVG 示意图。换成透明 PNG、WebP 或 SVG 时统一画布比例、主体位置与留白，避免同样的 CSS 尺寸对应不同视觉大小。每只产品在五页里引用同一份文件。第四瓶详情页不要换另一张不同裁切的图。

提示词见教学页，可要求“使用这个案例，替换四张图片、名称、配色及详情标题”。明确要保留运动关系、是否保留参考节奏。不要让没有四项产品的内容硬套四栏。

## 验证

```sh
node scripts/check-deck.mjs examples/drink-showcase/index.html
npm run palettes
node scripts/capture.mjs examples/drink-showcase/index.html -o examples/drink-showcase/index.mp4 --json examples/drink-showcase/capture-report.json
```

检查正常播放与中间帧：色块连续横移、旧瓶上出、新瓶下入、静止栏不抖动；最后青色面板铺满，瓶子持续可见，大字在背后。检查前进、回退、重播以及教学页慢放。`capture-report.json` 的 `problems` 应为空。输出 181 帧；30fps 表达包含源 6.000 秒的最后采样点，总时长 6.033 秒。
