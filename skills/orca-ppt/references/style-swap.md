# 同一个网页换风格：框内示意网页的样式例外

适用：同款 `style-swap`（[recipes/style-swap/RECIPE.md](../recipes/style-swap/RECIPE.md)）。稿子要演的是「同一个网页，换一种风格」——
网页风格本身就是内容，赛博朋克的霓虹粉、粗野主义的黑框、杂志风的衬线斜体，用主题的那十个颜色变量和字号类表达不了。
所以这个同款允许**画面里那个浏览器框内**的示意网页用稿子自带的样式表；框外（页面底色、风格名、浏览器框本身）照常只用主题和配色。

## 仅此同款的局部规范

根节点写 `data-layout="standard" data-demo="style-swap"`。没有这个标记，稿子引自己的样式表一律报错（`check-deck`「自带样式表」）。

1. **样式表只有一份**，放在稿子目录里（样稿叫 `mockup.css`），在主题和配色之后引入。
2. **只管框里的东西**：每条选择器都要带 `.mk` 开头的类（`.mk-min .mk-head`、`.mk-art-min`）。框外的元素一条也不许被它选中。
3. **示意网页的元素都在框里**：每页一个 `.mk-screen`（网页区域，带 `data-id="mk-screen"`），
   带 `mk` 类的元素终态和转场中途都不许出这个区域。
4. **示意网页里的字不许叠字、不许压在色块 / 图片边上**（完全落在一块里面可以，比如数字压在卡片上）。
   终态和转场 30% / 50% / 70% 都量：字号在变，宽度要跟着约束，别在中途溢出。
5. 行内 style 仍然只写位置、尺寸、`opacity`、`rotate`、`border-radius`，颜色和字号进样式表 —— 换一种风格就是换一个 section 类，
   不在元素上散落色值。

`check-deck` 对 `data-demo="style-swap"` 的稿子核第 1–4 条（读源文件看样式表和选择器；跑起来量终态和转场中间帧）。

普通汇报稿不继承这条例外：要换颜色字体，仍然按 `themes.md` 新建主题和配色。
